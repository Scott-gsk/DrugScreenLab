# DrugScreenLab 数据集目录

更新日期：2026-09-17。

本文客观记录 DrugScreenLab 当前本地数据资产，包括数据来源、数据类型、本地状态、规模、完整性和重要性。重要性主要依据数据是否完整、是否包含可分析数值，以及相对现有资产是否提供新的信息；不代表具体实验结论。

## 1. 目录结构

| 目录 | 内容 |
|---|---|
| `raw/` | 从公开来源取得的原始文件；只读保存 |
| `external/` | 第三方已处理数据和外部资产 |
| `interim/` | 可由原始数据重新生成的中间文件 |
| `processed/` | 按项目数据格式生成的处理后数据 |
| `splits/` | 训练、验证和测试划分文件 |
| `registry/` | 数据来源、版本、路径和校验值登记 |
| `artifacts/` | 数据审计、处理回执和实验产物 |

大型数据文件不提交到 Git。Git 中主要保留登记、代码、数据合同和紧凑审计结果。

## 2. 当前可获取规模与完整性总览

规模数字分为三种口径：**本地已解析**表示文件已经读取并实际计数；**本地已取得**表示原始文件已保存，但不一定完成全部表格化；**论文报告**只表示文章描述过该规模，不代表相应逐样本矩阵已经公开或已到本地。

### 2.6 汇总

- 已经形成较完整“基线表达＋药物响应＋身份”配对的资产包括三组跨资源配对（GDSC2—Cell Model Passports、PRISM—DepMap、CTRPv2—DepMap），以及两个来源内部已经配对的类器官数据（Kryeziu、Zhu）。
- IMPROVE 文件完整，额外提供 CCLE 药物响应、gCSI 和 GDSCv1，同时包含与现有来源重复的 GDSCv2 和 CTRPv2。
- 乳腺癌和胰腺癌方向尚无新增的完整多患者表达—多药公开矩阵；相关资源只保留简短来源和缺项说明。
- Herranz-Ors、Kuo、LINCS 和 ChemPert 数据本身有信息价值，但缺少完整药物响应标签，属于表征或机制数据。

## 3. 药物响应数据

### 3.1 GDSC2 响应与 Cell Model Passports 表达的配对

这是当前规模最大的完整基线表达—药物响应配对资产之一。GDSC2提供细胞系药物响应，Cell Model Passports提供同一批细胞系的基线表达和身份信息；配对后覆盖963个细胞系和219种药。理论上共有210,897个细胞系—药物组合，实际测得179,410个，未测组合属于来源筛选设计，不是本地文件丢失。

| 项目 | 内容 |
|---|---|
| 重要性 | **重要数据**；大规模基线表达与药物响应配对资产 |
| 药物响应来源 | Genomics of Drug Sensitivity in Cancer 2（GDSC2） |
| 基线表达来源 | Cell Model Passports |
| 生物模型 | 癌细胞系 |
| 数据类型 | 基线基因表达、药物结构、药物响应 AUC、细胞系身份 |
| 当前处理版本 | `processed/exp014/gdsc_v3/` |
| 药敏规模 | 963 个细胞系；219 种药；完整组合数为 210,897；实际有 179,410 个唯一响应组合；31,487 个组合没有响应记录；覆盖率 85.1% |
| 表达规模 | 963×19,091；每行是一个细胞系，每列是一个基因的基线表达值；共 46,224 个表达值缺失，非缺失比例约 99.75% |
| 响应定义 | `1 - AUC`，数值越高表示越敏感 |

| 已知缺项 | 部分批次和培养条件元数据不可用；当前处理版本没有纳入来源中重复的细胞系—药物键和无法确定当前结构表示的药物 |

官方来源文件和完整转换来源表均保留。`gdsc_v3` 是另行生成的处理版本，没有覆盖来源文件。

| 基线表达与身份来源 | DepMap 24Q2 |
| 生物模型 | 癌细胞系 |

### 3.5 CTRPv2 响应及其与 DepMap 表达的配对

| 状态 | 含义 |
|---|---|
| 文件齐全 | 登记范围内的文件已在本地，大小或校验值符合记录 |
| 部分齐全 | 已有部分数据类型或部分样本，仍缺研究声明的其他数据 |
| 已下载未解析 | 容器文件已在本地，尚未转换为项目可读取的数据表 |
| 公开未找到 | 已检查论文附件和常用公开数据库，未发现所需文件；不表示文件永久不存在 |
| 受控访问 | 需要数据库授权或申请后才可取得 |
| 技术阻断 | 文件入口存在，但当前下载请求被验证页面或客户端条件阻止 |

## 10. 文件保护与登记
