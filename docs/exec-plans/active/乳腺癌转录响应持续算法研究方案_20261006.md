## 目标和边界

主要问题：在共享药物扰动效应之外，处理前细胞状态是否能增加基因表达响应预测信息，并保留在未见细胞、未见药物及合格的独立公开转录研究中。主要终点为固定 978 基因轴的响应 NMSE，按独立来源对象等权；相关、方向和幅度为解释指标。药效、表达逆转分别作端点，不混为转录预测效能。

EXP-037/050 中已使用或已解锁的来源域统一作开发/历史证据，不重标为独立测试。真实 PDO 数据缺口只限制 PDO 实证端点，不暂停来源模型训练、基线比较或公开转录域准入。PDO 数值药敏、outer/locked 响应不得用于拟合、选模或诊断。不同文件名不证明数据独立；未核对对象、药物和条件重叠前不称“独立研究”。不联系作者、不采购、不开展湿实验。原 TranSiGen/XPert 代表模型仍是必做对象，不以小网络替代；不复用谱系未知旧权重，按原架构新训。研究范围实质变化另行登记，不改写 EXP-050。

### 模型合同、基线和小域门

逐项核对原仓 `D:/Code/TranSiGen`、`D:/Code/XPert` 的输入转换、控制/处理构造、损失分量与权重、优化器日程、BatchNorm/VAE 行为、输出变换、gene/condition 轴及官方配置。既有 TranSiGen v5 固定 100 轮两臂为 scratch、lr=1e-4、固定顺序；作者入口默认 lr=1e-3、shuffle、最多 300 轮且含可能的 shRNA 预训练权重。因此 v5 是已冻结的训练侧目标差异诊断，不冒称官方训练复现，不重跑。XPert 官方配置为 128 bins、范围 0–15.002、batch 128、学习率 0.004、weight decay 1e-5；官方训练前 70 轮使用按样本均值开根的 MSE 阶段，再切换 raw weighted loss。作者数据集连续目标路径没有已核实的运行时标准化或输出反变换。旧 EXP-050 runner 从 epoch 1 使用 raw weighted loss、batch 16 和 patience 10，未调用上游 `train_xpert.train()`；故旧 11 轮提前停止不能代表完整 XPert 官方日程，也不足以单独归因为算法无信息。首包实现须在尺度和输入分箱核验通过后，显式匹配其可复用的官方训练阶段；Scratch 初始化是为避免未知谱系 checkpoint 的本实验偏离项。

首个响应盲子域来自合格训练条件，最多 512 条且覆盖多细胞、多药。TranSiGen 和 XPert 各最多 100 轮，共用同一训练键、分组验证键、随机种子和目标轴。XPert 保留官方前 70 轮 schedule 后续阶段；小域训练按冻结日程运行，不因首轮内层分数差提前取消。记录每项 loss、梯度/输出幅度、每轮训练及内层验证的绝对 NMSE、相关、方向、幅度比、选停/末轮、checkpoint、逐键预测、键轴回读和成本。

固定基线：零变化、训练侧全局均值 delta、训练侧逐药均值；若估计和键覆盖合格，补充结构线性低秩、表达+结构低秩。主指标在 978 基因轴上按对象等权。固定训练拟合门：第 100 轮训练 NMSE 相对零变化和逐药均值中较强且非退化的基线至少降低 10%，且平均绝对预测/观察幅度比为 0.5–2.0。基线误差为 0 或分母为 0 时相对改善记未定义，给出绝对误差/差，不补零、不据此判模型失败。两模型首轮小样本合计不超过 2 GPU 小时；剩余最多 3 GPU 小时仅可作一次有证据实现修复并运行。未过门的模型标为当前训练实现拟合不足，其他模型和基线继续。

### 论文级验收与循环决策

论文级结论需同时覆盖六项：与 TranSiGen、XPert 及状态条件响应领域最近方法的具体贡献差异须经同协议比较；原架构代表模型和强基线须在同一键域、信息、分母上公平比较，未拟合模型保留缺项，不能以失败拟合低分宣称新方法获胜；既定三种子以及去状态、整对象状态打乱、容量匹配和功能随机组须支持归因；未见细胞、未见药物和通过资格核验的跨研究分别报告真正独立分母与冻结测试；乳腺转录迁移与药筛关系分开连接，PDO配对药效缺口只限制依赖它的结论；代码、划分、逐键预测、统计和成本须可复核。10%训练拟合门、5%开发晋级门和60%对象方向门是内部决策门，不等同于论文完成标准。

失败处理固定为：实现故障只修实现，不更换科学假设；拟合过关而开发无增益时停止该候选扩展，下一轮最多增加两个由已观察失败机制导出的候选；对象打乱或容量对照不支持归因时补对照或收窄归因；独立测试失败后冻结负结果且不再用该测试调参，后续确认须另行冻结未暴露域；预算不足时列明真实费用、剩余必做项并提出具体变更，不静默减项。不得用综述或状态更新代替获批算法实验。
