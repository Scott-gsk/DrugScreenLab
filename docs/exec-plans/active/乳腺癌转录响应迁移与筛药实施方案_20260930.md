# 乳腺癌药物诱导转录响应的跨体系迁移研究与类器官筛药实施方案

编制日期：2026-09-30。执行状态：用户已授权启动。执行窗口：从执行对话启动起七天；按研究依赖顺序推进，不按天分配任务。新增资源上限：48 GPU小时，失败和重跑计入，与历史实验账独立记录，不重新核准未知历史余额。

## 1. 研究目标与科学主线

以药物诱导的转录响应为研究对象，比较乳腺癌细胞系与患者来源类器官的基因表达和功能变化，验证转录响应的可迁移性及其与药物敏感性的关系，形成有可解释依据的筛药方法，并设计类器官实验检验有效性与适用范围。

主线：**实测类器官转录变化 → 细胞系与类器官实测响应比较 → 扰动模型预测 → 转录变化与药效关系 → 一次针对性改进及融合 → 类器官筛药实验。**

转录响应迁移是核心问题。药敏用于检验筛药价值；直接药敏模型作为参照，不开展新的大规模调优。疾病表达逆转作为一种评分依据，不预设逆转必然对应药效。相同功能变化是否对应相似药效是待验证假设，同时保留反例。

依据为会议转写中11:57—13:10的通路解释及取数要求、18:38—21:30的有效与无效药物共同验证要求、29:05—29:56的跨体系通路变化讨论。会议资料：`D:/software/微信/聊天记录/xwechat_files/wxid_x1q1dtvzi62m22_6d0f/msg/file/2026-09/“标准录音 44”-转文本结果.txt`。附加解读仅作参考，不代替原话或用户授权。

## 3. 顺序执行步骤与验收

### 3.1 建立类器官实测转录响应

补取GSE287429/GSE216540矩阵、注释和论文附件，按身份键绑定。取得计数时采用适合计数的差异分析；只有TPM/标准化表达时使用对应变化量方法，不伪装成计数分析。处理批次、时间、培养条件和重复。

输出逐药/逐类器官基因变化、功能方向及强度、重复一致性和不确定性。Hallmark是概括生物功能的50组基因，KEGG仅用于重点解释。全转录组与LINCS共有基因范围分开，报告功能覆盖；至少一项合格对照完成后立即接续3.2，其他数据并行。

### 3.2 比较细胞系与类器官的实测响应

同药共同范围比较：全部合格细胞平均、同亚型平均、按处理前状态选取相近细胞、数量匹配随机参照。相近细胞不能根据类器官处理后结果挑选。

主指标为共有基因转录变化相关性；同时报告变化幅度误差、功能方向一致率及重点差异。独立对象为类器官/患者，不以基因或单细胞数量扩大统计分母。同药同剂量同时间、同药跨条件、异药相关机制分层报告；不统一套用10µM×24小时。

产物为逐对象迁移比较和“保留/改变/无法判断”功能表。没有药物交集时登记具体缺口，继续可用单药比较和模型工程，不扩大为整条路线暂停。

### 3.3 预测转录响应并检查模型能力

复用`D:/Code/TranSiGen`、`D:/Code/XPert`和项目适配入口。核对曲线、选停、检查点及偏差；需要修复时先训练侧小样本拟合，来源开发数据冻结配置后再评价。

以类器官处理前/匹配对照表达预测处理响应，对比实测细胞参照、平均扰动、无变化。统一评价变化误差、变化相关性、幅度偏差及功能变化。RNA-seq与L1000输入差异必须披露；跨平台变换在来源开发侧拟合，使用目标无标签表达的协议单列。

已用目标处理后结果设计方法的分析标为探索，确认使用另一研究或未来独立患者。零变化相关未定义时保留未定义，不转零。训练失败、拟合不足与跨体系泛化失败分别判定。

### 3.4 检验转录变化与药效关系

在可配对细胞数据和具备真实药敏数值的类器官范围内，对比药物均值、直接药敏参照、实测扰动、预测扰动、总体扰动强度及增殖/应激对照。跨研究、剂量和时间配对明确列出限制，不称作同条件测量。

有合格乳腺癌疾病参考时开展逆转评分，缺参考不套用CRC签名。控制共享药物效应后检查功能信息增量。少药类器官数据做案例及功能验证，不强行算完整排序性能。输出可用规则、反例和适用范围。

### 3.5 一次方法改进与融合比较

监督模型根据开发证据只选择一个主改进：共享效应后的状态残差、功能变化表征、可迁移功能加权或尺度修复。不叠加多模块。候选至少与原模型和必要打乱/随机对照消融；候选数量不超过两个，仅开发侧选模。候选开发收益不足时保留结果，不再架构搜索。

随后共同范围完成直接、扰动、融合、等容量、扰动打乱五臂比较。融合用训练侧交叉预测，权重内层选择；记录药敏测试对象是否暴露于扰动训练。预算不足优先完成主线比较，保留融合未完成项，不宣布全部完成。

### 3.6 形成类器官筛药与取数方案

提出20药面板，覆盖细胞系反应较好与较差的两端各10药；转录/功能信息给出机制依据和迁移判断，两路线分歧药列替换候选。身份/覆盖不足时实际列出可用数和缺口，不凑数。

每药给出来源药敏、实测或预测响应、功能依据、新用途候选身份及正负实验如何影响假设。药敏后按预定规则挑选预测与药效一致及不一致的组合测序，包含匹配溶剂、合适时间剂量和独立培养重复。用于校正的患者与独立验证患者分开。培养容量、采购、用药和测序由实验团队确认，不自动执行。
