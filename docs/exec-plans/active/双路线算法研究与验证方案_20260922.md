# 面向类器官虚拟筛药的双路线算法研究与验证方案

用途：本轮研究设计与验收依据；2026-09-22 获用户授权，2026-09-24 更新执行规则。本文定义科学问题、数据、对照、评价和资源边界；各实验的实际进度、运行回执、测试结果与决策依据见 PROJECT_STATE.yaml、experiments/records/EXP-###.md 和对应产物。不要在本方案追加进程快照或执行矩阵。

**当前有效约束**：单次正式运行≤20小时，实验包累计≤48 GPU小时（含失败与重跑）；双路线融合、DepMap细胞系→Nature类器官基因依赖监督、细胞系→类器官通路迁移和可解释性验证均按相应章节执行。具体模型分工、成块授权及有界审查按 docs/AGENT_GOVERNANCE.md；本方案第17节给出当前研究队列。旧运行回执中的8/12小时门槛和历史NO-GO只作为当时记录，不能直接作为当前停止线或自动放行依据。

两条路线分别验收：路线一预测患者药物响应，路线二预测扰动并验证疾病状态逆转；融合在两路合格输入齐备后执行。现有PharmaFormer、TranSiGen、XPert实现先做资产与输入核验，再进入统一基准；PRnet是流程参考及可选对照，不从零重复已有复现。当前方案修订不等于实验完成或运行模型已经切换。

## 1. 核心判断与研究定位

项目首要目标是算法方法：提出并验证相对最近竞争方法有明确增益、且增益有消融证据的新方法。可靠输入、身份核验、基线折次和历史审计服务于该目标，不作为最终成果本身。每个阶段先给出论文主张、最近方法差异、已验证的训练侧瓶颈和最多两个可证伪候选，再决定完整比较；不得只因简单加排序损失、适配器、通路或融合就称为方法创新。身份核验和基本统计是研究底座；通路、基因依赖和域差异分析只在能够回答一个具体算法问题时开展。

两条路线解决不同问题，分别形成训练目标、主要终点和有效性证据。路线二不必预测细胞活力，不以路线一成功为前提，也不被默认降为辅助特征。

| 项目 | 路线一：直接药物响应预测 | 路线二：扰动预测与疾病状态逆转筛药 |
|---|---|---|
| 科学问题 | 来源细胞系知识能否帮助新患者的类器官药物响应排序？ | 能否预测药物在新细胞状态下引起的表达变化，并据此寻找纠正疾病表达状态的药物？ |
| 核心输入 | 给药前表达、药物结构、研究来源；剂量曲线摘要的定义另记 | 给药前表达、药物结构、剂量、时间；筛药阶段另输入独立疾病签名 |
| 训练标签 | 实测药物响应，AUC/DSS 等分别处理 | 实测处理与对照表达之差或明确的扰动签名，不使用药敏标签作为必需监督 |
| 输出 | 药物响应预测及患者内药物排序 | 预测扰动、疾病逆转评分、候选排序及适用范围 |
| 主要有效性 | 超过患者无关基线，且在未见患者上有效 | 未见生物模型的扰动预测准确；由预测产生的逆转排序与独立实测扰动排序一致 |
| 药敏在其中的角色 | 核心标签和评价终点 | 可选外部表型验证之一，不是唯一终点 |
| 当前证据定位 | 有限来源内部信号、候选迁移收益待严格复核 | 既有实现不足以代表路线能力；需要恢复独立的扰动和逆转验证链 |

首个疾病范围固定为结直肠癌，依据当前类器官资产与既有肿瘤—正常签名；不在首轮扩大到所有癌种。结直肠不同解剖部位、原发/转移和治疗背景记录为适用范围。药物先限定单药，小分子结构身份可确认；联合用药另立问题。

论文组织：一个项目、两套独立实验包。每条路线可独立形成方法学结果；仅在同一外部表型任务上比较两条路线。不得把路线一的 DSS 排序与路线二的表达恢复分数放在同一排行榜宣称优劣。

## 3. 科学假设及证伪条件

| 假设 | 预先定义的比较 | 支持条件 | 未获支持时的解释与下一步 |
|---|---|---|---|
| A1：表达—药物交互提供个体化响应信息 | 交互模型 vs 药物均值、药物单独模型；同癌种患者表达置换 | 患者内排序增量为正且配对区间支持；置换使表现降低 | 当前输入/模型/样本下未建立个体化贡献，检查能力与泛化，不宣布所有直接方法无效 |
| A2：来源权重降低目标学习成本 | 相同来源预处理的随机初始化 vs 预训练初始化，目标标签量相同 | 在预注册标签档位出现可重复增益 | 区分预处理、标签量和权重收益；不能仅凭最大档显著称少样本迁移成功 |
| B1：细胞状态条件化提高扰动预测 | 相同药物与处理条件下，条件模型 vs 去表达模型；已见药物的训练侧均值作为强对照 | 未见细胞状态上误差降低，扰动方向和特异性指标支持 | 检查上下文信息是否被利用、测量噪声与条件覆盖；允许一次受控高能力诊断 |
| B2：条件扰动能够重建独立实测的疾病逆转排序 | 同一固定疾病签名作用于预测扰动和实测扰动，按细胞和处理条件比较药物排序 | 预测排序优于药物无关/上下文无关对照，且对独立签名稳健 | 明确瓶颈是扰动预测还是筛药读出；不以药敏负结果否定分子逆转任务 |
| B3：预测的分子逆转具有外部疾病相关作用 | 冻结候选排序 vs 独立实测转录恢复或功能表型 | 外部关联或候选实验验证支持，且不是仅普遍毒性 | 保留分子层预测贡献，降低药效主张；表型可能与恢复不是同一目标 |
| B4：可靠性约束提高候选选择稳定性 | 相同扰动预测下，基础逆转评分 vs 可靠性/不确定性约束 | 降低跨重复和跨签名排名波动，且不牺牲独立实测排序表现 | 去掉无贡献模块，不反复换评分寻找正结果 |
| F1：两路线在同一外部表型上互补 | 两单路、等容量直接模型、融合、打乱扰动对照 | 公平监督和预算下融合获得稳定增量 | 只对该融合结构下结论；两路线独立结果仍保留 |

“支持”要求同时通过数据与实现验收，不以 p 值单独判定。没有公认实用阈值时报告效应大小与不确定性，不编造临床有效线。

### 4.2 三份独立数据合同

1. **药敏合同**：患者/细胞、样本、药物、研究、端点、原值和方向、剂量范围、重复测量。AUC 在此指剂量响应曲线面积，与分类 ROC-AUC 无关。不同研究不因同名 AUC 就直接合并回归；DSS 单独处理。
2. **扰动合同**：生物模型、给药前对照、处理实例、药物结构、浓度及单位、时长、批次、板号、重复关系、基因轴、测量层级和质量信息。共享对照、同一处理的重复和技术近重复不得跨训练测试。
3. **疾病参照合同**：肿瘤/正常标签、患者配对证据、组织部位、细胞组成、测量平台、处理方法、签名构建与验证角色。正常邻近组织不自动等同健康上皮，正常组织也不直接等同正常 PDO。

所有连接都检查键唯一性、连接前后行数、未匹配清单及重复来源。原始文件只读，矩阵必须保存轴标签。

### 4.3 表达与标签处理

- 基因映射用固定版本标识；一对多映射显式处理。加载矩阵按显式基因清单重排并断言一致，不凭文件顺序。
- 药敏输入在每个训练折拟合缺失处理、尺度和特征筛选；内层验证也单独拟合。缺失与低表达不同；大量缺失的样本不靠补零伪装完整。
- 扰动主版本仅使用可靠的直接测量基因；连续变化定义为同处理体系、可匹配对照下的处理后减对照值。对照匹配以实验元数据为证据，不以表达最近邻替代真实对照。
- 签名版本单独保留：只能支持方向的资源进入方向预测任务；未被列为差异基因不默认真实零变化，使用可观测标签掩码。
- GSE74602 先核对官方样本元数据和配对关系；不能仅凭排序顺序认定配对。原有“未标准化信号比值”只作历史敏感性版本。芯片按平台说明选择可用的背景/分布处理，随后用配对设计估计差异；不对芯片或 log 表达使用原始计数模型。
- 不默认做 ComBat/Harmony：先确定是否需要。生物状态与研究批次完全重合时不能宣称校正已区分两者；转导式目标域处理独立报告，严格新样本设置不得拟合整组测试表达。
- 签名发现所需差异分析只生成算法输入、可靠性和不确定性；不附加无对应算法问题的生存、网络和富集任务。

### 4.4 质量退出条件

身份、基因轴、处理方向、样本配对或单位无法确定时，阻断相关数据包；不阻断另一条独立路线。质量阈值在看模型效果前锁定。重复数不足不能伪造测量上限；缺乏正常参照时仍可研究扰动预测，但不能声称验证了正常恢复。

## 5. 路线一：直接响应预测算法与实验

### 5.1 模型定义

定义 y 为同一研究内统一方向后的药物响应，值越大表示越敏感。推荐候选结构：

`预测 y = 训练侧药物基线 + 细胞状态项 + 表达—药物交互项`。

交互项必须随患者和药物共同变化，避免纯加性患者项在患者内药物排序中抵消。先用表达编码与固定药物指纹的低秩双线性交互建立基线；主论文骨干优先复现PharmaFormer，再按第13节开展小样本适配。药物基线只对已见药物有效，未见药物单列结构模型分支，不用测试药物均值。

训练采用域内标准化响应的 Huber 回归损失，加患者内药物对排序损失；患者等权采样。不同研究使用独立输出头或独立训练，不强行合并标签。排序损失权重候选固定为 {0, 0.1, 0.3}，只由训练侧内层验证选择。

来源预训练保持输入定义一致。迁移比较包括：目标从头训练、来源预处理+随机权重、来源权重冻结表征+目标头、来源权重微调。第一轮微调与从头训练结构、预算、标签量一致。

### 5.2 必备基线与能力诊断

两种药物均值基线必须分别命名：**来源细胞系药物均值**是在来源训练细胞中，对每种药的响应先按生物对象汇总再等权平均；所有目标患者得到同一套来源药物排序，不使用目标药敏。**目标类器官药物均值**只使用当前训练折中获准访问标签的患者，先合并同患者重复，再对患者等权平均；所有测试患者得到同一套目标药物排序。后一基线需要目标标签，不能用于零目标标签设置；测试患者及验证患者不能进入其拟合。两者分别衡量跨体系固定排序和目标体系固定排序，均不包含个体化能力。

- 来源训练细胞药物均值；目标训练患者药物均值，分别用于正确监督情形。
- 仅药物结构模型、逐药 Ridge/ElasticNet、梯度提升树、现有双编码器。
- 候选交互模型及去交互消融。
- 癌种内唯一患者表达置换，广播到其全部药物记录。
- 单个更强交互模型作为容量诊断；不把增加层数和改变预处理混成一个比较。

### 5.3 划分与主要终点

| 实验 | 划分与范围 | 主要终点 |
|---|---|---|
| A-内部泛化 | 来源按细胞身份外五折、内三折；已见药物 | 细胞内全药 Spearman 相对内层选定最强基线的配对提升 |
| A-跨研究 | 冻结来源检查点及对应训练基线；排除全部来源训练生物身份 | 同指标，单独报告端点和候选面板差异 |
| A-零目标标签 | 不用目标药敏训练、选择或阈值调整 | 患者内排序相对来源基线的提升；置换检验个体化贡献 |
| A-少量目标标签 | 患者外五折；25%、50%、100%嵌套训练患者 | 50%档来源权重 vs 相同预处理随机权重为主要比较；其他档为学习曲线和校正后的次要比较 |

50%档为前瞻工作假设，不依据已有100%档阳性结果选择；旧100%档修复仍独立完成并如实报告。若任何档位不满足每药训练与验证条件，按预登记可用性规则标记不可评价，不改划分寻找阳性。

主要面板为来源与目标身份合格的共同药物；完整目标面板分已见/未见药物报告，禁止根据真实响应排序筛出“容易/困难药”作为主面板。每患者至少三种共同实测药才计算主排序，记录有效分母。

辅助终点：同药物跨患者折内相关性、前1/3药物选择损失、同端点误差、NDCG辅助值。患者内相关性本身不能证明个体化；必须联读基线增量及患者置换。

## 6. 路线二：独立的扰动与疾病逆转算法

### 6.1 三层任务，不强制接药敏头

1. **B-扰动预测**：预测未见细胞状态下的真实表达变化。
2. **B-分子逆转筛药**：使用独立疾病签名，将候选药按预测的疾病状态纠正程度排序。
3. **B-外部作用验证**：用独立实测转录变化和疾病功能表型验证。药敏是可选证据，不强迫改成 AUC 回归。

基础研究依据：CMap 建立表达扰动连接框架 [R2]；表达逆转研究展示了候选发现及外部验证路径，也指出剂量、时间和非特异效应会影响解释 [R3]。这些工作支持任务定义，不意味着本项目已经证明药效。

### 6.2 推荐的条件扰动模型

输入：对照状态 x、药物结构 d、浓度 c、时间 t；输出连续扰动 Δ，并保留缺失掩码与可靠性信息。

首轮候选结构：

`预测 Δ = 药物与剂量时间共享效应 b(d,c,t) + U[(W_x h(x)) ⊙ (W_d e(d,c,t))]`。

h 为表达编码，e 为药物/剂量/时间编码，⊙ 为逐元素相乘，U 把低秩交互映射回基因空间。通俗解释：先学一种药通常做什么，再学当前细胞状态如何改变这种作用。共享分支不用测试药物真实均值；未知药物通过结构编码产生预测。

该结构是待检验的算法候选，不宣称已经具备原创性或优于现有模型。创新是否成立需要与最接近的方法进行结构、损失和评估层面对照，而不只是换名称。

训练损失以可观测连续 Δ 的平均 Huber 损失为主；方向辅助损失只在由训练侧对照噪声界定的非零效应上计算。损失权重 {0,0.1,0.3}；不在训练中把“输出像正常”强制作为普遍目标，以免模型没有学会药物作用就迎合预期答案。

重复测量质量用于训练样本权重的独立消融，权重由训练侧质量定义并设上限，不能按模型残差删除难样本。三初始化差异仅表征模型不稳定性，不直接称校准概率。

### 6.3 模型基线与原论文复现

按顺序比较：

1. 无变化 Δ=0、全局平均扰动、仅药物结构模型；已见药物场景另加训练侧药物条件均值。
2. 正则化多输出线性模型、小型非线性条件模型。
3. 上述共享效应+状态交互候选。
4. PRnet作为优先筛药流程原型，TranSiGen作为核心对照，XPert作为剂量时间覆盖充分时的较强对照 [R4,R5,R9]：先跑官方最小样例，核对输入单位、分箱、剂量时间、基因输出及检查点；再进入统一基准。先完成一个骨干的可信复现，不同时全面调优所有候选。

TranSiGen 是表达与化合物条件的生成式方法对照，XPert 是双分支 Transformer 对照。官方权重若见过本项目测试细胞或药物，其结果单列为“预训练暴露条件下”，不能放入严格未见主排名。无法核实预训练重叠则记未知；条件允许时在统一训练集重训，无需为公平而伪称不可追溯权重无泄漏。

路线二允许预注册的一次高能力诊断，即便小模型失败；之后按验证证据决定是否扩大，不因旧简单实现弱而关闭路线。

### 6.4 扰动泛化设置

| 场景 | 测试留出对象 | 结论范围 |
|---|---|---|
| B1 主场景 | 未见细胞/供体；测试药物在训练出现；处理重复与共享对照成组 | 新细胞状态下的扰动泛化 |
| B2 次场景 | 未见药物结构身份；细胞已见 | 新药物泛化，禁止同药盐型/别名跨侧 |
| B3 压力测试 | 未见细胞且未见药物，化学骨架留出另列 | 更强分布外条件，不与主场景混报 |
| B4 跨来源 | 冻结模型，在无重复来源的独立研究评价 | 平台与实验研究变化下的稳健性 |

主场景优先分组五折，内层三折。细胞数或条件覆盖不足时先形成可用性报告，另定预注册留一细胞方案，不能运行后降标准。全部剂量、时间和技术重复随留出对象成组；同一生物对象在多个资源的身份同步隔离。

不得把 GSE92742/GSE70138 的 accession 分开就自动称未见药物测试；不得把 ChemPert 中的同源 LINCS 记录当独立验证。

### 6.5 疾病签名与逆转评分

**首轮主版本：方向型疾病签名。** 在独立肿瘤/正常资源建立上调集 U 与下调集 D；预设校正 p<0.05 且 |log2FC|≥0.5，最多各取100基因，按绝对效应大小排序。进入可靠输出空间后每方向至少20基因，否则该签名不承担确认性主分析，报告实际覆盖并继续扰动预测任务。阈值是本研究设计选择，不是普适标准；全基因连续签名作为预注册敏感性分析，不能事后择优。

主评分采用固定的秩富集式双向逆转分数：疾病下调基因在预测扰动正向排序前部富集、疾病上调基因在负向排序前部富集时，分数更高。首轮定义如下：在固定的 N 个输出基因中，按 Δ 从大到小排序；对基因集 S，计算每个排序前缀内“已出现的 S 基因数/|S| − 已出现的非 S 基因数/(N−|S|)”。取绝对值最大的前缀差作为带符号的 ES(S)，正负极值绝对值相同时记0。最终逆转分数为 `[ES(D)−ES(U)]/2`，范围[-1,1]，越大越支持双向逆转。这是预注册的简化无权重读出，不冒充官方 CMap 归一化分数。相同 Δ 的基因作为一组，在同值组末尾评价前缀，避免基因名称决定排名；全零扰动得分为0。空集合或覆盖整个基因空间时记不可评价。优先复用可验证实现，并用完全逆转、完全同向、全零和并列值四种手算样例验收。

负余弦 `-cos(疾病签名, 预测Δ)` 作为透明基线，明确它主要测方向，不把它解释成恢复幅度。药物条件主版本固定24小时、10微摩尔且仅评价实测支持的面板；该条件只是体外基准，不是临床剂量建议。其他剂量与时间独立报告；没有该条件不擅自补值，剂量插值另登记。

**连续恢复距离为条件性扩展。** 只有疾病、正常和处理后表达位于可比尺度并存在独立测量支持时，才计算：

`恢复 R = [D(x,正常参照) - D(x + 预测Δ,正常参照)] / [D(x,正常参照)+ε]`。

D 为预先锁定基因集合上的标准化距离，尺度由训练/参照数据拟合；ε为固定数值稳定项。原本接近正常的样本不使用该归一化比值，另报绝对距离。芯片 logFC 与 L1000 标准化签名不直接相加；跨平台秩变换可支持方向匹配，却不能证明表达幅度恢复。

**正常功能影响**：优先在正常细胞/类器官有处理数据时独立评价；没有这类标签就报告未知。通路偏移或应激分数只能作代理量，不能称已证明无毒或选择性安全。

### 6.6 避免自我验证

不能用“模型预测恢复很好”作为模型恢复能力的验证。需使用未参与训练、选模的真实药物处理签名建立观测逆转分数，再对比候选排序。

- 扰动主要终点：以训练侧每基因尺度计算的 Δ 归一化均方误差，先按条件汇总、药物等权、细胞等权；相对内层选定基线的误差下降。
- 扰动辅助：Δ 的 Pearson/Spearman、方向准确性、重复一致性、差异基因恢复。未变化占多数时同时报告扰动特异信号；事后按真实差异基因评价标为辅助，不用于测试选模。
- 筛药主要终点：固定细胞—剂量—时间面板内，预测与实测逆转分数的 Spearman，细胞等权；至少5种可评价药物。
- 筛药辅助：前10%候选与实测前10%的重合、按实测逆转分数计算的选择损失、跨疾病签名和重复测量的排序稳定性。前10%按向上取整至少1药，同分规则固定。
- 外部表型：有药敏用响应排序；有分化、炎症或其他疾病功能测量用对应终点；绝不把未知药物当无效负样本计算分类AUC。

用相同疾病签名计算预测和实测分数可以检验扰动到筛药的计算保真度，但不能单独证明疾病恢复假设具有治疗意义。独立签名与外部表型承担后一层验证。

### 6.7 类器官应用与能力边界

现有 PDO 基线表达可用于候选生成；如没有 PDO 给药后表达，不能验证 PDO 扰动预测准确性，也不能宣称个体化正常恢复已经成立。

第一阶段允许：以独立疾病签名+PDO条件表达生成研究候选，清楚标为外推结果，并在已有表型面板做次要外部检验。PRISM/Kryeziu 表型不进入路线二主模型和评分权重调参。

若缺乏跨平台输入适配证据，先停在来源细胞系计算基准；仅适配器最小运行成功不足以解除该限制。无标签域适配可单列，但不得用校正把所有目标样本推向正常后宣称药物恢复。

### 7.2 首轮固定预算

- 单个训练任务以一张 RTX A5000 24GB 为资源单位，启动前实测环境；所有代码在 WSL2 Conda drugscreening-gpu。实测有两张可用 A5000 时可按卡分配独立任务，每卡至多一个正式训练任务；先检查 CPU、内存和 I/O 竞争，不因有空闲显存就追加任务。
- 内部种子固定20260922、20260923、20260924；划分种子20260922，二者独立登记。
- 每个可调模型每个内层训练最多20候选；主候选首轮12组：交互秩{16,32}、权重衰减{1e-4,1e-3}、辅助损失权重{0,0.1,0.3}。学习率1e-3、最大100 epochs、耐心值10；数值不稳定只在训练验证阶段按失败流程修订，不能看测试后更换。
- 选模按任务主要验证指标，基线使用同等候选上限。树模型不能仅用默认参数与调优网络比较。
- 官方模型先适配和最小样例；重训沿官方可复现配置，搜索上限相同但披露实际算力/参数量。不能声称试验次数相同就完全算力公平。
- 用户于 2026-09-23 已批准：单个正式 run（现有分折入口对应一个完整外折，含内层搜索与最终重训）上限为 **20 小时**；从该次进程启动开始计墙钟时间，不能从修订时刻重新计时。实验包累计上限仍为 **48 GPU 小时**，按各卡分配时长累加，含失败和重跑；长时间 CPU 验证占着专用 GPU 的时间同样计入，不能按显卡利用率打折。未知中断开销单列并预留保守余量。不得将同一工作拆成多个 run 绕过上限。
- 预计超过单 run 20 小时或包累计 48 GPU 小时时，先提交具体预算修订；达到上限应在可恢复边界停止，无法保存时也不得无限超时。监督模型可在已批准范围内调整队列，进一步增加资源上限须用户授权。OOM 不得静默砍样本、基因或种子。20 小时是停止上限，不是默认必须跑满的时长。

这些是已批准的首轮预算，不保证所有外部模型能在该预算重训；预计超过单次 20 小时或包累计 48 GPU 小时须另报修订。不能运行的臂标为资源受限，不能以未完成结果参与路线判决。

### 7.3 统计对象

药敏以患者/细胞为独立单元；扰动以生物模型为主要重采样单元，先汇总技术重复和药物条件，不能把数万表达行当独立患者。未见药物场景另按药物为主要单元；同时推广到新细胞和新药时增加双向分组敏感性重采样并说明依赖。

主分析逐种子计算每生物单元得分，再对其种子平均，配对2000次重采样得到95%区间。检验用固定单位差值的配对置换/符号翻转，默认10000次并作有限次数修正；不平均各种子p值。依赖交换性假设的检验需在记录中写明适用条件。

第3节及第13节的假设A1/A2/A3为路线一一个比较家族，假设B1/B2/B5为路线二一个比较家族，各自做Holm校正；不得事后拆家族保显著。假设B3的外部表型检验须待合格数据与终点锁定后另行预注册；假设B4暂为可选探索，可靠性模块公式与主要稳定性指标未冻结前不开展确认性检验。假设编号与第6.4节泛化场景、实验包编号分别记录，不混用。逐基因探索使用BH校正，结果只作探索。统计显著不等于实际用途已成立；前列选择损失、测量重复性和有效覆盖同时报告。

常数/缺失相关性记未定义；误差指标仍评价常数基线。模型间有效集合必须明确并一致，报告资格损失；不得静默取最有利交集。所有主要结果同时给出有效患者/细胞数、药物数和记录数。

## 8. 必做融合与外部验证边界

融合是两条路线之后的第三个必做问题：检验扰动信息是否提高同一类器官药敏任务的预测。允许后续执行，但方案总收口前必须完成至少一种事前锁定的架构及公平对照。启动条件是数据身份、输入尺度、上游预测和评价可复核，不要求两条单路线先得到显著正结果。负结果也应交付；若跨平台输入适配或预算不合格，登记具体阻断、解除办法并报告，融合保持未完成，不擅自取消。

- 串联：预测基因/通路扰动表示→药敏头；冻结与微调分开。不以3个摘要分数冒充完整扰动模型。训练药敏头使用训练折内部交叉拟合产生的扰动预测，避免样本内预测比部署预测更乐观；实测扰动输入仅作为单列的理想输入诊断，不能混入可部署模型结果。
- 并联：两分支均有有效输入和患者—药物交互；配置单路、等容量直接、扰动打乱对照。
- 联合：共享模型的辅助权重=0对照，药敏优化步数和选模预算一致；不因扰动批次多而多更新药敏。
- 每种新增监督均披露。用目标药敏训练融合后，它属于有监督表型模型，不再称路线二零药敏监督。

正式运行前由 Sol 监督模型锁定一个首轮架构、单路输入与输出头、训练侧交叉拟合方式、候选数、三种子、患者外五折/内三折、共同药物面板、50% 主标签档和患者内排序终点；预算沿用第 7.2 节。使用同一批测试患者做配对比较，至少包含直接药敏单路、扰动单路、融合、等容量直接模型和扰动打乱融合对照；各臂监督、调参机会及更新次数明确且可比。打乱在唯一生物对象层进行后映射其全部记录。主比较及多重校正家族在训练前锁定。25%/100% 融合学习曲线和第二种架构不是自动追加项，须有另行依据。

**2026-09-23 Sol / medium 协议纠偏（EXP-047 五臂强制输入合同）**：F-A 使用给药前 PDO 表达+药物结构；F-B 是扰动单路，使用药物结构+冻结的来源细胞交叉拟合扰动预测，不得输入 PDO 给药前表达；F-F 使用 PDO 表达+药物结构+同一来源扰动预测；F-C 为等容量普通直接分支；F-S 在融合架构内按来源细胞/扰动生物身份打乱特征。旧登记把表达仍放进 F-B 的版本不具备“扰动单路”比较，已由 EXP-047 记录和配置更正。参考细胞预测须审计来源细胞留出与检查点暴露；它本身不要求目标患者交叉拟合。患者条件扰动如作为独立扩展，则须按 PDO 训练侧患者折交叉拟合，且验证/测试患者不参与其训练、尺度拟合或选模。患者条件扩展不能替代必需 F-B。五臂尚未通过接口和预算门槛前不得训练。

### 13.2 路线一优先课题：少量类器官标签下的稳定适配

**问题**：同样少量的目标患者标签，是否必须更新整个来源模型，还是只调整少量参数就能更稳定地保留来源知识？

**研究假设A3**：在相同PharmaFormer骨干、来源检查点、患者划分和目标标签量下，受约束的小型适配器相对全参数微调，能提高目标患者的排序表现或减少跨初始化波动。本假设来自本项目小样本情形，是本次提出的扩展，不冒充PharmaFormer原文结论。

**最小算法改动**：设来源表达表征为h，目标表征为 `h' = h + W_up GELU(W_down h)`；初始化W_up为0，让适配开始时保持来源模型输出。冻结主体编码器，仅训练适配器及响应头；适配秩候选{8,16,32}。其余药物编码与交互骨干保持一致。现有低秩交互基线与该适配器不是同一个模块。

固定比较四臂：随机初始化同结构、来源冻结仅训练输出头、来源全参数微调、来源冻结加适配器。各臂使用相同来源预处理和相同目标监督；不得以不同基因集合制造适配收益。适配器与全微调使用同等搜索上限，记录参数量和实际运行成本，不要求把参数量人为做成相同。

主分析沿用50%目标训练患者档及患者内Spearman；25%和100%为学习曲线。A3加入A1/A2的同一确认性检验家族，不能另拆家族获得显著。报告对强基线的绝对增量、患者配对区间、训练成本与跨种子波动。参数更少但精度持平只能作效率观察；要声称非劣，须另行预注册有依据的非劣界值。

**同疾病迁移诊断**：用全部来源细胞、仅结直肠来源细胞、与结直肠来源数量匹配的其他来源子集作受控比较。来源子集仅由训练侧组织标签和固定种子选择，重复子集不当独立患者。数据量和组织匹配效应分开解释。该诊断不强制作为新主模型，也不根据目标测试结果选择来源子集。

只有适配器证据不足且存在明确迁移瓶颈时，再考虑CODE-AE式共享/私有模块。先比较共享编码、共享加私有两种结构；正交损失和域对齐分步消融。禁止一次叠加适配器、对抗训练、通路图和多组学后无法归因。

### 13.3 路线二优先课题：让扰动学习更贴近逆转筛药

**问题**：平均表达误差较小，不保证疾病相关基因的上下调顺序正确；后者可能更直接影响候选药排序。

**研究假设B5**：在同一事前固定的扰动骨干和训练数据上，加入基于真实扰动的双向基因排序监督，能够提高留出细胞中的逆转排序保真度。代表骨干按第 13.8 节从已有 TranSiGen/XPert 实现中核验选择，PRnet 为可选对照。借鉴 ExPO 的排序学习思路，但是否适用于所选骨干、是否改善疾病逆转，均须实测。EXP-039 目前的小型条件模型实验仅检验该骨干上的损失作用，不能替代代表模型统一比较。

实施分两步。第一步保持所选代表模型的原目标与原生输出，复用已有复现资产并完成新协议接口验证；第二步在相同骨干上比较原目标与附加排序目标。不得先改掉原生成目标，再把结果称为原方法复现。预测处理后表达时，按同一对照和可比尺度导出Δ；不能把Level 5 z分数当作Level 3表达差直接回填。

**新增损失的可执行定义**：只在训练观测中，按训练侧对照噪声确定可靠上调集U和下调集D。将真实Δ按训练侧基因尺度标准化为z。对U使用z，对D使用−z，分别经温度为1的softmax得到目标分布q；预测值按同一变换得到p。每方向计算交叉熵 `−Σ q_g log p_g`，再取两个可用方向的平均；少于2基因的方向跳过并记分母。新增损失为 `L原方法 + λ L排序`，λ候选{0,0.1,0.3}，不与多种新损失同时笛卡尔积搜索。噪声阈值、尺度及有效基因只由训练侧确定。附加方向损失是另一独立变体，不默认同时启用。

这里排序的是一次药物处理下的基因，不是患者的药物榜单；训练使用实测药物扰动，不强迫所有药物朝疾病逆转方向输出。独立疾病签名不进入该训练损失，仍可用于多个疾病签名的冻结读出。

**消融设计**：所选代表骨干原目标、同骨干加排序；小型条件模型的两种损失比较作为单列诊断。监督模型应在代表模型正式运行前核对两类实验的输入、候选预算与终点，若受资源或资产限制则明确列出未完成臂。这个“两个骨干×两种目标”的比较用于分辨收益来自架构还是训练目标，不把回归模型与排序优化模型的差直接归为架构创新。

**主要判定**：B5以第6.6节预测—实测逆转分数的药物排序为主要终点，纳入B1/B2同一比较家族。归一化Δ误差、基因方向、上下调排序为辅助诊断。误差改善而逆转排序无提升，只能支持扰动重建；逆转排序提升而总体误差变差，明确报告权衡，不声称全面优于原模型。基因NDCG可作为辅助，与本项目不将药物NDCG@5作为主要终点的决定不冲突。

### 13.4 路线二后续扩展：参照不确定性和暴露条件

首轮保持已锁定的逆转读出；不边换模型边换评分。若预测排序已可信，再检验正常参照是否导致候选不稳定。

一个可执行的探索版本：对疾病签名开发队列按患者配对重抽样200次，每次重建签名，并对同一药物预测计算逆转分数。报告均值与第10百分位，将后者作为保守排序候选。三初始化预测分别计算再汇总，不能将这200次当新患者。签名基因集不足时记失败比例；少于180次有效时，该药物不输出保守分数并计入覆盖损失。此处第10百分位是候选决策规则，不是校准的患者获益概率或95%置信下界。

该模块对应原假设B4，仍属探索；转确认性实验前锁定排名稳定性指标、覆盖要求和比较家族。不能仅因保守分数自带低波动就宣布更优，必须在独立实测逆转排序上检验选择损失。缺少独立正常参照时保持探索状态。

剂量—时间扩展只在数据包含足够条件覆盖时开展。ExPO/XPert式条件建模可区分同一细胞药物内的暴露插值与跨细胞外推；两者分别留出。首轮不强加每个基因单调变化，也不在测试中挑选使逆转最高的剂量后报告最优值。24小时、10微摩尔的固定基准仍保留，连续暴露另立协议。

### 13.5 融合借鉴BioGDR，但不改变路线二定位

满足第 8 节的数据身份、输入尺度、上游预测和评价可复核条件后，必须执行融合验证，不以单路线正结果或显著提升为条件。优先用以下三种输入分清扰动信息的来源：

1. 基础表达＋药物结构。
2. 在1上加入固定参考细胞的预测扰动，检验药物生物特征是否有用。
3. 在1上加入当前患者条件下的预测扰动，检验患者条件化是否额外有用。

文献中参考细胞上的扰动为第2类思路，不能写成已提供第3类证据。实际准入的比较臂使用同一药敏监督和相同输出头设计，增加扰动打乱与等容量对照；首轮基础融合不同时叠加额外激酶预测和通路图。通路迁移按第 16 节单独消融后再作条件性组合，该限制不取消通路研究。对各折的上游预训练暴露和交叉拟合按第8节执行。融合结果属于药敏任务，独立路线二的分子筛药结论不随融合成败撤销。

三种输入是输入信息的比较，不等于串联、并联、联合三种架构都已验证。五臂最低验收按本节及第 8 节的 F-A/F-B/F-F/F-C/F-S 定义执行。患者条件扰动须先核验类器官到来源模型的尺度适配；不合格时仍可完成合格参考细胞扰动的融合，但患者条件增量须标为受阻，不能拿参考细胞输入冒充。若有合格输入而仅因结果不显著，仍须完成已登记比较，不得取消。

- 历史 EXP-018 已做依赖辅助药敏实验：20 位患者、7 种已知药、单种子开发结果中，前三药排序质量 NDCG@3（越高越好）由关闭依赖监督的 0.67404 升至真实依赖监督的 0.67775，绝对差仅 +0.00371；仍低于药物均值基线 0.74755。它支持有限验证动机，未证明稳定或实用收益。来源为 `experiments/records/EXP-018.md` 和 `data/artifacts/EXP-018/bounded_development_aggregate.json`。
- EXP-030/035 的通用必需基因识别与患者间依赖差异是不同任务；高识别分数不等于个体化药敏有效。旧预测曾出现键值错位，个体化相关及置换统计仍受第三波审计限制，禁止复用旧显著性结论作为扩展门槛。依据为 `docs/reports/weekly_report_20260920.md`、EXP-035 记录及 `docs/reports/audit_repair_wave3_20260922.md`。
- [FORGE：Gene dependency-informed inference of response to targeted cancer therapies（Nature Communications，2026）](https://www.nature.com/articles/s41467-026-73977-2) 已研究依赖信息辅助药物响应建模。因此，“使用新数据”或“增加依赖预测头”本身不足以证明方法创新。候选贡献定位于同癌种类器官适配、群体共性与个体偏离的监督分解，以及对双路线融合的独立增量；均须通过对照成立。专项预登记中补充与 FORGE 的方法差异表；若复用其低秩联合建模作对照，必须在同一数据合同上评估，不直接比较论文分数。

### 15.2 模型接入与三个问题

首轮固定路线一已有 PharmaFormer 表达编码器及适配器接口，优先训练小型适配器、药敏头和两个域分别使用的依赖头。第一阶段用 DepMap 细胞系表达—依赖监督学习来源功能表示，同时保留实际来源药敏监督；第二阶段用 Nature 类器官表达—依赖监督适配，再结合获准的目标训练患者药敏标签优化药敏头，并保留来源药敏/依赖重放以检查遗忘。阶段长度、重放比例和冻结层在内层选模前登记；先验证这一顺序流程，不同时扩成多个训练策略排行榜。正式实施前核验接口，不因旧外层成绩挑选骨干；若不可接入，由 Sol 记录原因并在新外层评价前冻结替代方案。

训练时：两域表达经各自训练侧预处理后进入共享编码器/适配器，再连接药敏头（另接药物结构）、DepMap 依赖头和 Nature 依赖头；每条观测只计算其实际具备的标签损失。两个依赖头分别拟合本域量纲，通过共享表示迁移功能信息。Nature 辅助类器官与药敏目标类器官可以来自不同患者，不要求三种标签同时具备，也不制造假配对。推理时只需给药前表达和药物结构，无需新患者的基因敲除数据；两种辅助资源的价值在于改善训练，不是增加患者推理输入。

| 问题 | 假设与比较 | 可支持的结论 |
|---|---|---|
| D1：两域功能监督是否帮助药敏 | 无依赖、仅 DepMap、仅 Nature、DepMap→Nature 联合；加逐域打乱标签对照 | 区分来源知识、类器官适配、二者交互与额外表达/训练量的贡献 |
| D2：帮助来自共性还是患者差异 | 原始依赖、训练侧逐基因均值监督、减去该均值后的个体偏离监督 | 区分一般生存规律和患者相关信息，不预设偏离监督一定更好 |
| D3：依赖监督与扰动信息是否互补 | 直接模型/融合模型 × 无依赖/有依赖的四臂比较 | 分别估计依赖增量、融合增量及二者交互，不仅比较最终模型与最弱基线 |

首轮使用均等权重的缺失掩码依赖损失，按样本及有效基因数归一。D2 的均值只在对应辅助训练患者中估计；癌种分层与文库差异处理也只使用训练侧。可靠性加权属于后续条件性模块：先明确质量指标、训练侧估计方法及等权对照，再登记；不得按测试相关性筛基因或加权。

### 15.3 数据与泄漏门槛

1. 冻结来源版本、校验和、样本—患者—癌种—文库映射、基因轴及表达/依赖的含义和单位。原始文件只读，配对按键而非行序；保存写出读回核验。缺失依赖标签使用掩码，不填成无依赖。作者已取对数的表达不得再次取对数。
2. 首轮同时纳入 DepMap 细胞系与 Nature 类器官配对资源。Chronos 基因效应和 Nature 文库处理依赖值分别登记、在本域训练侧处理尺度、使用独立预测头；方向相似不代表量纲可直接合并。冻结明确的共同基因身份和覆盖规则，以其作为首轮可比输出轴，不能把不同域的原始数值直接相减解释迁移差异。任何标准化都不等同于已消除培养体系或测量流程差异。
3. 统一核验 DepMap、Nature 与来源药敏、目标药敏队列的生物身份和可能别名；不同编号体系的字符串不重合不能证明患者不同。不能确认的可疑重叠对象从相关辅助训练排除并记录。目标外层测试患者及其重复、配对样本不得以任何标签进入辅助训练；内层验证患者同样隔离。做来源冷细胞或跨研究未见细胞评价时，被留出的细胞也必须从 DepMap 表达重建、依赖训练及其预训练权重中排除；不能只隔离药敏标签。与来源药敏训练集的合法重叠允许联合学习，必须登记。EXP-030 的旧全源域权重不能未经暴露核验直接用于新留出评价。
4. 特征选择、覆盖阈值、基因均值/尺度、可靠性及表达归一化仅在对应训练侧确定；辅助验证按患者留出，辅助误差不替代药敏选模终点。有限基因集合可复用 EXP-018 的选择逻辑，但不能复用曾由全体目标样本选出的基因名单。
5. DepMap 来源端首轮使用准入后的跨癌种细胞系，Nature 适配端固定为准入后的结直肠癌配对类器官，以匹配目标癌种；记录各域癌种组成和患者/细胞数，域间任务权重不能由样本数自动决定。若声称“同癌种更有效”，必须追加预先冻结的等患者数量、相同基因覆盖与更新预算的其他癌种类器官对照；不足以匹配时明确无法支持该归因。历史 Zhu 跨癌种结果不能直接充当此对照。
6. 不把敲除效应与预测表达变化相乘当作药效标签或机制证明。路线二仍独立用真实药物扰动验证；基因依赖不替换该路线标签。药物靶点机制分析须先核验面板靶点覆盖，只对有依据的药物报告。

### 15.4 分阶段最小矩阵与扩展门槛

**阶段 D0：准入与预登记。** 复用已有资产和接口，在现有实验登记中分配可用编号，不在本方案抢占编号。建立独立实验记录、集中配置与正式产物目录；不复制旧训练脚本另起一套框架。预登记写全数据隔离、模型、对照、内层候选、统计家族、时间估算和停止条件，提交 Sol 启动审查。这里只补充方案，不启动训练。

**阶段 D1：必做的路线一最小验证。** 固定当前 50% 目标训练患者标签主档、原患者外折、14 药合同和三初始化；最终有效药物/患者范围按原合同确认。以下七臂必须使用相同骨干与药敏更新预算；其中 D-E/D-C/D-O/D-CO 构成两种依赖监督开/关的四种组合：

| 臂 | 训练内容 | 回答的问题 |
|---|---|---|
| D-A | 直接药敏模型，无新增辅助任务 | 原模型参照；仅协议和版本完全一致时复用已验收预测 |
| D-E | 两阶段均使用相同 DepMap/Nature 辅助表达重建，两域依赖损失为 0 | 额外表达与训练流程的参照 |
| D-C | D-E 加真实 DepMap 依赖监督，Nature 依赖关闭 | 细胞系功能知识是否可帮助类器官药敏 |
| D-O | D-E 加真实 Nature 依赖监督，DepMap 依赖关闭 | 类器官功能监督本身的贡献 |
| D-CO | D-E 加真实 DepMap 来源依赖训练及 Nature 依赖适配 | 两域功能监督的联合收益 |
| D-SC | D-CO 中只打乱 DepMap 依赖标签，保留真实 Nature 标签 | DepMap 的正确细胞—依赖对应是否重要 |
| D-SO | D-CO 中只打乱 Nature 依赖标签，保留真实 DepMap 标签 | Nature 的正确患者—依赖对应是否重要 |

D-E/D-C/D-O/D-CO/D-SC/D-SO 使用相同两阶段日程、两域表达样本、两个依赖头、药敏步数、各域辅助批次数、早停规则及匹配的候选配置表；改变的是相应依赖损失开关或标签对应。共享超参数与开关权重的搜索机会需配平，不能让联合模型获得额外搜索预算。打乱只在本域训练侧、癌种及适用文库分层内进行：DepMap 按生物细胞身份，Nature 按患者整组处理，保留重复和缺失结构；不可交换或无法等形映射的组须预先登记排除/处理规则和有效数量。药物均值及当前合格强基线继续报告，不能只与 D-A 比较。

四种监督组合分别报告 D-C−D-E（DepMap 单独贡献）、D-O−D-E（Nature 单独贡献）、D-CO−D-O（已有类器官监督时的 DepMap 增量）、D-CO−D-C（已有细胞系监督时的 Nature 增量），以及交互差 D-CO−D-C−D-O+D-E。联合臂有收益不自动说明两个来源都有贡献；互补主张需要相对两个单源的增量支持，“超出两者单独收益之和”还需交互差证据。

**阶段 D2：条件性机制消融。** D1 的内层药敏验证显示 D-CO 相对 D-E、D-SC 和 D-SO 的平均配对增量均为正、且多数内折方向一致，并通过来源能力保持检查时，才开展“共性均值监督/个体偏离监督”以及同癌种等量对照。分解在两域各自训练侧实施，固定另一域真实监督后逐域消融，避免同时改两域而无法归因。门槛在专项记录冻结，只用内层验证决定，不能读外层结果后挑模块；若不满足则停止扩模，仍完成 D1 所有臂的外层评价。可靠性加权仅在训练侧质量证据支持时再加一个等权对照，不一次叠加多个模块。

**阶段 D3：条件性融合扩展。** 与 D2 使用相同的事前内层门槛，且第 8 节融合输入准入后，完成 D-E、D-CO、无依赖融合、有两域依赖监督融合四臂；四臂使用相同两域辅助表达与训练日程，后两臂除依赖监督外结构一致。按配对患者计算两种架构各自的依赖增量，以及“融合中的依赖增量减去直接模型中的依赖增量”的交互差；不能以 D-A 替代 D-E 混入额外表达收益。原融合单路、等容量和扰动打乱对照继续保留，增强融合也须有对应容量/打乱对照，不能拿新增容量解释为功能信息。参考细胞扰动与患者条件扰动仍分别标明。D3 未触发不影响原 F 必做融合执行，也不能写成依赖增强融合已验证。

### 15.5 评价、预算与接受条件

- 主终点沿用路线一患者内药物排序的 Spearman 相关（越高越好），患者等权、同一有效集合配对；NDCG 等前列选择指标仅作预登记辅助，旧 NDCG@3 不与新主终点直接比较。另报逐药跨患者表现、来源药敏保持、覆盖及资源成本。依赖预测准确度仅作辅助诊断。
- D1 确认性家族包括 D-CO 对 D-E、D-C、D-O、D-SC、D-SO 及同监督药物均值的六项比较，统一做 Holm 校正；两个单源对 D-E、四组合交互差及 D-A 差值报告配对区间并标为探索性，不事后改为主要检验。若要将交互作为确认性主张，须在专项预登记及外层评价前纳入同一家族。D2/D3 若触发，同样先锁定比较家族。按第 7.3 节患者级配对重采样与有限次数修正执行，报告效应大小、95% 区间、有效患者数和种子稳定性，不把基因数或患者—基因行数当独立样本量。
- 对 D-E、逐域打乱和强基线的证据共同支持后，才能称联合功能监督有可靠药敏增量；是否优于两种单源按 D-C/D-O 比较另行判断。超过弱模型但未超过药物均值时，只能称局部改善。来源能力保持容许差须在专项预登记中依据原评价精度确定，不看目标外层结果设阈值。区间宽或跨零时记证据不足；高依赖分数本身不构成通过。

### 16.2 首轮结构及迁移策略

采用**已有基因表达骨干 + 小型通路分支 + 药物条件交互**：通路分支从有明确基因轴的表达输入出发，按冻结的基因—通路关系聚合，再用小型可训练映射形成每条通路的表示，结合药物结构预测对药敏的贡献。不能将骨干的任意潜在维度直接命名为某条通路；基因骨干保留未被通路覆盖的信息。

首轮使输出可分解为“基因骨干预测 + 各通路分支贡献之和”，各通路贡献显式依赖药物输入。它支持审计模型如何得到预测，但贡献受通路重叠和模型训练影响，不能解释为互相独立的生物作用。把通路分支移除、替换或打乱后须重新训练公平对照，不能只在推理时关掉分支就宣称其训练增益。

来源细胞系训练后，将同一通路映射及来源权重转入类器官训练侧，用轻量适配器调整；同时设置相同来源预处理但随机初始化的目标训练对照，区分结构先验与权重迁移。首轮不强制两域全部通路分布一致，避免抹掉真实类器官差异。只有训练侧证据显示特定迁移瓶颈时，再预登记“共享通路表示 + 体系特异修正”或对齐损失，与无对齐版本单独比较。

通路资源首轮优先复用已登记 Hallmark 版本并冻结覆盖规则；Reactome、KEGG 或 PROGENy 的表达足迹评分作为后续独立敏感性验证，不同时堆叠。通路基因表达聚合只是功能表示，不能无验证地称为实测通路活性；通路评分不能代替真实药物扰动或 CRISPR 标签。

### 16.3 最小实验及分步组合

使用路线一相同患者划分、50% 标签主档、药物面板和三初始化，药敏更新与候选预算匹配。预登记五臂：

| 模型 | 比较目的 |
|---|---|
| 原基因骨干 | 原方案参照，满足完整版本和协议条件时复用 |
| 基因骨干 + 等容量无通路分组分支 | 排除仅增加参数量/额外表达处理带来的收益 |
| 基因骨干 + 随机通路分支 | 匹配真实通路分支维度和稀疏性，检验生物分组是否有用 |
| 基因骨干 + 真实通路分支，来源预训练后适配 | 检验可解释通路表示及其泛化 |
| 相同真实通路模型、相同来源预处理、目标侧随机初始化训练 | 与上一臂比较来源权重迁移，而非混入预处理或结构差异 |

随机对照保留逐基因度数、通路大小、稀疏度、总体覆盖、映射初始化、参数量和优化步数；使用训练前冻结的三个随机映射，汇总全部随机映射分布，不能选最差对照。完整三图训练成本计入预算，不作为额外独立患者。真实通路集合、候选重要通路、基因覆盖和归因阈值不得依据目标测试结果选择。

最小验证后，若内层药敏表现相对等容量与随机结构均有正向配对增量、多数内折方向一致，且来源能力保持通过，才启动组合扩展；各内层数据和决策不可接触外层标签。先做“无/有通路 × 无/有 DepMap→Nature 依赖监督”的四组合，保持两域表达、训练日程及依赖头尺度合同一致，区分结构与标签增益。两类模块单独结果均完整保留；不得因组合效果选择性删除负结果。

随后按事前门槛接入原融合：在相同基因轴上分别构建给药前通路表示与预测扰动通路变化，验证其对融合的增量。路线二的通路变化须在独立实测扰动上检查，不能用基线表达的通路分数代替处理效应。代表骨干、无通路融合、真实通路融合、随机通路融合保持公平监督，沿用交叉拟合、单路与容量对照；组合未触发不取消原必做融合。

### 16.4 三层验收，分别给结论

1. **预测与泛化**：以未见患者的患者内药物排序为主终点；真实通路模型分别对等容量、随机通路、相同结构随机初始化模型和同监督药物均值作预登记配对比较并校正多重检验。报告区间、有效患者、来源能力保持及成本。若要声称少标签优势，需按冻结协议扩至 25%/100% 标签量；若要声称跨研究泛化，须完成相应独立范围的验证，已查看的历史队列另列。表示更接近或通路方向更一致不能替代药敏提升。
2. **解释忠实性与稳定性**：输出患者—药物—通路贡献及正负方向；检查贡献是否能重构模型输出，模型内通路遮蔽/替换是否产生预期变化，跨折和三初始化是否稳定，并与同大小随机通路遮蔽比较。遮蔽基准从训练侧确定，记录输入偏离原分布的风险和通路重叠；注意力权重或一张富集图不单独作为解释通过。跨体系比较须固定药物、归因参照和可比通路覆盖，训练侧提出保守/改变通路，留出样本检验并作多重校正；不要求所有通路方向一致。
3. **功能与机制支持**：用 DepMap 与 Nature 中未参与训练/选模的细胞或患者依赖观测，验证重要通路相关基因的功能关联；按生物对象留出，不能使用已作辅助监督的标签再称独立验证。通路均值、随机基因组及通用必需基因效应作为对照；基因敲除证据支持相关基因的功能，但未直接干预整个通路，不能据此断言完整药物作用链已证实。独立药物靶点或实测扰动证据可补充关联；确立因果机制仍需独立干预证据。

解释可信但预测未提高，可报告“解释有支持、泛化增益未建立”；预测提高但真实与随机通路无差别，只能归因于结构/正则化效果；两者及独立功能证据共同支持后，再提升机制相关表述。旧实验的代谢通路线索不预设为必然保守，也不据此在测试侧筛通路。
