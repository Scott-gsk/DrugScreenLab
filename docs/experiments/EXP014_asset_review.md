# EXP-014 公共资产获取审计说明

本说明只审计公共资产获取器的安全与可复现行为，不构成数据准入、训练或评测结论。

- 最终原始文件仅通过原子替换创建；已有最终文件只做大小与校验和验证，绝不覆盖。
- 传输使用同目录 `.part` 文件。接收首个响应头后立即写入 URL 和验证器元数据；读取中断后可留下可审计的部分文件。
- 续传必须同时满足：原 partial 的 URL 与验证器匹配、服务器返回 `206`、`Content-Range` 从当前偏移开始且覆盖声明的总长度、验证器未变化。任一条件失败均拒绝续传。
- 有 `Content-Length` 或 `Content-Range` 时，字节数不足会阻止最终文件生成。缺少验证器的完整初始响应可以原子封存，但其残留 partial 不可安全续传。

离线测试覆盖截断响应、ETag 改变、读取失败后的 partial 元数据、校验和不匹配、已有最终文件不覆盖、范围续传、幂等运行和路径穿越。Reactome/KEGG 等实际来源仍须由数据注册表的独立准入流程决定是否可用于研究。
