# 类器官跨模型迁移研究：阶段工作汇报

记录日期：2026-09-13。区分历史实验结果、当前数据建设与未完成研究；本报告不表示迁移方法已验证。

## 研究目标与执行偏差

原方案要求先完成不依赖功能数据的单药基线，再逐项加入三篇Nature资源，比较N0—N5独立增益。本轮完成了较多数据与评测建设，但没有及时交付新的真实模型训练结果。将多个资源的审计串行化、没有及时切换已允许的备选源域，是执行安排的问题。辅助数据未就绪不应阻塞全部直接药敏基线；患者泄漏和标签身份问题仍必须解决。

## 已有训练结果（EXP-013历史协议，不能当作EXP-014结果）

来源：data/artifacts/EXP-013/mcrc_pdo_b0_b1.json。

| 项目 | 结果 |
|---|---|
| 数据 | 52患者分组、91 PDO、49药、3268响应 |
| 模型 | 训练患者逐药均值B0；512变异基因、alpha=10的逐药Ridge B1 |
| 划分 | 患者分组五折，固定参数，非新合同的5×3嵌套搜索 |
| B0患者内Spearman | 0.7860 |
| B1患者内Spearman | 0.7648 |
| B1−B0 | −0.0212 |
| 当前可支持判断 | 旧协议下表达Ridge没有显示患者内排序优势，药物主效应需要严格控制 |

旧产物中的逐药增益、置信区间与INDIVIDUALIZED_SIGNAL标签不能作为新研究的有效结论：逐药重采样实现存在问题，跨折汇总的均值基线也受折间差异影响。旧NDCG与新合同定义不同，需版本化更正。以上描述性数值保留历史身份，不代表对新清洗数据的复现结果。

## 本轮完成的工作

- 保全原工作、登记EXP-014及原文方案，保留旧实验与原始数据。
- mCRC重建：92个表达PDO中91个有药敏配对，52个患者前缀分组、48种当前可处理单药、3183响应；部分患者关系待来源核验。原始表的立体结构信息纳入新药物映射。
- 建立SMILES规范化、保留手性Morgan指纹、训练折内表达预处理、Hallmark/Reactome/KEGG先验资源和登记驱动读取接口。
- 实现患者等权排序评测、患者整块bootstrap、双编码器与归因基础接口、准入检查和5×3嵌套基线运行器。
- 完整测试117项通过，数据登记验证PASS；后续新增两项回归测试，基线专项4项通过。测试通过不等于模型有效。

## 纠偏后的近期交付与验收

1. 聚焦一个PDO开发队列准入，解决患者映射和单药结构边界；保留不确定样本审计，不因突变表缺行选择性删除患者。
2. 不等待全部Nature资源，完成真实B0/B1/M1；GDSC2通过来源审计后衔接M2/M3与N0。CTRP解析并行，不能成为唯一源域瓶颈。
3. 每个实际实验交付冻结配置、患者划分、OOF预测、患者等权指标、配对区间、计算成本及首版解释；阴性结果同样汇报。
4. Nature资源并行建设，达到各自角色准入后按N1—N5加入；每项必须报告独立增益，不能只报告下载量或辅助任务准确率。
5. 未见外部队列、完整解释验证与论文材料仍未完成；不提前宣称论文就绪。

本周可汇报的实质内容是历史强基线的不足、数据质量发现与修复、可复用训练评测闭环；新的迁移性能结果仍为明确欠交付项。
