# EXP-015 低自由度残差诊断结果

真实运行产物：`data/artifacts/EXP-015/zhu_residual_v3/`。20 位患者、严格源域已知 7 药、5 个患者外折、2000 次患者 bootstrap；来源模型、目标回执和 OOF 输入均 SHA-256 绑定。

| 方法 | NDCG@3 | 相对冻结来源预处理目标模型 |
|---|---:|---:|
| 线性校准 lambda=0 | 0.561 | -0.183，95% CI [-0.247,-0.121] |
| 校准 + 残差 lambda=0.1 | 约0.740 | 约0 |
| 校准 + 残差 lambda=1 | 约0.737 | 约0 |

单独来源分数校准明显低于目标训练模型；五个外折的非负来源校准系数 `a` 均为 0。小权重残差可恢复到接近冻结来源预处理对照，但这个恢复来自目标残差项，不能解释为保留了来源知识，也没有证明超过 M1_source_scaled 或 B0。当前证据只支持“来源分数在该开发队列中没有可检测的正向贡献；限制来源项可避免其拖累”的判断，尚不支持迁移成功。

该结果是开发队列探索证据，不是独立验证或已证明算法创新。严格已知药物只有 7 种，所以只报告 NDCG@3；lambda 未根据测试结果选择。残差是样本表达和药物指纹的加性模型，其中样本加性项在同一PDO内排序时抵消，不能把性能称为个体化表达恢复或机制解释。
