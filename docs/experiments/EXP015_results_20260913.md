# 本周算法工作：已训练模型、迁移可行性与Nature功能资源

## 实际完成

原方案主线保持为细胞系→PDO单药排序；本轮用已有公开配对肝胆PDO替代尚缺配对表达的胰腺优先队列，开展固定参数探索实验。没有将mCRC旧结果重命名为新结果。

- 来源训练：963个细胞系，219个结构唯一药物，179410条唯一来源响应。80/20生物模型分组，实际训练143474对，早停验证35936对。
- 双编码器：512基因→32→32；2048位手性Morgan→32→32；拼接表达、药物及逐元素乘积→32→1。87233参数，Huber+患者内成对排序，CUDA分组小批量。50epoch上限、实际21epoch（恢复验证最优权重），训练85.45秒；来源开发验证MAE0.0522。该验证用于早停，非独立测试。
- 目标训练：20个PDO分组，先跑33药版本，再依作者货号一对一连接补齐为54药、1080对。两个版本各完成3个目标种子×5患者外折×3个训练模型（M1、M1_source_scaled、M3），合计90个目标模型拟合；M2仅冻结预测，B0为训练患者逐药均值。不能把M2保存副本算成新训练。
- 同一个来源权重用于全部目标种子。目标种子同时改变划分与初始化，不是3次独立来源预训练。
- 保存源模型及所有目标fold权重、冻结变换、训练历史、OOF预测、配对指标、模型推理接口；已对一个M3外折的4个未见PDO实际生成33药排序及12个预测后Top-3归因。

## 药敏迁移结果

54药目标版本与来源完整InChIKey严格交集7药；以下仅为这7药的NDCG@3，不能替代原方案≥10药的主NDCG@5。

| 方法 | 三个目标种子的患者等权NDCG@3 | 平均 |
|---|---|---:|
| B0训练患者逐药均值 | 0.738 / 0.748 / 0.752 | 0.746 |
| M1仅PDO，目标折内预处理 | 0.703 / 0.670 / 0.681 | 0.684 |
| M1_source_scaled仅PDO标签，来源冻结预处理 | 0.744 / 0.740 / 0.731 | 0.738 |
| M2来源权重直接预测 | 0.560 / 0.560 / 0.560 | 0.560 |
| M3来源权重初始化后PDO微调 | 0.675 / 0.669 / 0.680 | 0.675 |

M3−M1的各种子患者配对95%区间均跨0；M3−M1_source_scaled的前两个种子区间分别约[-0.135,-0.001]和[-0.139,-0.008]，第三个跨0。这里是开发患者的探索分析，未校正多重比较，不作确定性负迁移机制主张。

可支持的结论：训练与推理链条可运行；当前低容量直接微调没有证明迁移优势。冻结来源预处理的目标模型比原生目标预处理模型表现更好，但两者仍未超过均值基线。预处理差异与权重迁移必须分开评估。

不能支持：已证明细胞系→PDO有效、可临床使用、已实现新颖算法贡献。FPKM原尺度目标与logTPM来源存在明显量纲/平台差异，旧来源结构缓存可能丢失立体信息；这些是下一轮明确诊断的问题，而非把本次结果写成整条路线无效。

## 2026 Nature功能库：真正取到、配对并训练

官方补充包41586_2026_10830_MOESM3_ESM.zip已取得，SHA256为7e83b7551c9c272de0bc0455ea9a0e7803a8043d15d9cfedf5a1c3e609a2a6e2。表6真实类器官依赖与表2患者映射、表达精确配对：162模型、157患者、16562依赖基因。16模型有双文库，不可当独立模型相加。此前930模型比较矩阵没有被误用于本实验。

F0固定单minLib文库、Colorectal子集：59模型、57患者，35训练患者、11验证患者、11测试患者（测试12模型）。训练折选512HVG和128高变异依赖基因；比较均值、Ridge(alpha10)与小MLP，缺标签掩码，测试不参与选基因/早停。

可支持的结论：该子集上，小样本表达模型未超过依赖均值，表达置换变化小，尚无强个体化依赖预测信号。不能推断全资源无用，也不能由辅助任务成绩推断药敏迁移增益。后续应检验功能表示/通路及容量匹配对照，而非直接把原始依赖标签全部加入药敏模型。
