# 同疾病域差异与基因依赖能力分析（EXP-035，工作包 F 收口）

> 版本 v1（2026-09-22）。状态：完成；本报告含一项对 09-21 版 F2 结果的关键审计修复（见第 7 节）。未经独立审查。

## 1. 研究问题与预先假设

1. **F1 同疾病域差异**：控制疾病构成（同为结直肠）后，细胞系与类器官之间的哪种差异仍然存在？这些差异与预测误差是否相关？
2. **F2 基因依赖三层次**：基因依赖任务在①通用必需基因识别、②癌种/谱系依赖、③**同癌种同一基因在不同患者间的变化（个体化能力，核心）**三个层次上，信号分别有多强？模型与数据分别构成什么限制？
3. **F3 归纳偏置与学习曲线**：在当前输入和划分下，逐基因独立模型、低秩多任务、非线性共享表示、固定通路结构四种归纳偏置，谁在学习曲线上表现更好？固定通路结构是否带来超出等规模随机分组对照的增益？

本实验为工作包 F（阶段 6）唯一正式实验；预登记协议见 `experiments/records/EXP-035.md`，此前所有判定句子均以该记录为契约。

## 2. 数据背景及实际使用范围

| 资源 | 角色 | 本次使用规模 |
|---|---|---|
| GDSC2 v2 | 细胞系表达（源域对照） | 963 株全癌种；结直肠（COREAD）46 株 |
| Kryeziu mCRC PDO | 目标域表达（白名单强制） | 51 患者 / 60 PDO |

标签说明：基因依赖标签为类器官 CRISPR 依赖分数（Chronos 类），与药敏（DSS/1-AUC）是不同任务，结论只在依赖任务内使用。

## 3. 输入、标签、划分和模型

- 表达输入统一为 14,900 共享基因、域内逐基因 z-score（EXP-029 约定）；距离 = 1−Pearson。
- 划分：EXP-030 individual 整组 5 折（依赖任务）；F1 域分类为 5 折分层（置换基线 100 次）。
- 模型：F1 用无监督 PCA(50)+平衡逻辑回归（域分类）与 PCA 共享/私有分解（重建诊断）；F2 引用 EXP-030 ZS（来源冻结 ridge）与 HD（目标域从零多输出 ridge）预测；F3 训练逐基因 ridge / 低秩多任务 / MLP 共享表示 / 通路掩码 + 等规模随机分组对照，25%/50%/100% 训练患者档位。

## 4. 基线、主要比较及指标

- 域分类：**平衡准确率 + 置换基线**（修正此前"无基线数字"问题）。
- 误差关系：逐样本零样本 Spearman 与最近距离的 Spearman 相关（2000 次患者/样本 bootstrap 95% CI）。
- 依赖任务：逐基因折内/合并 Spearman（患者先聚合再跨患者），置换检验 100 次，必需 vs 可变基因分层。
- 全部 bootstrap 为对既有结果的重采样，不重训模型。

## 5. 结果

### 5.1 F1 控制疾病构成的域差异（f1_summary.json）

| 分析 | 结果 | 解读 |
|---|---|---|
| 同癌种域分类 | 平衡准确率 0.903；置换基线均值 0.499、p95 0.588（p=0） | 同癌种下域差异**显著存在**且能被稳定分类 |
| 对照：泛癌设定 | 平衡准确率 0.356 | 不控制癌种时反而低于机会水平，无法分离 |
| 对照：原始 log2 表达 | 1.0 | 平台差异本身足以完全分离（预期内，非生物结论） |
| 距离 | Kryzei→GDSC COREAD 中位 0.845（GDSC 内部 0.492） | 控制癌种后距离差异仍大 |
| 关键对照：跨研究细胞系 | DepMap-CRC ↔ GDSC-CRC 中位 0.980，**大于** PDO→细胞系 0.845 | 平台/文库/培养混杂；**无法把距离独立归因于"类器官"生物差异** |
| 预测误差-距离相关 | 样本级 rho 0.025/0.137、患者级 0.060/0.113，CI 全跨零（Holm 1.0） | **距离不解释零样本误差**，不宣称"距离导致失败" |
| 表示重建（模型诊断量） | 共享子空间重构方差贡献：GDSC 0.893 / Kryzei 0.523 / biobank 0.752 | 两域在共享空间的重构比例有差距，但口径仅限该分解模型 |

## 6. 解释、限制与失败分析

1. 三个问题各自的回答集中表述一次：
   - **F1**：控制疾病构成后仍存强的域差异（平衡准确率 0.903），但该差异无法与平台/文库混杂分离（跨研究细胞系对照距离更大），且**与零样本药敏误差无相关**——分布距离不是当前迁移失败的可操作原因。
   - **F2**：个体化依赖信号存在（ZS 0.023，置换显著），但强度低、集中于必需基因、仅 5-6% 基因逐基因稳定；目标域从零训练（HD）不承载跨折稳定的个体化信号。数据层面主要限制=同癌种患者数（83 人）与逐基因噪声。
   - **F3**：可用表现参照：当前输入与模型家族下 100% 档 0.03 左右（必需基因 0.05-0.09）；固定通路归纳偏置不提供增益；提升方向不来自架构偏好，而需更大的同癌种患者样本或更强的基因级先验。
2. 限制：类器官依赖图只含 85 结直肠模型（83 患者），卵巢 11、胰腺 4、胃 3 例，小癌种数字只作线索；F1 距离与误差相关的检验单位已分别按样本级与患者级报告。
3. 失败条件核查：带基线口径（置换基线）已按预登记执行；通路类结论只报线索级、未升级。未触发失败条件。

## 7. F2 关键审计修复（09-22，归档被替换数字）

**问题**：EXP-030 `predictions.parquet` 写入时，`sample`/`gene` 标签按 sample-major 排列、`predicted`/`observed` 数值按 gene-major（k = g×n_te + s）排列；09-21 版 F2 按标签重建矩阵，混入跨基因协方差，产生系统性伪相关。

**验证**：按书写行序重建后，与 EXP-030 内存口径（arm_summary.json）**逐折精确一致**（HD 13 位小数内 0.0321、ZS 0.0294）；按标签重建则得到污染值（HD 0.441、ZS 0.358）。另校验 EXP-032 `predictions.parquet` 与 l3_summary 一致（0.453/0.675 vs 0.455/0.685，聚合口径差），F1 不受影响；F3 数据源独立。

**归档（09-21 污染版关键数字，不再作为结论）**：层3 HD pooled 0.458 / 折内 0.441 / CI>0 98%（13,265/13,539）；ZS pooled 0.376 / CI>0 79%；层2 分癌种宏平均 HD/ZS 0.27~0.46；谱系基因 AKAP7、AKNAD1、PSMB9 等清单作废。EXP-030 自身全部结论基于内存口径，不受影响。
