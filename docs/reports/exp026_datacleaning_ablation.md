# EXP-026 数据清洗消融报告（4 维度 × 3 版本）

日期：2026-09-19 ｜ 状态：预登记分析完成，供收口与 EXP-027 合同固定使用

## 一、结论（先读这里）

在同一测试协议（52 患者外层 5 折、患者隔离、非结构药子集 NDCG@5 主终点）下，
对 4 个数据清洗维度做了单变量替换消融，共 10 个配置 × 2 类模型
（确定性 Ridge + 3 种子小 MLP）：

1. **基因空间**：把输入基因从 2000 个高方差基因扩到全交集 19091 个，MLP **显著变差**
   （患者级 bootstrap 差值 -0.0059，95% 置信区间 [-0.0115, -0.0004]，不跨零）；
   收缩到 Hallmark 通路基因 4376 个无差异。**维持 2000 基因方差选择合同**。
2. **归一化**：z-score、分位对齐、秩变换三者无差异（置信区间全部跨零）。
   **维持 z-score**，无需复杂化。
3. **通路压缩特征**：ssGSEA 50 维、Reactome 主成分 64 维、PROGENy 式 14 维，
   与 2000 基因直接输入相比 NDCG 均无差异；但压缩特征存在数值稳定性代价
   （详见第四节）。**主特征维持基因直接输入**。
4. **响应口径**（唯一正向维度）：训练时把药物响应换成「逐药标准化」或
   「减训练折药均值的残差」，MLP 非结构 NDCG@5 从 0.8424 升至 0.8539 / 0.8590，
   逐药跨患者 Spearman 从 -0.007 升至 +0.145 / +0.122——是全部 10 个配置中
   唯一出现明确正向个性化信号的维度。但 bootstrap 置信区间仍跨零
   （[-0.0103, +0.0339] / [-0.0037, +0.0357]），**按预登记口径不能宣称显著，
   作为候选改进臂带入 EXP-027 正式对比**。
5. **Ridge 对数据清洗完全不敏感**：10 个配置的非结构 NDCG@5 全部落在
   0.8417（逐药标准化 0.8421），与 B0 药物均值参照（0.8421）几乎重合，
   bootstrap 差值精确为 0——线性模型的患者内药物排序由药物主效应主导，
   数据清洗无法改变它。这与 EXP-026 前置审计（交互项方差仅 35.8%）一致。

## 二、实验设计（预登记，先于结果）

| 维度 | 版本 A（基线） | 版本 B | 版本 C |
|---|---|---|---|
| 基因空间 | 2000 高方差基因 | 全交集 19091 | Hallmark 并集 4376 |
| 归一化 | z-score | 分位对齐 | 秩变换 |
| 通路特征 | 基因直接输入 | ssGSEA 50 维 | Reactome 主成分 64 维 |
| 响应口径 | 原始 DSS | 逐药标准化 | 训练折药均值残差 |

注：通路维度内部以 ssGSEA 为版本 A（B=Reactome 主成分、C=PROGENy 式）；
PROGENy 式为 14 条经典信号通路的 Hallmark 映射基因均值，映射表预登记于脚本。

- 每配置只改一个维度，其余与基线一致；Ridge 确定性 1 轮，MLP 3 种子。
- 防泄漏纪律：方差选择、归一化、主成分、响应变换全部只在训练折拟合，
  测试折仅变换。
- 终点：`evaluate_stratified` 三分层终点（非结构 NDCG@5 主终点 +
  逐药跨患者 Spearman + 全面板参照）；患者级 2000 次配对 bootstrap。
- 运行：733 秒，5 折全部完成，无缺失值。

## 四、异常与机制（如实报告）

1. **全交集 MLP 预测尺度发散**：19091 维输入下（73 个训练样本对约 19000 个
   输入维度，参数样本比约 1:480），MLP 优化不稳定，预测最大值达 2400
   （观测上限 43.7），各折均出现。排序型指标仍可计算，但该配置 NDCG 同时
   显著变差，方向一致。判定为高维小样本的真实代价，非实现缺陷。
2. **通路压缩特征的外推放大**：Reactome 主成分与 PROGENy 式特征在部分测试
   患者上出现大幅外推（主成分配置预测达 ±1700）。机制：测试折个别患者在
   训练折拟合的标准化空间中处于远端，特征值被放大后传入模型。预处理已按
   防泄漏纪律只在训练折拟合（含主成分分量标准化），此前冒烟检查发现的
   未标准化 bug 已修复，剩余漂移属真实分布外推。后果：Reactome 主成分配置
   的 Ridge 逐药 Spearman 塌缩至 0.001。
3. **B0 逐药 Spearman 为负的伪影**：B0 用「训练折（=全部其他患者）的逐药均值」
   预测测试折患者。同一药物下，若某折患者观测偏高，其余患者的均值必然被拉低，
   预测与观测产生系统性负相关（-0.244）。这是折互补均值的固有伪影，不影响
   配对对比（各配置预测结构相同，伪影在差值中抵消），但 B0 该列不能当作
   个性化零基线的精确零点。
4. **逐药标准化配置的 Ridge 差值非零（0.8421）**：标准化仅改变拟合目标的
   尺度，Ridge 排序本应不变；微小差异来自标准化后正则化等效强度变化，
   幅度可忽略。

## 五、数据合同固定决策（本消融驱动）

| 合同项 | 决定 | 依据 |
|---|---|---|
| 基因空间 | 维持 top-2000 训练折方差选择 | 扩交集显著有害，收缩无增益 |
| 归一化 | 维持 z-score（训练折拟合） | 三种归一化无差异 |
| 特征族 | 维持基因直接输入为主特征 | 压缩特征无增益且有稳定性代价 |
| 响应口径 | 逐药标准化/残差变换进入 EXP-027 候选臂 | 唯一正向维度，CI 跨零待验证 |
| 通路特征 | ssGSEA 仅作可解释性辅助视角 | 无预测增益，不进主特征 |

## 六、限制

- 52 患者样本量下，bootstrap 区间宽度约 ±0.02，正向信号（+0.012~+0.017）
  无法在本波内达到显著；这是样本量约束，不是分析缺陷。
- MLP 为固定超参（h64 depth1，与 EXP-024 一致），未做超参搜索——预登记纪律，
  不用测试结果调参。
- 全交集配置的优化发散提示：若未来扩展基因空间，需先解决正则化或降维。
