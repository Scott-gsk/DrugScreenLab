## 三、口径说明

1. 非结构 NDCG@5：剔除 7 个结构药后每 PDO 5-7 药排序（资格 ≥5），
   B0 在此口径下仅剩药序记忆成分。**已逐 run 精确复现官方 metrics.json
   的全面板 B0（容差 1e-9）**；EXP-020 Stage1 管线的 0.9089 与 b2000
   官方迁移管线的 B0（0.8917~0.8932）来自不同 split 版本与聚合管线，
   本表参照列与重打分同管线（后者）。
2. 逐药跨患者 Spearman：主方案 §三.3 患者间差异度量。**重要口径限制**：
   B0 的折常数预测得到 −0.26 的稳定负值，机制为有限总体补集效应
   （某折训练均值偏高 ⟺ 该折测试患者均值偏低，机械负相关），并非
   「B0 学到反信号」。因此该端点**只用于模型间相对比较**，不作绝对
   个性化量度；M3（0.16）> M1_source_scaled（0.11）> M1（0.09）的
   排序仍有效，但与 B0 的差值高估了个性化成分。
3. 全面板 NDCG@5：官方资格（已知药 ≥10/PDO）。
4. 误标重复轮 run_b2000_seed2 仅用于交叉验证，不计入种子聚合
（沿用 EXP-021 修正口径；其 B0 与 seed 20260912 完全一致，交叉验证通过）。
5. 增益波/联合 parquet 为 51 患者口径（官方 run 52 患者，第一波已知
   admission 口径遗留）；涉及 B0 的配对比较一律在同 parquet 内重算 B0，
   消除跨版本偏移。

## 四、结果判读（EXP-026 重打分核心发现）

**核心发现：第一波「全部变体证据不足」的结论在非结构药子集口径下部分翻转。**

1. **M1_source_scaled（GDSC 源域缩放迁移）vs B0：+0.0186
   [+0.0001, +0.0391]，CI 不跨零**——非结构药上出现第一波全面板口径
   未能分辨的正增益。逐种子方向一致（0.8604±0.0024 vs B0 0.8413±0.0004，
   差值远超种子波动）。**限制**：CI 下界 +0.0001 极度贴近零，
   判定为 EXPLORATORY-POSITIVE，需更多种子与重抽样次数复核，
   不作为已确立结论。
2. **pathway_pca_best_reg vs B0：+0.0066 [+0.0005, +0.0133]，CI 不跨零**
   ——与 EXP-024 患者级 +0.0054 的方向与幅度一致，非结构口径下更清晰。
   该家族的患者级正信号在两种口径下一致出现。
3. **M3 vs B0：+0.0145 [−0.0086, +0.0366]** 跨零但方向为正、幅度是
   全面板口径（+0.0016）的 9 倍——微调迁移的信号被旧尺子压缩了约一个
   量级，但仍未达统计门槛。
4. **M2 显著负（−0.0409 [−0.0727, −0.0067]）** 与第一波一致：零样本
   直接预测在非结构药上同样失败。
5. **逐药跨患者 Spearman 全体低弱**（最好 M3 0.16）：任何模型的
   患者间个性化信号都微弱，与方差分解（交互项 35.8% 含噪声）一致。
6. 联合臂（EXP-025 joint）非结构 0.8337 低于所有直接臂，与
   DO_NOT_EXPAND 判定一致。

**对第二波路线的直接影响**：① EXP-027 路线对比应将 M1_source_scaled
与 pathway_pca 家族列为路线 A 的代表臂；② EXP-028 融合的基线应以
