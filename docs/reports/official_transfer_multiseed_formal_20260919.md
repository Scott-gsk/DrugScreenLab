# GDSC→Kryzei 官方迁移多种子正式汇总（EXP-021，2026-09-19）

## 结论（先行）

在 3 个真种子（20260912 / 20260913 / 20260919）、bootstrap=2000、EXPLORATORY_TRANSFER_ONLY
口径下，**没有任何迁移变体相对对照证明增益**：

- **M1（原生迁移）与 M3（迁移校准）**：三种子逐种子与三种子合并的患者级
  ΔNDCG@5 95% CI **全部跨零** → 一律判定「证据不足」，不得宣称增益。
- **M2（固定源模型直接排序）**：相对 B0 与相对 M1_source_scaled 均为
  **显著负**（合并 CI 完全位于零以下）。
- 按 EXP-021 预登记失败条件：三真种子汇总后各迁移变体 Δ 的患者级 95% CI
  跨零或为负 → 判定**当前 GDSC→Kryzei 官方迁移未证明增益**，停止在该协议
  下追加种子（除非新假设另登记）。

M3 是唯一点估计方向上有微弱正信号（vs B0 合并 +0.0016）的变体，但幅度
（≤0.006）远小于 CI 半宽（~0.014），种子间方向不稳定（+、−、+），证据不足。

## 口径

- **协议**：官方 `scripts/run_transfer_experiment.py` →
  `drug_screen.transfer.transfer_experiment.run_transfer_experiment`，评价协议
  `pdo-transfer-v2`（`drug_screen/transfer/metrics_v2.py`）。本汇总的患者级
  bootstrap 完全复刻官方实现（PDO 内 NDCG@5 → 患者内平均 → 患者宏平均；
  以患者为单位有放回重采样 2000 次，2.5/97.5 分位，rng seed=0），并与各 run
  `metrics.json` 官方 bootstrap 结果**逐位一致验证通过**（点估计与 vs
  M1_source_scaled CI 全部 match，见
  `multiseed_summary_20260919/patient_level_bootstrap.json` 的 `validation` 节）。
- **主指标**：known 源域药物（14/48 药）上的患者宏平均 NDCG@5；每 PDO 需
  ≥10 个 known 药物才纳入 NDCG@5（5–9 药 PDO 只计 NDCG@3，不进本主指标）。
  评价覆盖 52 患者 / 91 PDO / 14 known 药（每算法 known 行 947；52 患者全部
  有 NDCG@5 eligible PDO）。
- **bootstrap**：FORMAL_2000（2000 次），患者级配对（candidate 与对照共享
  同一患者重采样索引）。
- **对照**：B0（目标域训练折药物均值）为主对照；M1 另报 vs
  M1_source_scaled（官方 comparator，源尺度预处理公平性对照）。
- **种子**：从各 run `frozen_config.json` 的 `config.seeds` 与预测文件算法
  标签双重核验（不信目录名）：20260912 / 20260913 / 20260919。
  `run_b2000_seed2_20260918_223331` 核验为 seeds=[20260912] 重复轮（误标
  目录，见 `_MISLABEL_NOTE.md`），**排除**。
- **源模型**：三 run 共用同一 GDSC EXP-015 冻结源（frozen_run.json
  sha256=3f3076b3…，source_model.pt 3069d881…，expression_transform.npz
  dc69e10b…）；仅外层折划分（患者 5 折）随种子变化。
- **合同版本说明**：前两种子（20260912 / 20260913）跑于 DRAFT 合同期，
  seed 20260919 跑于其后；三者的外层折划分方式与基因合同
  （n=19091，gene_order_sha256=0fd5fdd7…）与 FROZEN 口径一致，冻结仅为
  增量 val 物化，不影响训练/评价路径。
- **算法定义**（按 EXP-015 与 runner 代码）：B0=目标训练折逐药均值；
  M1=目标域原生预处理+随机初始化训练；M1_source_scaled=冻结源预处理+目标
  标签训练；M2=固定源模型直接排序（**不做目标域训练**，其预测与种子无关
  ——三种子 NDCG@5 完全相同 0.8517 即为此因，逐种子 Δ 的微小变化来自对照
  随折划分变化）；M3=源权重初始化后目标域微调。
- **三种子合并方法**：每患者先取三种子逐患者 Δ 的平均（52 患者全部三种子
  有定义），再对该患者池（n=52）做患者级 2000 次 bootstrap。该法保留患者
  聚类结构、把种子间变异平均入患者内；不做 (seed, patient) 混合重采样。

### 种子间一致性

- **M1**：方向不稳定（−、+、−，幅度 -0.0170 ~ +0.0073）——种子间变异与
  点估计同量级，无一致方向。
- **M2**：三种子一致显著负（Δ ≈ -0.04），且其预测本身不依赖种子（固定源
  模型零样本），负向结论稳健。
- **M3**：方向小幅波动（+0.0020 / -0.0035 / +0.0062），全跨零；合并 +0.0016
  仍远小于 CI 半宽。
- **B0 与 M1_source_scaled**：三种子点估计稳定（0.892 / 0.892–0.896），
  是当前协议下最强的两个对照级算法。

## 判定（CI 闸门）

按预登记规则：CI 跨零一律「证据不足」，不得宣称增益。

1. M1、M3 相对 B0 与相对 M1_source_scaled：逐种子与合并 CI 全部跨零 →
   **证据不足**。
2. M2 相对两个对照：合并 CI 完全在零以下 → **显著负**。
3. 触发 EXP-021 预登记失败条件：**当前 GDSC→Kryzei 官方迁移（EXPLORATORY_
   TRANSFER_ONLY）未证明增益**；停止在该协议下追加种子。

## 限制

1. EXPLORATORY_TRANSFER_ONLY：admission 与基因空间合同为 DRAFT / 未冻结；
   不据此宣称源域预训练价值，不外推临床。
2. **评价集与 admission 名单不一致（如实注明）**：admission 收据
   （`data/processed/identity/transfer/kryeziu_mcrc_target_admission_DRAFT.json`）
   为 51 患者 / 60 样本，其 blocked_claims 明确禁止「使用全部 52 组做正式
   patient-grouped 评价」；而官方 runner 实际加载的注册 cohort 为 52 患者 /
   91 样本，含未 admission 的 **Pt120**（1 样本 Pt120_t2，39 药物行）。这是
   既有三个 run 的共同口径（非本次汇总引入），对 52 患者宏平均的 Δ 影响至多
   1/52 权重，方向性结论不变，但在合同冻结后的正式重跑中必须修正为
   admission 白名单。
3. known 药物面板仅 14/48（GDSC InChIKey 重叠），M2/M3 只在这 14 药上与
   源域知识直接相关；全 48 药面板结果不在本主指标内。
4. 三种子合并 CI 的方法（患者三种子平均后患者 bootstrap）为主分析选择；
   种子数仍少（3），不能刻画种子分布的高阶性质。
5. M2 的逐种子 Δ 变化仅反映对照随折划分的变化，不构成 M2 本身的种子复现。
6. 源域模型仅一个冻结 checkpoint（EXP-015 seed=20260912），未覆盖源域训练
   不确定性。
