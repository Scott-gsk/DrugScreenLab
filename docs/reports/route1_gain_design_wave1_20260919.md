# 路线一增益设计波次一结论报告（EXP-024，2026-09-19）

## 一、结论（先行）

**在当前数据与设定下，未证明任何变体超过 B0 基线；按预登记失败条件，本波次停止，不做循环调参。**

- 6 个配置（2 个头部配置多种子复核 + 4 个预登记新变体）**全部未通过双闸门**（折级置信区间 + 患者级置信区间需同时不跨零且点估计为正）。
- 两个头部配置中，`pathway_pca` 家族（通路主成分表征）是唯一患者级区间不跨零且为正的方向（增益 +0.0054 ～ +0.0060），但其折级区间跨零，按预登记口径只能判为**证据不足**。
- `genes` 表征头部配置多种子均值（0.9044）**低于** B0（0.9089），折级区间不跨零且为负（弱于对照）；此前单次运行 0.9098 系种子运气。
- B0 每药均值基线再次表现出极强的稳健性：4 个新变体（残差目标、内层验证集成、源域校准、更强正则）均未带来可宣告的增益。

| 项目 | 口径 |
|---|---|
| 数据合同 | Kryzei 患者级外层 5 折冻结划分（`kryzeiu_patient_outer5fold_FROZEN.json`，患者与 DRAFT 完全一致），48 药，主指标患者宏平均 NDCG@5 |
| 训练种子 | 每配置 3 个种子（20260919/20260920/20260921）；迁移校准为确定性方法（无随机训练），单次运行 |
| B0 对照 | 官方口径宏 NDCG@5 = 0.9089（EXP-020 口径：(患者,药) 去重均值、fit 患者每药均值）；本波次复现断言通过（5 折逐一与冻结 CSV 一致，误差 < 1e-9） |
| 折级闸门 | 配置种子均值的原始行折宏 NDCG 对 B0 官方折值做配对重采样（2000 次，random_state=20260918），沿用 stage2 折级判定惯例 |
| 患者级闸门（主） | 两侧同用 Task-B 协议打分（(患者,药) 去重）；逐患者、逐种子配对差对种子取均值；患者单位 2000 次配对 bootstrap 95% 区间 |
| 双闸门 | 点估计 > 0 且折级区间、患者级区间均不跨零，方可宣告候选增益；任一跨零即证据不足；不跨零且为负即弱于对照 |

## 四、各配置要点

1. **genes_h64_wd02 多种子复核**：三种子宏 0.9066 / 0.9023 / 0.9045，均值 0.9044 低于 B0；折级区间不跨零且为负。此前单跑 0.9098 的"增益"不能在种子期望下复现。
2. **pathway_pca 家族**（wd0.01 / wd0.02）：两种正则的多种子均值几乎相同（0.9101 / 0.9100），且 wd0.02 种子间波动最小（±0.0005）。患者级区间一致为正且不跨零——这是本波次最强的正向信号，但折级区间跨零（5 折单位下 +0.001～+0.006 的差异无法分辨），按预登记双闸门不宣告。
3. **V1 残差目标**：去除药物主效应后的小网络未改善患者内排序（折级点估计还为负）。假设不成立。
4. **V2 内层验证加权集成**：三个成员的内层验证 NDCG@5 几乎相同，权重退化为近似均匀（各约 1/3）；集成没有超过最佳成员，且成员训练数据减少（41 → 32 患者）的代价未换来方差下降（种子间标准差 0.0039 反而最大）。假设不成立。
5. **V3 源域校准**：多数折在内层验证上选择 w=1.0（完全退回 B0）；允许偏离 B0 的折整体变差，折级区间不跨零且为负。GDSC 细胞系源域的每药效应信息在患者级排序上没有可用增量。假设不成立。

## 五、次级观察（敏感性分析，不作为宣告依据）

- **种子集成**（三种子预测平均，事后参考）：pathway 家族 +0.0060 [+0.0007, +0.0117]、genes +0.0077 [+0.0019, +0.0139]，方向为正且区间不跨零——提示预测平均可降低种子波动，但这属于事后分析，未预登记为闸门，不能据此宣称增益。
- stage2 原始行口径（不去重）的患者级区间所有配置均跨零，与主口径结论一致（证据不足）。

## 六、限制

- 折级闸门单位仅 5 折，对 <0.008 量级的差异分辨力有限；患者级单位 51 人。
- 折级闸门为混合口径（配置侧 stage2 原始行折值 vs B0 侧官方 Task-B 折值），沿用 stage2 历史判定惯例；主患者闸门两侧同协议打分，不受此影响。
- 多种子为 3 个，标准差仅作描述；V2 成员训练数据少 9 名患者；V3 仅覆盖 14 个交集药且源域为细胞系（与 PDO 分布不同）。
- 本波次结论限于当前 51 患者数据、48 药、冻结划分与既定模型家族，不外推。

## 七、下一步

1. 本波次按预登记停止；不追加未登记变体、不循环调参。
2. pathway_pca 家族患者级一致正向信号可作为后续波次的**预登记动机**（例如：更多种子下的预测平均部署口径、外部验证数据），需新的 EXP 登记后另行评估。
3. EXP-025（联合切片）的前置输入（头部配置多种子逐患者预测分）已全部落盘，可继续执行。
