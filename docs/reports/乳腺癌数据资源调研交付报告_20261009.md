# 乳腺癌细胞数据资源调研交付报告

日期：2026-10-09。依据：9月28日会议整理记录、用户10月9日对交付范围的明确说明，以及本地公开数据文件核查。用途：向老板交付数据调研结果，支撑模型研究及后续类器官实验决策。完整三方身份交集与分型证据整理已交付；当前继续验证细胞系模型的训练与预测可靠性。本文不构成模型验证成功或湿实验完成证明。

## 一、交付结论

**所需数据能够检索到，且本地已具备开展乳腺癌细胞药效建模的数据基础；但“基线表达、同药转录变化、药敏和可靠分型全部齐全”的覆盖远小于药敏数据覆盖，尚不能直接承诺所有分型的模型验证或类器官筛药。**

本次实际文件核查得到：

- DepMap 24Q2 有97条乳腺来源模型记录，其中67条在本地基线表达文件中有对应记录。97是注释记录数，不能全部直接称为97个合格乳腺癌细胞系。
- CTRP本地版本有40个乳腺来源细胞的药敏记录；通过Cellosaurus稳定身份号与DepMap逐项精确连接，这40个都有基线表达。其药敏覆盖544种药物、16,825个不同细胞—药物组合。544是整体并集，不是每个细胞都测齐544药。
- LINCS当前已处理条件表中，BT20、HS578T、MCF7、MDAMB231、SKBR3五个乳腺肿瘤细胞背景有扰动记录。MCF7覆盖最广，其余四个明显较窄。原始乳腺来源注释另有HME1和MCF10A，不能混入肿瘤细胞计数。
- 分型仍有实质缺口：97条DepMap记录中34条缺少历史分子分型；已有basal、luminal和HER2扩增等标签也不能直接替代三阴性受体判定或PAM50分型。
- 当前没有用户项目新生成的类器官加药前后RNA和对应湿实验药敏数据。本报告交付公开资源核查及能力边界，类器官实验仍处于后续决策阶段。

**此前报告把某次训练子集的4个乳腺细胞当作资源全貌，并把实验讨论和候选面板提前作为主要交付，范围不准确。本报告予以更正。** 当前不交付已验证的分型前10/后10药物面板，也不把历史探索候选作为最终实验选药结果。

## 二、会议要求与当前工作的先后关系

会议记录明确提出：以乳腺癌为例，查询细胞系分型和药敏数据库，之后考虑将同分型细胞的高、低敏感药物用于类器官处理，比较排序和通路变化，并利用新数据校正模型、寻找新的药物候选。会议最后要求“回去看看数据库……整理一下方案给老板看”。原材料是整理记录，含转写误差，本文不把它当逐字核验的老板原话。

用户现在进一步明确了执行顺序：

1. **先交付数据调研事实**：能找到什么，实际下载了什么，同一细胞有哪些数据，分型是否可信。
2. **再验证细胞模型能力**：用药前RNA与药物能否准确预测转录变化和药效，尤其能否超过只利用药物平均效应的简单方法。
3. **之后做按分型的药敏排序和前后10药验证选择**：区分实测药敏排序与模型预测排序；明确模型在哪些分型、药物和条件上可信。
4. **最后决定类器官实验与迁移验证**：根据细胞结果、可测药物与实际类器官材料，确定需要新增的数据；校正用数据与独立验证用数据分开。

这一顺序与会议的数据查询任务及未来验证方向相容。“先把细胞模型做充分再进入类器官验证”是用户当前明确的推进要求；会议同时讨论过用新增类器官数据帮助校正模型，并未明确要求先完成算法论文才能开展任何类器官实验。两者应如实区分。

## 四、数据完整性：哪些连接已经核实

### 4.1 基线表达与药敏：40个乳腺来源细胞已精确对应

本次通过DepMap的RRID字段与CTRP的Cellosaurus accession字段精确连接，未用相近名称强行匹配。40个CTRP乳腺来源细胞均能对应到有基线表达的DepMap模型记录。

这给出了开展“用药前RNA＋药物→药效”研究的实际基础。它尚不说明模型有效，也不说明每个分型有足够的独立细胞。16,825个组合不能当作16,825个独立生物对象；对未见细胞的验证必须按细胞或来源分组。

逐记录清单见：[乳腺癌细胞数据覆盖清单](乳腺癌细胞数据覆盖清单_20261009.csv)。其中药物数量仅按药敏表中出现的不同药物身份统计，没有读取药敏数值；正式建模还需检查有效值、重复测量、条件和当前数据角色。

### 4.2 乳腺实测扰动：覆盖集中，不能假定全分型充分

当前GSE92742处理条件表的身份计数如下。一个“条件”包含细胞、扰动、剂量与时间等信息；多条件不等于多个独立细胞。

|细胞背景|条件记录数|不同扰动身份数|
|---|---:|---:|
|MCF7|24,852|11,204|
|BT20|1,406|176|
|HS578T|1,400|176|
|MDAMB231|1,405|176|
|SKBR3|1,393|176|

这里统计的是扰动身份，未在本次核查中逐个验证为结构可用且药敏可连接的候选药物；不能把11,204直接称为可训练的完整药物数。补充核查已形成三方身份交集：5个细胞系、128种不同完整药物结构键、229个细胞—药物组合、1,832条LINCS处理条件。详见[三方交集与分型统一报告](乳腺癌三方交集与分型统一_20261009.md)。这是身份交集；药敏与扰动的暴露条件是否相同、数值响应是否符合建模要求仍需分别核验，不能宣称40个细胞都有实测扰动。

LINCS常用的978个直接测量标志基因与全基因RNA测序不是同一覆盖范围。报告模型预测准确性时必须注明预测的基因集合；预测978基因准确，不能直接写成全转录组预测已经准确。

### 4.3 分型标签：有线索，尚未完成临床口径统一

97条乳腺来源记录的历史标签分布：luminal 17、basal_A 16、HER2_amp 13、basal_B 11、basal 4、luminal_HER2_amp 2、缺失34。

这些数量对应97条注释记录，并非40个表达—药敏交集的分型分母。basal_B不直接等于已确认三阴性；luminal不直接等于Luminal A；HER2扩增与临床HER2阳性也需按定义说明。后续应按稳定身份补齐ER、PR、HER2受体及其来源，再明确是否使用临床分型、PAM50或研究中的历史标签。缺失或相互矛盾的记录单列，不凭经验填补。

## 五、现在的数据能做什么

|研究问题|当前判断|完成该问题还缺什么|
|---|---|---|
|用药前表达和药物是否能预测乳腺细胞药效|有数据基础，可推进|有效药敏值与重复处理、按对象分组验证、强基线比较；分型层面需核实独立细胞数|
|能否预测药物引起的转录变化|有来源数据，但乳腺背景有限|同药身份、可靠对照与处理条件连接；训练与评价基因轴一致；有效训练及代表模型公平比较|
|加入预测转录变化能否改善药效预测|可检验的算法问题，尚未证明有增益|与直接“基线RNA＋结构”比较，匹配容量及打乱对照；必要交叉拟合，避免同对象标签泄漏|
|各乳腺分型是否能得到可靠药敏排序|目前只能说有部分基础|分型统一、每药每型有效独立细胞数、共同药物范围、跨数据库一致性和排序不确定性|
|哪些药能组成正式前10/后10验证面板|当前未完成，不宜直接锁定|先完成模型能力评价，再明确实测与预测排序口径、可比条件、药物可得性及目标类器官分型|
|细胞规律能否迁移至类器官|目前没有本项目实验证据|类器官用药前RNA、对应药敏及按问题选择的处理后RNA；校正与验证材料独立|
|模型是否具有通路层面的可解释性|现阶段可建立分析方法，尚不能给出验证结论|乳腺细胞实测转录变化与药效的对应证据、预测准确性及合适对照；之后再检验类器官一致性|

仅用药物结构或药物平均效应也可能得到较好总体排序，因此模型必须证明基线RNA提供了与对象差异有关的额外信息。转录组逆转评分主要描述分子状态的变化方向，不直接等于抑制类器官生长；没有类器官药敏测定，不能证明药敏排序已经迁移。

## 六、后续决策依据与验收顺序

**当前先完整交付三方数据交集和有出处的分型统一，再验证模型是否在细胞系上预测可靠。正式前10/后10药物面板及类器官验证仅为条件性设想：前序预测不可靠时，不推进这两项，也不将其列为无条件待完成任务。当前无需先采购20药或确定测序样本数。**

1. 数据完整性验收：交付乳腺细胞身份、基线表达、药敏、实测扰动与分型来源的对应表；分别报告每个交集的独立细胞和药物分母。现已完成三方身份交集及受体注释来源整理，三阴性受体表型支持3个三方细胞；MCF7的PR来源冲突与5个细胞的PAM50缺失保留，不强行填补。
2. 转录预测验收：在明确的基因与处理条件上，与药物平均响应及代表模型比较，报告绝对误差、变化方向、拟合情况和未见对象泛化；正负结果均保留。
3. 药效预测验收：比较直接基线RNA＋药物、加入预测转录变化、容量与打乱对照，明确增益大小及不确定性。转录预测更准与药效更准分别验收，不能相互代替。
4. 分型排序交付：在资料充分的分型输出实测与模型预测排序、每药独立细胞数、差异和置信程度；据此形成前10/后10验证候选。资料不足的分型给出缺口，不硬凑20药。
5. 类器官决策：依据已有细胞证据提出需要补测的最少信息和可回答问题；再由实际材料、药物条件及成本确定方案。预测与实测通路一致只能支持相应分子响应解释，机制因果仍需专门实验。
