# 直接预测药物反应与转录逆转排序：对比报告

## 结论

如果目标是给类器官的候选单药排序，**直接预测药物反应是当前主路线**，因为它直接用真实的体外药物反应检验排序。转录逆转路线可提供基因和通路层面的辅助线索，但本项目尚未证明“逆转分数越高，类器官受抑制越强”。两条路线也尚未在**同一批类器官、同一批药物、同一评价指标**下正式比较。

## 两条路线做什么

| 步骤 | 直接预测药物反应 | 先预测转录变化，再计算疾病逆转 |
|---|---|---|
| 输入 | 类器官给药前的基因表达、药物结构 | 给药前表达、药物结构、剂量和时间；另需可靠的疾病与正常组织表达差异 |
| 模型直接预测 | 药物对类器官的体外抑制反应 | 药物给药后会使哪些基因表达上升或下降 |
| 最后怎样排名 | 按预测的抑制反应强弱排序 | 计算预测变化是否把疾病表达特征推向正常方向，按逆转分数排序 |
| 最终分数代表什么 | 在所用实验指标下的预测反应 | 分子表达变化的逆转程度，**不是药物抑制强度** |

## 优点与限制

| 问题 | 直接预测药物反应 | 转录逆转排序 |
|---|---|---|
| 最大优点 | 直接对准药物排序；可用同批类器官的真实反应核验 | 可利用较多药物扰动表达资料；能够展示候选基因和通路变化 |
| 主要数据条件 | 需要足够多、身份与药物对应清楚的“类器官—药物—反应”记录 | 需要可靠的扰动表达和疾病—正常表达参照；剂量、时间、基因测量方式要相容 |
| 主要误差来源 | 类器官样本少、不同实验的反应指标不同；容易学到药物的总体抑制效应 | 先预测表达再算逆转，误差可能逐步传递；表达逆转不一定带来真实抑制 |
| 新药潜力 | 药物结构输入提供探索可能，但当前实验只验证了训练中见过的药 | 药物结构输入也提供探索可能，但当前没有证明逆转排序能准确筛出未见药物 |
| 普遍毒性 | 强毒性药可能因抑制很强而排前面 | 强毒性药也可能产生显著表达变化；逆转分数不能自动排除它 |

## 本项目实际证据

| 检查 | 已得到的结果 | 能说明什么 |
|---|---|---|
| 直接路线：GDSC未见细胞 | 同时使用表达和药物结构的模型，比只按药物训练均值排序小幅提高；药物总体效应仍很强 | 来源细胞系内部有有限的表达相关信号 |
| 直接路线：类器官 | mCRC适配改善了直接使用来源模型的结果，但未超过简单目标模型；Zhu研究中适配模型低于药物平均值 | **细胞系→类器官迁移尚未证明有效** |
| 转录路线：扰动表达预测 | 已做XPert相关模型及扩展实验；一些表达预测指标和后续药物排序指标方向不一致 | “更会预测表达”不能推成“更会筛药” |
| 转录路线：真实扰动表达逆转检验 | EXP-007用真实测得的扰动表达做疾病逆转，再与PRISM细胞系药物反应比较；前列药物富集结果总体接近随机置换参照 | 即使先跳过“预测表达”这一步，当前逆转评分也未建立稳定筛药信号；这不是类器官同场对比 |
| 两条路线同场比较 | **待评估** | 目前不能依据本项目结果判定哪条路线在类器官筛药中更准 |

EXP-007的阴性结果只适用于当时的疾病表达特征、剂量时间、细胞背景和PRISM反应指标；不能据此断言所有转录逆转方法都无效。此前说“转录逆转路线完全没有实测结果”不准确，特此更正。

## 对当前目标的判断

目前先用直接路线给出**体外抑制反应候选排名**，同时与药物平均值等简单方法比较。转录逆转分数可以作为独立的探索性线索，不能在没有同场验证前直接与药物反应分数相加，也不能规定“两条路线都排前列才保留”。

下一项真正有判别力的比较是：在同一批未见类器官和相同候选药物上，分别冻结两条路线的排序，再用同一批真实药物反应评价各自及联合排序；另用正常组织毒性和可达到浓度判断候选药物是否值得继续实验。两条路线目前都不能单独给出“安全有效药物”结论。
