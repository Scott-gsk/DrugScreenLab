# EXP-020 IMPROVE 跨研究细胞系评测合同草案

状态：等待用户批准；尚未登记为运行中实验，尚未训练或评测。

## 已确认的数据事实

- IMPROVE 固定包包含 587,709 条响应，覆盖 CCLE、gCSI、GDSCv1、GDSCv2 和 CTRPv2。
- IMPROVE v0.1.0 跨研究工作流默认使用 `auc` 作为回归目标。
- 官方 10 套划分只保证响应行互斥。几乎全部细胞系和全部药物跨训练、验证、测试重复，不能支持严格未见细胞系或未见药物结论。
- 固定包作为一个不可变版本保留，不拆分或覆盖项目已有的 CCLE、GDSCv2、CTRPv2 资产。

## 建议的正式合同

研究问题：在目标研究药敏不参与训练、选模或阈值制定，且排除来源研究中出现过的细胞系身份后，表达加药物结构模型能否对同一种已知药在目标研究的不同未见细胞系之间进行排序，并超过不使用表达的基线？

数据：仅使用 IMPROVE 固定包中的表达、药物结构和 `auc`。来源研究与目标研究必须不同。目标测试细胞系如在来源研究出现则整体排除。同一目标细胞系的全部药物记录保持在同一角色。

划分：为每个来源研究建立 10 个固定种子的细胞系分组训练／验证划分。目标研究只承担锁定测试，不使用其响应选择模型。药物限定为来源训练与目标测试共有的已知药物；本实验不主张未见药物泛化。

模型：

1. B0：来源训练集逐药平均 AUC。
2. DrugOnly：只使用药物结构，不使用细胞系表达。
3. DualEncoder：使用基线表达和药物结构，复用项目现有双编码器接口。

主要指标：逐药物计算目标未见细胞系之间的 Spearman 排序相关，要求每种药至少有 10 个可评估细胞系，再对药物等权平均。

次要指标：细胞系等权 NDCG@5、细胞系内 Spearman、RMSE 和 Pearson。不同研究间 AUC 尺度可能存在偏移，因此 RMSE 只作描述。

失败条件：DualEncoder 相对 DrugOnly 的主要指标差值不大于 0，或细胞系／药物分块 bootstrap 的 95% 区间下界不高于 0，则不支持跨研究细胞系特异泛化。DualEncoder 还必须不低于 B0。

边界：结论仅限癌细胞系、已知药物和 IMPROVE 所含研究；不外推到 PDO、患者、临床疗效、未见药物或独立表达测量平台。

## 官方固定划分的处理

可另行做一次官方混合记录划分复现，但必须单独标记为“官方基准复现”，不得与上述严格评测合并，也不得作为细胞系泛化证据。
