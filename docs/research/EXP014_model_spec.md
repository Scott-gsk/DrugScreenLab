# EXP-014 可执行模型定义与算法假设

本文件细化原文B0/B1、M1—M5及N0—N5，不替代原文。状态：双编码器来源训练、Zhu开发队列M1/M2/M3和一轮残差诊断已完成；当前未证明PDO迁移有效。以下M5仍为待验证候选，不能称为已证实创新。

## 第一条必须完成的模型链

输入：训练折处理的基线表达x；药物SMILES派生的2048位、半径2、保留手性的Morgan指纹d。

首版采用512个训练折变异基因；样本分支512→32→32，药物分支2048→32→32，ReLU。交互层拼接[h_x,h_d,h_x⊙h_d]，96→32→1。对应现有DualEncoderPairModel(hidden_dim=32)，不把普通双编码器称为创新。

源域标签为本来源定义的敏感性；目标域DSS使用独立训练折尺度。损失为Huber + 0.2×同一生物模型内的成对排序softplus损失。只比较可比药物，剔除精确平局；成对采样必须可复现且避免按药物行序只取前若干对造成偏差。

M1：仅PDO训练。M2：来源域训练权重直接预测PDO，跨端点只评价排序而非原始单位回归误差。M3：同一来源权重在PDO训练折微调。三者使用相同基因空间、药物结构编码、外层患者划分和候选药物规则。

需要明确的预处理公平性：M2/M3使用源域冻结变换；M1需增加使用同一变换的对照，和PDO训练折自拟合版本区分，避免把缩放差异误认成预训练增益。PDO测试折永不参与变换拟合。

训练产物：权重、表达变换、药物映射、训练/验证ID、配置与数据hash、OOF预测、训练日志、计算成本；推理入口只接收基线表达与候选SMILES。缺少这些产物不能叫“训练完成”。

## 原文要求的低自由度适配

在M5之前比较完整微调和：s(x,d)=a·s_source(x,d)+b+λ·r_target(x,d)。

a,b在PDO训练数据拟合；λ在内层验证选取并含0；r_target为低容量目标残差预测器。必须使用交叉拟合的校准残差训练，或明确联合拟合目标，避免把训练内过拟合的来源校准当作真实残差。a的符号约束、λ候选和残差容量在执行配置冻结。

这不是已证明的创新，而是验证负迁移是否来自过度微调的诊断对照。若λ=0最稳健，保留校准模型并报告边界。

## M5候选：功能先验引导的选择性迁移

核心问题是“哪些患者—药物预测值得借用来源信息”，而非简单增加通路或堆叠域适配损失。

候选实现：共享表达编码h_s、域私有编码h_t；药物编码h_d；目标特异残差r_t；门控g(x,d)∈[0,1]。预测由校准来源分数与门控残差组合。门控可接收训练内估计的来源适用域距离及功能表示；不能读取目标测试标签。共享/私有编码不预设为真实生物机制。

通路先验约束基因→通路连接，分别采用Hallmark、Reactome、KEGG，不在首轮混合。来源特征迁移权重和门控的贡献分别消融，避免多个模块同时开启后无法归因。

功能辅助头按NextGen和类器官功能库分别预测依赖分数，缺失掩码跳过；HCMI肿瘤—模型保持度只作弱约束。功能损失权重包含0，各项资源遵循N0—N5引入；先去重、后划分，并隔离独立解释证据。
