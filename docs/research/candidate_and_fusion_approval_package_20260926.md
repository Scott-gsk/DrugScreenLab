## 主候选：交叉拟合共享效应后的状态残差

### 方法差异与可证伪假设

现有实现 `src/drug_screen/models/conditional_perturbation.py` 的 `SharedEffectInteraction` 联合拟合药物/暴露共享分支和细胞状态交互分支，输出为共享预测加状态—条件交互。它没有先生成按细胞组留出的共享效应预测，也没有把交叉拟合残差作为状态分支的训练目标。当前不存在独立的残差候选模型、候选训练驱动器或配套统计入口。

候选定义为：

1. 以药物结构、剂量和时间为输入拟合共享效应 `b(d,c,t)`。
2. 在**训练折内部按细胞身份分组交叉拟合**共享效应。对每条训练条件，只用未包含该细胞组的共享模型得到预测 `b̂₋g(d,c,t)`，形成残差 `r = Δ − b̂₋g(d,c,t)`。共享模型的归一化尺度、特征处理和候选选择均只在相应训练侧拟合。
3. 用给药前细胞表达、药物结构及暴露条件学习残差 `r̂(x,d,c,t)`；推理时加回仅在当前训练折拟合的共享效应，得到 `Δ̂ = b̂(d,c,t) + r̂(x,d,c,t)`。

**假设：**把训练目标改为共享药物/剂量/时间作用之外、且不由同组共享模型拟合造成的残差，能减少联合训练时共享主效应压过细胞状态信号的情况。这个机制解释目前只是可检验假设。

**最近方法边界：**状态条件扰动生成已有 PRnet、ExPO 等近邻；CODE-AE 等工作已有共享与特异成分分解思路。候选不主张“表达条件化”“共享/特异分解”或“残差学习”本身原创；待检验的差异仅是以按生物细胞组交叉拟合的共享效应残差作为状态分支目标，并在同一未见细胞预测协议中与既有联合模型配对比较。文献与方案依据见 `docs/research/algorithm_research_redirection_20260925.md` 第 3 节及 `docs/exec-plans/active/双路线算法研究与验证方案_20260922.md` 第 6 节。若原文/官方实现核查显示这一训练机制并无方法差异，仍报告该比较，不把它包装成原创主张。

## EXP-047：九药 MCF7 五臂探索性融合

用户已批准将九药备选用于本周探索性比较。Sol 已建议该范围；其结论仅限共同键覆盖的药物及合格患者。九药对应冻结药物索引 `0/1/3/4/5/7/9/12/13`；不把索引 2 的歧义、索引 10 的结构冲突或索引 6/8/11 的未匹配近似补入。唯一共同来源条件为 MCF7、10 µM、24 小时。

### 必做五臂与比较

| 臂 | 固定输入 | 比较作用 |
|---|---|---|
| F-A 直接单路 | 给药前 PDO 表达 + 药物结构 | 直接药敏基线 |
| F-B 扰动单路 | 药物结构 + 来源细胞 OOF 预测扰动；不含 PDO 给药前表达 | 扰动路线基线 |
| F-F 融合 | 给药前 PDO 表达 + 药物结构 + 与 F-B 完全相同的 OOF 扰动向量 | 融合候选 |
| F-C 等容量直接模型 | 给药前 PDO 表达 + 药物结构 + 参数量/更新机会匹配的普通直接分支；不含扰动信息 | 排除仅由额外容量造成的增益 |
| F-S 扰动身份打乱 | 与 F-F 同架构；训练侧按唯一来源细胞/扰动身份打乱整个扰动块并广播全部观测 | 检验正确扰动身份是否必要 |

沿用 EXP-036 的同一 PDO 患者外五折/内三折、50% 标签档与三个种子；候选剂量、早停与更新机会相同。外层药敏响应标签仅在五臂、模型、预处理、阈值和选择规则全部冻结后用于一次评价。不得依据外层分数筛药、改剂量/时间或选种子。F-S 的打乱仅用目标训练侧独立的扰动实体身份，外层验证/测试对象不参与打乱设计、特征变换或超参数选择。

主终点为九药共同可评分 PDO 患者的患者内 Spearman 排序，先按患者等权，再跨患者汇总；较高为好。F-F 对 F-A、F-B、F-C、F-S 四个预登记配对比较，以患者为配对单位报告效应、95% bootstrap 区间、有限修正双侧符号翻转检验及同一家族 Holm 校正。报告实际共同患者数、每患者有效药物数、缺失与未定义分数；不足冻结门槛的患者/折按既有规则报告，不能补药、按患者改变药物面板或将未定义值置零。精确参数搜索表、最低患者/药物覆盖门槛和停止阈值由 Sol 训练前一次冻结。

### 输入语义、准入门与结论范围

- 根据 EXP-047 已冻结的数据语义，以 MCF7 在九药、10 µM×24 h 条件下的来源细胞 OOF 预测汇聚成同一个静态来源参考向量。逐条件按三种子等权平均；只在全部九药该暴露键的共同、完整留出来源集合内等权汇聚。本备选的共同集合预检为一个细胞 MCF7，但必须由已验收 OOF 数值回执再次证明三种子、目标键、978 基因轴、有限值和对应五折来源留出哈希都齐全。单一来源参考向量不代表 PDO 个体化扰动预测。
- **残差候选与融合的连接待 Sol 冻结：**EXP-047 原有五臂输入合同绑定已验收 `conditional_v2` 来源 OOF 特征。本文件默认保持该合同，以免静默改变 F-B/F-F 语义；Sol 必须明确九药 F-B/F-F 使用现有 `conditional_v2` OOF，还是在同一五臂语义内使用残差候选 OOF。未经这一项冻结，不得物化/训练融合。无论如何，残差候选开发比较与五臂融合均完整记录，不能用前者负结果取消后者。
- CPU 准入先投影来源 OOF 条件键、药物键、基因轴、有限值和回执哈希；再只投影目标 PDO 可用药物键与覆盖，不读外层响应值。覆盖或可训练患者数不满足门槛则只停止融合分支，继续残差候选工作。
- 若准入通过，结果只支持九药、MCF7、10 µM×24 小时和通过五臂共同键门槛的 PDO 患者范围；不能称 14 药融合完成、等效、患者特异扰动已验证、全剂量/多来源泛化或治疗效果成立。原 14 药必做协议继续未完成，等待发布方身份交叉表解决余下五项身份问题。
