# 每个数据集是否完整，以及缺口能否获取（更新至 2026-09-17）

定位说明：当前数据集总表和统一完整性结论已归入 `data/DATA_CATALOG.md`。本文件保留 2026-09-16 至 2026-09-17 的详细核查依据，不再作为数据目录入口。

## 判断口径

本文件判断的是“来源数据是否能够取得、取得后是否包含实现研究目标所需的信息”，不以当前代码是否已经适配作为完整性标准。

当前研究目标按以下形式理解：使用基线分子特征和药物信息预测药物响应；先利用规模较大的细胞系数据训练，再用患者来源类器官数据微调，并在未参与训练的患者、类器官或独立研究中验证同一种药跨样本的响应排序。

“完整”必须说明范围：公开文件全部下载，不代表表达、药敏和患者身份三类信息同时存在；论文报告了某项实验，也不代表逐样本数值已经公开。

- **文件齐备**：明确列出的来源文件已到本地；文件清单之外的内容不作完整承诺。
- **任务输入齐备**：表达、药敏、药物身份和样本对应关系在指定子集中可用；患者关系未独立核实的，单独注明。
- **未获取**：本地还没有；需要记录是否已实际尝试下载。
- **访问受限**：官方要求权限申请；无需把它写成永久无法取得。
- **公开未找到**：已查过的公开来源未提供，不能据此证明作者没有数据。
- **已下载未解析／未验收**：问题在本地处理或证据核查，继续下载相同文件不会自动解决。

## 总体结论

目前已经逐项核实、能够直接提供“基线表达＋药物响应＋样本身份”的数据来源有 5 类：GDSC2、PRISM、CTRPv2、Kryeziu 结直肠癌类器官和 Zhu 肝胆癌类器官。前三者是癌细胞系数据，适合大规模训练和跨研究检验；后两者是患者来源类器官数据，能够支持微调和患者／类器官分组验证，但规模明显较小。

IMPROVE 是一个完整取得的标准化跨研究数据包。它额外带来 CCLE 药物响应、gCSI 和 GDSCv1，也重复包含 GDSCv2 和 CTRPv2，因此不能把包内五项研究全部重复计算为新数据。它的表达、药物结构和药敏数据有价值；官方划分按响应记录随机拆分，身份没有隔离，因此需要重新按细胞系分组后才能回答未见细胞系泛化问题。这属于评测划分问题，不属于数据文件缺失。

乳腺癌和胰腺癌方向目前没有新增的完整多患者“表达＋多药响应”公开矩阵。Chen 2021、Farin 2023 和 2025 胰腺癌数据一旦取得受限或作者掌握的表达及身份对照，最有希望补成有价值的外部验证数据。Xu 2026、Tiriac 2018、Bhatia 2022 仍缺两种以上关键内容，补齐路径或成功率更不确定。

Herranz-Ors、Kuo、LINCS 和 ChemPert 对表征学习有帮助，但不提供完整的患者来源类器官多药响应标签。它们可以帮助模型学习类器官表达分布、基因依赖或药物处理后的表达变化，不能单独证明药敏预测准确。

## 数据内容与目标需求的对应关系

1. **规模较大的细胞系表达—药敏数据**：GDSC2、CTRPv2、PRISM，以及 IMPROVE 中统一整理的 CCLE、gCSI 和 GDSCv1，提供较多细胞系—药物组合。
2. **患者来源类器官表达—药敏数据**：Kryeziu 的配对样本和药物数量最多；Zhu 提供较小的肝胆癌配对数据。两者都是目前直接与患者来源类器官药敏目标相符的数据。
3. **独立研究来源**：PRISM、CTRPv2、Kryeziu 和 Zhu 来自不同实验研究，可用于观察不同来源之间的数据一致性。这里仅说明来源独立性，不指定训练或验证角色。
4. **尚未形成完整配对但潜在价值较高的数据**：Chen 2021、2025 胰腺癌／HRA010277、Farin 2023，分别缺作者掌握的表达、受控表达或身份对应。
5. **辅助表征数据**：Herranz-Ors、Kuo、LINCS 和 ChemPert 提供类器官表达、基因依赖或药物扰动信息，但没有完整的患者来源类器官多药响应标签。
