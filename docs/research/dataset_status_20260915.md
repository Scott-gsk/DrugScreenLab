# 项目数据集现状（2026-09-15 本地复核）

> 本页已由 2026-09-16 的[逐数据集完整性与获取状态](dataset_completeness_20260916.md)取代。新表区分文件齐备、任务配对齐备、公开未找到、受控访问、技术阻断和已下载未解析，并包含 Terra 本轮实际获取及去重结果。

当前已经有可运行的细胞系药敏训练数据、PDO 开发数据和跨研究测试数据。最关键的缺口是尚未用于开发、且同一患者来源类器官（PDO）的基线表达与药敏能严格配对的独立验证数据，尤其是乳腺癌。

本表以当前本地登记、处理结果和实验记录为依据；本轮没有重新联网判断下载链接是否恢复。下载、配对、已运行实验分别报告。历史实验的数据规模不能替代当前版本。
