
# 基于细胞系—类器官跨模型迁移的可解释单药筛选研究方案


# 总述：研究定位、任务合同与证据边界

本课题建立面向患者来源肿瘤类器官（PDO/PDxO）的可解释单药筛选方法。核心贡献是细胞系到类器官的跨模型药敏迁移，而不是药物扰动表达预测。方法层面可服务于任意具备基线表达、单药剂量反应与可核验样本身份的PDO队列；论文结论只覆盖实际通过数据准入和外部测试的癌种与实验体系。

研究采用“总—分—闭环”结构：先固定任务合同与可检验假设，再按数据、模型、训练、评价、解释和扩展逐章展开；每个阶段只有达到预设门槛才进入下一阶段。所有结果定位为研究级候选预筛选，不构成临床诊断或治疗建议。

| 项目项 | 固定定义 |
| --- | --- |
| 研究对象 | 肿瘤PDO/PDxO；单药，小分子为主；不研究联合用药、协同或疗效联用标签。 |
| 样本输入 | 基线bulk RNA-seq或作者发布的标准化表达矩阵；可选配对正常样本的差异特征；样本、患者、癌种、培养体系、平台和批次元数据。 |
| 药物输入 | 规范化结构标识（canonical SMILES、InChIKey）和MVP阶段的ECFP/Morgan指纹；可选已知药物靶点，多热靶点向量单独建模。 |
| 主输出 | 给定一个PDO及候选单药集合，输出每种药的预测药敏排序分数、候选药物排序、Top-K列表与不确定性。 |
| 辅助输出 | 同一PDO—药物对的连续药敏预测；模型归因、忠实性检验结果与外部证据等级。 |
| 主监督标签 | 数据集内方向统一的连续药敏端点。优先原始剂量反应重算的AUC/AAC/GR-AOC；无法重算时保留数据集专用标签头。 |

### 重要数据来源与总体路线

三篇Nature研究[2–4]共同构成本课题的重要数据基础和理论支撑。它们进入研究的数据建设、表示学习、功能辅助训练和验证环节，不只用于背景引用。直接药敏监督仍来自细胞系和具备真实单药响应的PDO队列；三维表达与基因依赖用于帮助模型学习可迁移功能信息。

完整路线为：细胞系表达与单药药敏学习 → 三维模型表达及功能依赖适配 → 小样本PDO真实药敏微调 → 未见患者的候选单药排序。先完成不依赖功能数据的药敏基线，再逐项加入三篇研究的数据，测量独立增益。正式预测仍只要求PDO基线表达和候选药物信息，不要求新患者具有CRISPR筛选或配对肿瘤测序。

# 1. 研究背景与问题定义

细胞系药敏资源具有规模优势，但二维细胞系、三维类器官、培养条件与测量协议并不服从同一分布。类器官更接近患者肿瘤的生物学语境，却常面临样本数量小、药物面板有限和表达—药敏配对不完整的问题。因此，跨模型迁移必须作为可证伪的统计学习问题处理，不能将细胞系结果直接外推为患者疗效。

形式化地，对样本o与候选药物d，模型学习 fθ(xo, zd, kd, md)→(ŷod, σod)，其中x为基线表达，z为结构表征，k为可选靶点特征，m为数据集/域元数据，ŷ为方向统一的药敏分数，σ为预测不确定性。对每个PDO o，按ŷod从高到低得到排序πo。


# 2. 高质量证据与可检验工作假设

理论依据来自域适配与迁移学习：源域与目标域共享部分机制，但存在协变量偏移、标签尺度偏移和模型体系特异机制。共享性不能预设，需要通过未见患者、未见药物和跨队列测试判断。通路、靶点、CRISPR依赖和扰动表达均为候选信息源，不等同于药敏真值。

| 假设 | 问题 | 最小证据 | 失败后的处理 |
| --- | --- | --- | --- |
| H1 迁移信号 | 源域预训练是否帮助PDO排序 | 预训练→目标域微调在锁定PDO测试上稳定优于仅目标域与均值基线 | 先诊断端点与域差，比较受约束适配；仍无增益时限制迁移结论。 |
| H2 表示迁移 | 通路或基因+通路是否优于基因 | 至少两个可用PDO队列或重复患者分组上方向一致 | 通路仅用于解释与稳定性分析。 |
| H3 迁移机制 | 共享—特异编码是否减少负迁移 | 相对强迁移基线在主要终点和残差终点均有增益 | 不使用共享—特异模块作为论文主张。 |
| H4 扰动增量 | 逆转是否提供额外药敏信息 | 真实扰动逆转先于预测扰动，在PDO排序上有独立增益 | 降级为附录分析，停止将扰动模型作为药敏主线。 |
| H5 可解释性 | 归因是否具有可审计支持 | 遮蔽/置换改变预测且与外部靶点、依赖性或已知标志物相符 | 仅报告模型归因，不声明机制。 |

### 2.1 四篇P0论文分别支持什么

DrEval提供偏倚感知和跨数据集评价框架。论文中的未见药物测试说明，分子特征并不自动带来新药泛化能力。[1] 因此本研究将“新PDO上的已知候选药排序”设为主任务，未见药物与双冷启动作为单独挑战；NDCG及患者分组是本研究面向PDO场景的扩展，不归为DrEval已验证的结论。

NextGen DepMap联合分析传统细胞系与三维模型的表达、基因组和依赖性，显示共享规律与培养体系相关差异并存。[2] 这是开展跨模型学习的生物学依据，不是迁移算法有效性的直接证明。HCMI对肿瘤与来源模型进行配对组学分析，提示模型保真度需要按分子层次和细胞状态分别判断，不能由基因组一致性推导转录组或药敏等价。[3]

类器官功能生物库建立了256个模型，并在162个类器官开展全基因组CRISPR筛选。[4] 该资源可用于功能解释和域差异分析；162不是新增的全药库药敏样本数。三篇Nature研究关联HCMI项目，模型可能交叠，不能视为三个独立验证队列或直接相加计算样本量。

### 2.2 将证据转化为可检验设计

本方案据上述研究提出两个额外检验：在同癌种内比较细胞系与PDO，再分析癌种构成差异；在基因表示、通路表示及二者联合表示中比较迁移增益。若域分类准确率降低但PDO排序未提高，不判定适配成功。共享—特异结构是候选实现，需要与直接微调、正则化残差适配及参数量匹配模型比较，不能单凭结构命名主张创新。

### 2.3 三篇Nature研究对应的学习假设

NextGen DepMap[2]支持“细胞系与三维模型共享部分功能规律，同时存在培养体系相关差异”的假设；HCMI[3]支持“肿瘤—来源模型的保持程度具有特征和状态依赖性”的假设；类器官功能生物库[4]提供在三维体系中检验基因依赖的监督数据。由此提出功能辅助迁移假设：相较仅细胞系药敏预训练，加入独立三维表达和功能监督，能够在相同PDO药敏样本预算下改善患者内排序。

这些生物学证据不能保证算法增益。数据量增加、额外训练时间和功能标签本身的贡献需要分别消融。若依赖性预测改善但最终PDO药物排序不改善，只能认为功能任务有效，不能声称筛药迁移成功。

# 3. 总体目标、研究主线与阶段目标

总体目标是建立并严格评估一个跨模型单药排序框架：细胞系药敏知识用于源域表示学习，有限PDO药敏用于目标域适配，最终以PDO内候选单药排序为主任务。算法论文的第一贡献是可验证的细胞系→PDO迁移方法，第二贡献是可解释的负迁移控制与严格评估协议。

| 阶段 | 目标 | 可交付结论 |
| --- | --- | --- |
| S0 数据准入 | 完成身份、药物、表达和反应标签的版本化对齐 | 哪些公开队列可真实承担MVP、训练或外部验证角色。 |
| S1 MVP | 建立强基线并判断是否存在迁移信号 | 跨模型预训练是否优于PDO内学习。 |
| S2 方法创新 | 以共享—特异表征和可迁移特征加权控制负迁移 | 何种域差异应共享、何种应保留。 |
| S3 扰动验证 | 验证真实与预测逆转的下游价值 | 扰动信息是否增加PDO排序性能。 |
| S4 外部验证 | 在独立癌种/队列进行锁定模型评估 | 结论的适用范围与失败边界。 |

# 4. 数据体系与公开资源

数据按任务职责分层。直接药敏数据须具备样本身份、表达、药物身份及端点定义；表达适配数据须具备基线表达与模型元数据；功能监督须具备基因依赖标签和可对齐表达；保持度学习须具备肿瘤—模型配对信息。各层均记录来源、版本和访问条件，不因缺少药敏标签就排除其参与表征或功能训练。

### 4.2 乳腺癌外部验证的准入条件

Guillen等研究的PDxO经历PDX移植过程，不能与直接从患者组织培养的PDO混同；乳腺癌整体也不能等同于TNBC。[7] 先按模型ID、来源患者、亚型、基线表达测量体系和药物标识建立交集。若RNA来自配对PDX而非PDxO，应单列跨体系分析，不替代主任务的PDxO基线输入。

严格零样本外部测试不使用乳腺队列的标签或表达拟合预处理和模型；如开展目标队列微调，应另设患者分组的少样本适配实验。TNBC仅报告有足够有效样本的子集结果。若只有药敏而无合格基线表达，可验证端点与复现药敏分析，但不能声称完成算法外部预测验证。公开数据主路线不依赖取得受控访问许可才能完成。

### 4.3 三篇Nature数据的正式纳入方式

NextGen DepMap[2]作为跨体系训练资源：优先整理模型元数据、处理后的基线表达和CRISPR基因依赖矩阵；按细胞系与三维模型、癌种和培养信息建立可比较的训练子集。表达用于无药敏标签的表示适配，依赖性用于辅助监督。同一癌种内的分析先于泛癌比较，以降低癌种构成混杂。

HCMI[3]作为肿瘤—模型配对表示资源：获取可公开使用的处理后表达及配对映射，分析基因和通路保持度。合格的独立配对数据可用于学习弱先验或训练表示约束；不把所有差异都当成批次噪声，也不强制肿瘤与类器官表达完全一致。原始测序受控时，优先使用开放处理数据；无法取得的文件不作为主路线必需条件。

类器官功能生物库[4]作为三维功能监督资源：以模型身份对齐表达和CRISPR依赖，构建“表达—基因—依赖分数”记录。训练部分用于辅助任务，独立留出部分用于功能泛化及解释验证。模型具有哪些药理实验另外核查；只有满足基线表达、药物身份和可比单药响应配对要求的子集，才可进入直接药敏训练或测试。

三个资源分别登记公开入口、文件名、版本、许可或访问条件、模型数、独立患者数、表达与依赖交集、可配对药敏子集及排除原因。入口见4.1节，论文规模不等于实际训练规模；三篇关联资源先按患者及模型去重，不能累加样本数或互相冒充独立外部队列。当前已核实论文与数据声明，文件下载和有效交集仍是正式建库任务。

# 5. 数据处理策略

所有处理以可复现、无泄漏和保留域差异为原则。建立四张版本化表：sample表、drug表、response表和split表；模型训练只从这四张表读取。每一行response由数据集、患者、样本、药物、端点、方向、剂量范围和质控状态共同定义。

| 对象 | MVP处理规则 | 必须记录 |
| --- | --- | --- |
| 表达 | 使用作者处理后的bulk表达；统一HGNC/Ensembl并取固定公共基因集合；log2(TPM+1)或来源推荐变换。训练折拟合缩放参数再应用至验证/测试。 | 基因版本、缺失比例、重复映射、测序平台、批次、培养条件。 |
| 通路 | 并行构建Hallmark和PROGENy等稳定低维特征；不使用全数据拟合的特征选择。 | 基因集版本、评分算法、参数、覆盖基因数。 |
| 药物 | canonical SMILES去盐和标准化；以InChIKey主键建立跨库映射；ECFP半径、长度固定。 | 原始名称、同义词、SMILES、InChIKey、来源、映射置信度。 |
| 药敏 | 统一为“数值越大代表越敏感”的方向；原始曲线可得时重算；否则数据集内标准化、专用输出头或排序损失。 | 端点定义、方向、浓度范围、拟合方法、重复数、质控标记。 |

### 5.1 防止辅助数据引入隐性泄漏

建立跨资源身份总表，将HCMI、DepMap、Cell Model Passports中的别名、来源患者及配对模型连成同组。测试患者及其衍生模型不能进入预训练、通路筛选或依赖性辅助训练。若使用无标签测试表达，应明确另列为传导式实验，不能与严格未见患者结果混报。

GR指标重算必须具备给药时刻基线量及处理组、对照组终点数据和可用增长条件；不能从AUC反推。不同浓度窗口即使使用同一积分算法也不保证可比。跨药物排序只能解释为预定义实验协议下的响应优先级，连续预测分数不称为有效概率。

### 5.2 新增表达配对与功能监督数据表

在sample、drug、response和split表之外，增加expression_pair与dependency两张表。expression_pair记录肿瘤ID、来源模型ID、患者ID、测量平台及基因空间；dependency记录模型ID、基因ID、依赖分数、算法版本、质控和训练/验证角色。两表保留与样本总表的外键关系，不要求每个药敏PDO同时拥有所有模态。

不同研究的CRISPR分数及处理方法可能不同，不直接拼成统一数值标签。先采用资源专用辅助输出头或分别训练，再比较联合学习；缺失依赖标签以掩码跳过，不作为零依赖。HCMI与功能库中的测试患者衍生模型必须在所有预训练和辅助任务中排除。

# 6. 最小可行性验证（MVP）模型架构

MVP采用可控且可复现的模型，不把Transformer或药物基础模型设为成功前提。样本编码器与药物编码器分开，交互层使用拼接、双线性层或小型MLP。输出层同时给出连续分数与可用于排序的分数；当多数据集标签不可比时使用数据集专用回归头，共享排序表示。

| 模型 | 输入 | 训练目的 |
| --- | --- | --- |
| B0 均值/残差基线 | 药物均值、样本均值、癌种/数据集协变量 | 揭示药物普遍毒性和样本普遍敏感性可解释的比例。 |
| B1 强传统基线 | 表达降维或通路+ECFP；ElasticNet、XGBoost、随机森林 | 防止深度模型在小目标域虚高。 |
| M1 目标域模型 | PDO表达+ECFP | PDO内学习下限。 |
| M2 直接迁移 | 细胞系训练，PDO零样本测试 | 测量直接跨模型泛化。 |
| M3 微调迁移 | 细胞系预训练→PDO微调 | H1的核心基线。 |
| M4 表示消融 | 基因、通路、基因+通路分别执行M3 | 检验H2，选定后续表征。 |
| M5 共享—特异模型 | 共享编码器+域私有编码器+药物交互 | 目标域验证与负迁移诊断后用于H3。 |

### 6.3 功能辅助迁移模型

在既有药敏模型旁增加训练期功能头。共享样本编码器接收基线表达；药敏头结合药物结构预测排序分数；依赖性头结合基因标识或基因嵌入预测该模型对该基因的依赖。药敏样本优化药敏损失，功能样本优化依赖损失，只有具备对应标签的记录参与各自任务。无需构造不存在的全模态配对样本。

MVP功能头优先使用固定基因集合的多输出预测，基因范围依据训练标签覆盖和质控确定。新PDO预测时由其表达生成表示，不输入实测依赖标签。可选的预测依赖—药物靶点汇总特征须另设消融，不将基因敲除强度等价为药物抑制效应。

# 7. 训练目标与学习策略

主损失由连续药敏和患者内排序组成：L = λr LHuber(y,ŷ) + λq Lrank(y,ŷ) + λd Ldomain + λs Lstability。MVP阶段λd与λs为0；M5才引入域约束与稳定性正则。排序对只在同一PDO且标签可比较的药物之间构造，并排除质量不足或差异小于预设实验噪声阈值的药物对。

训练顺序固定为：源域预训练；目标域内部患者分组验证调参；在训练PDO上短程微调；锁定模型后只评估未见患者测试集。任何测试PDO、测试药物或外部队列均不得参与特征选择、早停和超参数选择。


### 7.3 分阶段加入Nature数据的训练协议

先训练细胞系药敏基线，再使用公开三维表达进行受约束表示学习，随后加入三维依赖性辅助任务，最后用PDO药敏训练集适配。各阶段保留前一阶段检查点，并以相同目标域训练/验证患者划分比较；采用混合小批次或参数收缩减少辅助训练造成的药敏遗忘。

功能增强模型的目标写为 L总 = L药敏 + αL依赖 + βL表达 + γL保持 + ηL正则。其中L药敏沿用回归与患者内排序，L依赖按有效标签掩码计算，L表达可采用掩码重建，L保持仅约束训练期独立配对数据支持的稳定特征。各项按数据集和样本归一化，α、β、γ允许取0，并由目标域开发验证集选择。各资源体量不同，通过采样比例控制贡献，不让大功能矩阵淹没药敏目标。

HCMI保持度先验与功能监督为可分别关闭的模块。若数据覆盖不足或引起负迁移，可保留仅表达适配或直接药敏模型；三篇资源的重要性不意味着每个模块都必须进入最终预测器。

# 8. 贯穿全生命周期的评价体系

主要终点是未见PDO上的患者内NDCG@K，建议K根据候选药物数预注册为3或5；第二终点是逐PDO Spearman的宏平均。连续回归指标用于描述，不能单独支持个体化筛药结论。报告患者重采样95%置信区间、每PDO分布和配对差异。

| 层级 | 指标 | 解释 |
| --- | --- | --- |
| 数据质量 | 配对完整率、重复相关性、曲线质控、药物交集、批次可视化 | 确认标签和特征是否具备建模条件。 |
| 主要任务 | PDO内NDCG@K、PDO内Spearman、Precision@K、Hit@K | 回答有效单药是否排在同一患者的前列。 |
| 数值拟合 | MAE、RMSE、R2、Pearson | 辅助描述连续分数误差。 |
| 偏倚审计 | 相对B0的增益、残差性能、逐药物/逐PDO性能 | 排除只记住药物或样本均值。 |
| 泛化 | 未见PDO、未见药物、双冷启动、跨队列 | 分别对应新患者、新药和真实部署外推。 |
| 不确定性 | 覆盖率、校准误差、拒绝低置信预测后的性能 | 避免把高不确定性排名当作确定候选。 |

### 8.1 DrEval启发的PDO评价实施细则

在相同患者分组下实施药物均值、强传统模型、目标域模型和迁移模型比较。[1] 测试患者的药敏均值不可从其真实标签计算后提供给预测器；已知药物的均值仅从训练数据估计，未见药物无可用均值时采用训练全局均值或预定义特征模型。训练外拟合药物主效应后计算测试残差，辅助检查患者特异信息。

主要设定固定为新患者、已知候选药；至少10种可比实测药时评估NDCG@5，候选不足时采用预先约定的NDCG@3并独立报告。连续相关性要求存在响应变异；全平局样本报告数量，不当作完美预测。NDCG相关性用同一PDO实测敏感性分位秩映射至[0,1]，并说明其衡量相对排序而非临床有效性。没有可信阳性阈值时，Precision@K只作为实测Top-K重合率，不写成有效药命中率。

增加表达置换、药物特征置换和结构编码消融；若打乱患者表达仍保持成绩，应检查是否由药物主效应主导。置信区间以患者为抽样单位，同一患者多个模型先汇总；重复折不是独立患者。第二终点与探索性多药比较分别报告，必要时校正多重检验。未知药物必须从所有药敏训练域留出，另报结构相似度或骨架划分敏感性分析。

# 9. 转录组逆转分支的客观验证路径

该分支后置执行，不参与MVP选模。R0使用实测扰动表达评价逆转特征能否解释样本特异药敏残差；R1比较实测与XPert/TranSiGen等预测扰动的表达和通路保真；R2只检验其是否提高锁定PDO模型的NDCG@K和Spearman。表达PCC提升但排序无增益，不构成保留该分支的理由。


### 9.1 XPert的接入与逆转所需条件

XPert以未处理表达、药物特征和剂量—时间条件预测处理后表达及表达变化。[5] 复现先核对基因空间、剂量单位、时间和对照定义；对照包含不改变表达、平均扰动和TranSiGen，分别评价变化量与处理后绝对表达，避免基线表达相似性造成虚高。剂量和时间必须预先固定或按训练验证协议汇总，不能在测试PDO上挑选最佳条件。

R0首先在能匹配细胞背景、药物和实验条件的公开细胞系数据检验扰动与药敏关系，这只属于辅助可行性证据。疾病逆转还需要可靠的肿瘤—正常参考；缺少该参考时，仅做扰动表示融合，不构造伪疾病签名。只有存在PDO实测扰动与药敏配对时才设置“真实PDO扰动”参考臂；缺失时不能把其他细胞系扰动称为该PDO真值，也不阻塞直接药敏主线。

### 9.2 PDGrapher的借鉴范围

PDGrapher解决由细胞状态推断干预靶点集合的逆问题，其基因网络是因果图的近似，模型依赖相应假设。[6] 本方案可借鉴靶点级状态表示，将一个候选单药的已知多靶点谱汇总为辅助特征，再检验其排序增益；单药多靶点不等于联合用药。不得把靶点集合直接解释为可实现的药物，不扩展到药物组合优化。该改造属于任务适配，不能称为原论文药敏结果复现。

# 10. 可解释性：从模型归因到可审计证据

解释输出分为模型归因和外部支持，两者不得混写为因果机制。模型归因采用特征遮蔽、通路置换、积分梯度和反事实删除；每个解释必须报告删除后的预测变化和跨折稳定性。外部支持以药物已知靶点、同模型体系CRISPR依赖、已知标志物或独立PDO/PDX证据分级。

| 输出字段 | 必备内容 |
| --- | --- |
| 预测 | PDO ID、候选药物、排序、连续分数、不确定性、适用域标记。 |
| 模型归因 | 基因/通路/靶点贡献、跨折出现频率、遮蔽后的分数变化。 |
| 外部支持 | 靶点来源与版本、依赖性证据、癌种和模型体系是否匹配。 |
| 声明边界 | “模型依赖”与“外部支持”分列；没有因果干预实验时不称为真实致敏机制。 |

### 10.1 基于类器官功能依赖的解释实验

利用[4]的依赖性数据检验高归因通路或药物靶点是否比表达量、网络度数和靶点数量匹配的随机对照更富集功能依赖。优先在相同癌种与明确背景中比较；不同背景的支持降级呈现。基因敲除与药物抑制在作用强度、选择性和时间上不同，依赖性不能替代药敏。[2,4]

用于功能正则化的模型不得再充当独立解释验证集。按患者/模型拆分辅助训练和解释验证数据；数据不足时仅做描述性一致性分析并标明复用。已知靶点作为输入时，再发现该靶点不构成独立新机制证据。

# 11. MVP实验设计与继续/停止判定

MVP先在一个达到准入标准的PDO队列中完成完整患者分组交叉验证，再在第二独立PDO队列上锁定外部测试。不能因某癌种名称被预先指定就跳过数据准入。每个模型使用相同药物映射、相同患者分组和相同候选药物池。

| 门槛 | 通过条件 | 未通过时的行动 |
| --- | --- | --- |
| G0 数据准入 | 表达、患者ID、单药标签、药物结构、端点方向和分组全部可核验。 | 不进入建模，转为背景/机制资料。 |
| G1 个体化信号 | M1在未见PDO上超越B0，且逐PDO性能不是由少数药物驱动。 | 重新审计标签和候选药物面板；不做迁移主张。 |
| G2 迁移价值 | M3相对M1和M2在主要终点的患者重采样区间稳定为正。 | 先完成小规模负迁移诊断，再决定是否开发M5；不以单次阴性结果否定迁移。 |
| G3 表示价值 | 基因/通路选择在第二队列或重复划分上方向一致。 | 只保留更稳健的表示，另一表示降为解释。 |
| G4 外部可复现 | 锁定模型在独立PDO队列趋势可复现。 | 限制结论为单队列，论文重点转为评测或负迁移分析。 |

### 11.1 新增的证据驱动实验

| 实验 | 对照与检验 | 判定及对应参考 |
| --- | --- | --- |
| E1 评价复现 | 训练集均值、传统模型、表达/药物置换，与主模型同划分 | 患者排序增益需超越均值，且表达置换使个体化信号下降；借鉴[1] |
| E2 域差异拆解 | 同癌种细胞系与PDO、匹配样本量、培养元数据；再做跨癌种 | 描述性域差不能声称培养条件因果效应；以[2,3]为依据 |
| E3 适配创新 | 直接微调、收缩残差、共享—特异；相近参数量与搜索预算 | 对弱迁移的诊断可以继续；扩大模型前须有目标域验证支持 |
| E4 功能解释 | 独立CRISPR模型与匹配随机靶点对照 | 同时报告忠实性和功能一致性；依据[4] |
| E5 外部挑战 | 合格乳腺PDxO零样本测试，少样本微调另报 | 区分亚型、来源患者与PDX/PDxO表达；依据[7] |
| E6 辅助分支 | 无扰动、简单扰动、XPert/TranSiGen、靶点特征 | 仅以药敏排序增量决定保留；借鉴[5,6] |

简单预训练无增益时，先检查端点、域差异和样本量，并允许小规模残差/选择性迁移诊断；不由一次阴性结果否定全部迁移方法。独立外部队列用于最终检验，不能反复作为决定架构的开发集。若某队列已影响设计，应如实标为开发验证集，最终结果需要另一锁定队列或独立患者测试。

### 11.2 Nature数据增量实验矩阵

在相同PDO患者分组、药物面板和调参预算下依次比较：N0，仅细胞系药敏预训练与PDO微调；N1，N0加三维表达适配；N2，N1加NextGen依赖监督；N3，N1加类器官功能库依赖监督；N4，两个功能资源去重后联合监督；N5，在最佳开发模型上加入HCMI配对保持度约束。无需把所有组合都训练为复杂网络，先用受限模型筛查增量。

附加对照包括等训练步数的N0、相同模型容量、移除功能损失和训练样本内打乱依赖标签。比较相同目标域样本预算下的NDCG与Spearman、药物主效应校正结果、负迁移比例及学习曲线。功能资源交叠的样本不能出现在两个独立验证组。

依赖性预测指标用于检查辅助任务是否学会，PDO排序指标决定该模块是否保留。只有新增数据在开发验证中有支持，才锁定方案进行外部测试；外部阴性结果如实报告，不回流选模。

# 12. MVP通过后的可扩展模型

MVP通过后，提出“可迁移表征分解模型”。编码器将样本表示拆为共享部分zs和域私有部分zp，预测使用zs与目标域私有表示的门控组合。对共享部分施加弱分布一致性约束，对私有部分使用域可辨识约束，并通过重建/正交约束减少表征坍塌。模型不追求消除全部域差异，而是学习何种差异不应被迁移。

创新点应被限制为可被实验证明的三件事：共享—特异分解是否降低负迁移；基因/通路可迁移权重是否改善外部排序；不确定性门控是否减少错误Top-K推荐。药物靶点与功能依赖首先作为正则和解释证据，只有消融支持后才进入主输入。


### 12.1 将生物学依据落实为可比较的候选算法

第一创新候选采用受约束的适配形式：目标域分数＝校准后的来源分数＋收缩的目标域残差。校准参数与残差均只在训练PDO拟合；与从头训练、完整微调比较相同目标样本预算。这给小样本迁移提供低自由度对照。

第二候选再引入共享—特异表示。通路保持度可从独立HCMI配对资料估计，培养敏感性可从NextGen资料描述，但两者只作为可消融的弱先验，不直接称为“通路可迁移真值”。对照均匀权重、随机权重和无先验模型，只有目标域排序改善才保留。共享与私有表示在统计上不保证唯一对应真实机制；新颖性仍须与既有表示分解和残差迁移文献比较。

# 13. 主要风险与应对

| 风险 | 表现 | 预防与处置 |
| --- | --- | --- |
| 目标域过小 | 深度模型优于基线但区间宽或不稳定。 | 患者分组、重复划分、参数预算、强正则与简化模型；报告失败，不靠增加模块掩盖。 |
| 标签不可比 | 不同队列AUC、IC50、GR指标和剂量范围不同。 | 优先重算曲线；否则多头、数据集内排序与分队列结论。 |
| 药物主效应 | 随机拆分高分，未见患者性能下降。 | B0、残差终点、逐药物报告和严格药物留出。 |
| 药物交集不足 | 源域与PDO无法形成可靠共同评估。 | 主MVP先做共同药物；未见药物单列为挑战任务。 |
| 批次/培养偏移 | 模型学习实验室或二维/三维标签。 | 只用训练折拟合变换；保留域元数据；跨队列测试。 |
| 外部队列不可用 | 乳腺/TNBC只有处理后表达或缺少配对矩阵。 | 不作为排序验证；保留为分子方向旁证，待准入后再启用。 |

# 14. 预期结果与可发表故事线

最佳结果是：在两个PDO队列上，M3稳定优于目标域基线和均值基线，M5进一步减少负迁移并改善低置信案例的排序；解释审计显示模型依赖在外部靶点/依赖证据中可复核。论文贡献将是带有严格患者分组和外部验证的细胞系→PDO单药排序迁移方法。

同样可发表的结果包括：迁移只在特定癌种/药物面板有效；通路压缩不优于基因层；药物主效应占主导；逆转无增益。此时论文应以公开PDO药敏迁移的系统评估、失败机制和负迁移边界为主，而不能将阴性结果包装成方法优势。

# 16. 建议的实际执行顺序

- 冻结研究合同与版本：建立数据字典、药物映射表、患者分组和预注册的主要终点。
- 完成G0：优先审计胰腺癌PDO；同时审计mCRC及乳腺/TNBC候选队列的表达—药物—单药响应配对。
- 在GDSC2/CTRPv2建立B0、B1和M2来源域诊断，并检查药物身份和标签方向。
- 在通过G0的胰腺癌PDO队列完成M1—M4的嵌套患者分组MVP；若未通过，切换至下一个合格PDO队列并记录原因。
- 在第二个合格PDO队列只做外部评估；乳腺/TNBC若未满足G0，不作为药敏测试集。
- 按训练和开发验证结果决定M5开发；外部G4保留为锁定后的最终检验。
- 仅当直接药敏模型稳定后运行R0—R2，决定是否保留逆转分支。
- 整理可复现代码、版本清单、固定划分、模型卡、结果表和论文图表。

### 16.1 三篇Nature数据的优先执行清单

数据建库阶段即整理三篇论文对应的资源清单，不后置到论文解释阶段。先核查开放处理矩阵和访问条件，再建立患者—模型—癌种—培养体系映射，完成跨资源去重；分别冻结表达、功能、配对保持度和药敏任务的训练/验证清单。

# 17. 研究方案的最终判定标准

本课题完成的标准不是构建一个复杂网络，而是形成一条可复现、可证伪、可扩展的计算证据链：任务输入输出明确；公开数据身份和标签可审计；严格未见患者测试超过正确的简单基线；源域迁移增益在独立PDO队列得到验证或被诚实界定其边界；解释经过忠实性和外部证据双重核验；扰动分支以最终排序增益而非表达拟合指标决定去留。
