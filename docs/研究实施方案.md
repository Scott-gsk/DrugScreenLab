# 基于通路表示与迁移学习的患者来源类器官药物敏感性预测研究方案

> 2026-09-22 版本关系：本文保留早期研究设计与资源盘点。当前执行以 `exec-plans/active/双路线算法研究与验证方案_20260922.md` 为准：直接药物响应预测与连续转录扰动、疾病逆转筛药分别建立监督、主要终点和验收证据。下文历史数据规模和“统一评价指标”要求不覆盖两路线任务差异；实际准入、划分和指标须按当前方案及审计表重新冻结。当前运行状态见 `../PROJECT_STATE.yaml`。

## 一、研究目标与总体设计

### 1. 研究目标

利用大规模细胞系基线表达和药物响应数据，在患者来源类器官（PDO）药敏样本有限的条件下，建立能够：

1. 预测 PDO 对不同药物的敏感性；
2. 为每个 PDO 排列优先验证的候选药物；
3. 从通路状态和药物作用角度解释预测；
4. 量化预测稳定性和适用范围。

研究同时评价两条技术路线：

- **药敏预测路线**：基线表达与药物信息 → 药敏预测 → 候选药物排序。
- **转录扰动路线**：基线表达与药物信息 → 转录变化 → 通路变化或疾病逆转评分 → 候选药物排序。

两条路线先分别验证，再检验联合使用是否优于单独使用。

### 2. 研究原则

- 从统计分析、线性模型和树模型开始，逐步过渡到小型神经网络、近期通路模型和预训练模型。
- 每增加一个模块，设置能够单独检验其贡献的对照实验。
- 所有模型在统一的数据版本、划分、候选药物集合和评价指标下比较。
- 本研究重新建立数据与评价协议，不以此前实验结果作为模型选择、参数设置或研究结论的依据。
- 计算环境按 **NVIDIA RTX A5000、24 GB 显存**配置。

## 二、数据组织与分析任务

### 1. 数据分工

| 数据 | 内容与当前配对规模 | 研究用途 |

| CTRPv2—DepMap | 820 个细胞系、544 种药、364,761 条响应 | 扩大训练覆盖；跨研究评价 |
| PRISM—DepMap | 当前配对资产含 877 个细胞系、104 种药、59,037 条响应 | 跨研究评价，不参与超参数选择 |
| Kryeziu | 91 个有药敏的表达样本、48 种结构确认单药、3,183 条评分 | 主要 PDO 建模与验证 |
| Zhu | 20 个配对模型、54 种药、1,080 条响应 | 第二 PDO 队列验证 |
| LINCS GSE92742 | 药物处理表达、对照和扰动签名 | 转录扰动建模 |
| ChemPert | 多来源药物转录响应及元数据 | 扰动数据补充、跨来源评价 |
| Kuo、Herranz-Ors | 类器官表达、基因组或基因依赖数据 | 后续无标签表征与生物学支持分析 |

表中为当前目录记录的规模；正式实验数量以身份、药物、表达和标签审计后的冻结清单为准。不同来源的数量不能直接相加解释为独立样本数。

### 2. 数据标准化

#### 身份与药物

- 建立统一细胞系、PDO、患者和药物身份表。
- 药物匹配核对结构、盐型和立体化学，保留原始名称。
- 原始数值和文件只读保存，标准化结果另行生成。
- 无法支持结构编码的药物单独登记，不改写成近似结构。
- 同一记录重复收录时去重；同一模型在不同研究中的独立测量保留研究来源。

#### 基因表达

建立三个并行输入版本：

1. **基因表达版本**：用于线性模型、神经网络及预训练表示。
2. **通路活性版本**：用于低维建模和生物学解释。
3. **扰动基因版本**：用于给药前后变化预测，优先使用可靠实测基因。

不同模型按自身输入合同使用数据，不把所有药敏数据统一压缩到 978 基因。

归一化按原始数据类型分别处理；对已经取对数的数据不重复变换。特征筛选、缺失值填补和跨样本标准化均只在训练集拟合。

#### 药物响应

- 统一为数值越高表示越敏感。
- 保留 DSS、AAC、AUC、PRISM 响应等原始终点名称和单位。
- 不将不同实验终点直接拼成同一个回归目标。
- 多来源模型采用共享表示、研究特异输出头。
- 未测响应不补为零，不解释为耐药。

### 3. 必须完成的数据分析

| 分析 | 具体内容 | 用途 |
|---|---|---|
| 覆盖分析 | 样本、药物、基因、通路及来源交集 | 明确各项实验实际可用范围 |
| 标签分析 | 每药样本量、响应分布、变异、重复一致性 | 判断预测难度与标签质量 |
| 跨研究一致性 | 相同细胞系—药物组合的响应关系 | 区分模型误差与实验体系差异 |
| 表达差异 | 细胞系与 PDO 的表达、通路分布差异 | 确定迁移面临的主要变化 |
| 患者身份 | 显式映射、推断分组、重复取样 | 防止患者信息泄漏 |
| 扰动质量 | 对照匹配、重复、剂量时间、基因覆盖 | 确定转录变化是否可学习 |

降维图只用于描述数据，不把两类样本在图中靠近作为迁移成功证据。

## 三、任务定义与评价协议

### 1. 区分两个排序问题

**任务 A：同一种药在不同患者之间排序。**

回答哪些患者对该药更敏感，主要检验模型是否学习到患者差异。

**任务 B：同一个患者的不同药物之间排序。**

回答应优先验证哪些药物，是最终应用目标。

两个任务分别评价。逐药标准化适合研究患者间差异，但不能直接替代患者内跨药物排序分数。

患者内排序以同一研究、可比较筛选条件下的响应为依据。若药物剂量范围不一致，结果解释为“该筛选条件下的候选优先级”。

### 2. 数据划分

| 场景 | 划分单位 | 主要问题 |
|---|---|---|
| 细胞系内部验证 | 细胞系身份 | 能否预测未见细胞系 |
| 跨研究验证 | 研究来源，并区分细胞身份是否重合 | 能否跨实验体系泛化 |
| PDO 验证 | 患者；身份不足时按模型分组 | 能否预测未见 PDO |
| 新药验证 | 药物身份或结构骨架 | 能否推广到未见药物 |
| 扰动预测 | 化合物、细胞背景及相关重复组 | 能否预测未见处理条件 |

主任务为**已知候选药物对未见 PDO 的排序**。新药泛化作为次级任务，避免同时承担过多外推目标。

Kryeziu 的患者身份确认子集用于患者级主分析；名称推断分组的扩展分析单独报告。Zhu 若无进一步患者映射，结论限定为模型留出。

### 3. 主要指标

- 患者内排序：NDCG@5 为主要指标，Spearman 和 Top-5 重合率为补充。
- 患者间差异：逐药跨患者 Spearman。
- 数值预测：同一研究终点内的 MAE、RMSE。
- 个体信息贡献：同癌种表达整行置换、训练均值表达替代。
- 稳定性：不同划分、随机种子和训练样本量下的排名变化。

所有方法在同一可评价药物集合上比较；未测药不计为错误。患者拥有多个 PDO 时先在患者内汇总，再患者等权统计。

## 四、路线一：从简单模型逐步发展到通路深度模型

### 阶段 1：统计基线与可解释机器学习

首先建立以下模型：

| 模型 | 输入 | 要回答的问题 |
|---|---|---|
| 每药训练均值/中位数 | 药物身份 | 仅靠药物总体效应能达到什么水平 |
| 仅药物模型 | 分子指纹 | 不使用患者信息能达到什么水平 |
| 每药 Ridge/ElasticNet | 基因表达或通路活性 | 简单表达关系能否解释患者差异 |
| 共享交互模型 | 通路活性、药物指纹及低维交互 | 多种药能否共享可迁移规律 |
| 梯度提升树 | 通路活性＋药物特征 | 非线性关系是否带来额外收益 |

通路特征首先采用固定版本的 Hallmark 基因集和单样本秩评分；Reactome 作为扩展敏感性分析，避免首轮引入大量高度重叠通路。

这一阶段同时比较：

- 基因表达与通路特征；
- 泛癌训练与结直肠癌相关训练子集；
- 单来源训练与多来源训练。

**阶段产物：**可靠基线、关键通路关联、误差分布和数据量学习曲线。简单模型即使表现最好，也保留为正式候选模型。

### 阶段 2：小型神经网络

建立低容量双分支模型：

```text
通路活性 → 通路编码器 ┐
                     ├→ 交互层 → 研究特异药敏输出
药物指纹 → 药物编码器 ┘
```

依次比较：

1. 简单拼接；
2. 低维乘性交互；
3. 通路条件化的药物交互。

一次只改变一种交互方式。先使用普通回归损失，再加入患者内或细胞系内药物排序损失。

该阶段用于判断深度交互是否确有必要，不提前加入扰动生成、复杂图网络和域对抗模块。

### 阶段 3：近期方法与预训练表示

在前两阶段协议稳定后，引入：

- **DiSPA**：主要通路深度模型，建模药物子结构与通路表达交互。
- **PharmaFormer**：场景匹配的迁移学习对照。
- **scFoundation 冻结表示＋统一预测头**：检验表达预训练是否提供增益。

先验证官方实现，再接入统一数据协议。模型间保持相同数据划分和相近调参预算；论文原始终点不同的，明确区分“原方法复现”与“本项目任务适配”。

DiSPA 的原始通路设置用于方法复现；替换通路集合属于单独消融，不与模型结构变化同时进行。

相关方法依据：[DiSPA](https://pmc.ncbi.nlm.nih.gov/articles/PMC13340222/)、[PharmaFormer](https://github.com/zhouyuru1205/PharmaFormer/)、[scFoundation](https://github.com/biomap-research/scFoundation)。

### 阶段 4：多来源学习

分别完成 GDSC2 和 CTRPv2 单来源建模后，训练共享编码器、独立响应头的多来源模型：

- 研究间均衡采样；
- 留出细胞身份从全部来源同时排除；
- 不强制不同终点预测为同一绝对数值；
- PRISM 只用于固定协议的跨研究评价。

多来源版本必须与最佳单来源版本比较，检验增加数据是否带来收益或负迁移。

## 五、PDO 迁移：从无适配到小样本微调

### 1. 适配方式

按复杂度递增比较：

1. **零样本预测**：仅细胞系训练，直接应用于 PDO。
2. **输出校准**：冻结编码器，只训练 PDO 输出层。
3. **小型适配器**：冻结主体网络，训练低容量适配模块。
4. **部分微调**：解冻最后一层交互模块。
5. **完整微调**：作为高自由度对照，不默认作为最终方案。

相同特征下的 PDO Ridge 和从头训练的小网络始终保留，以检验源域预训练的实际价值。

### 2. 训练目标

基础目标为 PDO 原始终点方向一致后的回归。

随后分别加入：

- 患者内药物排序目标；
- 同药跨患者的敏感性残差目标。

最后才评价组合目标。这样能够区分“改善整体药物排序”和“改善患者特异性预测”。

### 3. 小样本学习曲线

采用外层 5 折分组评价、内层 3 折选模；同一患者的全部样本保持在同一折。

固定外层测试对象，在训练患者的 20%、40%、60%、80%、100% 五个比例下重复抽样，比较：

- 从头训练；
- 细胞系预训练后校准；
- 小型适配；
- 部分微调。

这项实验回答两个实际问题：

- 预训练在多少 PDO 样本时开始有帮助？
- 继续增加患者药敏数据，预计能否改善模型？

Kryeziu、Zhu 首先分别适配与评价；跨癌种迁移作为独立实验，不与同癌种小样本适配合并解释。

## 六、路线二：由实测转录变化到预测扰动，再到排序

### 阶段 1：建立实测扰动基准

先不训练复杂生成模型。

从 LINCS 与 ChemPert 中构建：

```text
处理前/匹配对照表达
＋药物、剂量、时间
→ 处理后表达或差异表达
```

要求：

- 化学处理与遗传扰动分开；
- Level 3 表达差值与 Level 5 标准化签名分开；
- 同一化合物的重复及相关处理记录按任务要求成组划分；
- ChemPert 中与 LINCS 重合的记录不能跨训练集和测试集；
- 无可靠对照的记录不作为表达差值监督标签。

### 阶段 2：先研究“变化与药敏的关系”

在药物和细胞身份可匹配的范围内，分析实测扰动与药敏的关系：

1. 整体扰动强度；
2. 增殖、细胞周期、凋亡等通路变化；
3. 疾病签名逆转；
4. 药物和细胞背景相同情况下的剂量、时间差异。

比较三类解释：

- 扰动越强是否越敏感；
- 特定通路变化是否更有预测价值；
- 疾病逆转是否具有独立于总体扰动强度的价值。

疾病签名采用与癌种匹配的肿瘤—正常差异；PDO 相对其他 PDO 的差异另称“样本差异特征”。缺少正常参照时不声称实现患者特异性疾病逆转。

### 阶段 3：由简单模型过渡到 XPert

依次建立：

| 层级 | 模型 |
|---|---|
| 基础参照 | 无变化、训练平均扰动、已见药物平均扰动 |
| 简单预测 | Ridge：基线表达＋药物特征＋剂量时间 → 表达变化 |
| 小型深度模型 | 条件化多层感知机或低维编码器 |
| 生成式对照 | TranSiGen |
| 近期主模型 | XPert |

评价重点是**表达变化**，不是仅评价处理后总表达：

- 变化相关性与误差；
- 上下调方向一致性；
- 差异基因恢复；
- 通路变化一致性；
- 未见药物、未见细胞背景的表现。

使用公开权重时检查训练数据范围。若测试样本已在权重训练中出现，该结果不能用于证明未见条件泛化。

方法依据：[TranSiGen](https://www.nature.com/articles/s41467-024-49620-3)、[XPert](https://www.nature.com/articles/s42256-025-01165-w)。

### 阶段 4：从扰动预测转为排序

固定以下评分，不在外部测试集上选择公式：

- 基因级逆转：负余弦相似度；
- 排名型逆转：上下调基因秩富集；
- 通路级逆转：疾病通路偏离与药物通路变化的反向一致程度。

分别报告实测扰动评分与预测扰动评分，区分：

- 评分规则本身是否有效；
- 扰动预测误差造成多少损失；
- 从细胞系到 PDO 又增加多少不确定性。

若实测逆转分数与药敏关联不足，保留其机制分析用途，不继续假定提高表达预测精度就必然改善药敏排序。

## 七、两条路线的联合与通路解释

### 1. 联合顺序

先比较三个独立结果：

1. 直接药敏模型；
2. 扰动/逆转排序；
3. 简单联合模型。

第一版联合模型使用低容量回归或排序模型，输入：

- 直接药敏预测；
- 扰动通路特征；
- 逆转分数；
- 扰动预测可靠性。

联合训练使用内层交叉验证产生的留出预测，避免拿训练样本上的过拟合分数训练第二层模型。

只有简单联合稳定有效，才扩展为共享通路表示的多任务网络。

### 2. 通路解释的证据层次

| 层次 | 分析 | 可以支持的表述 |
|---|---|---|
| 关联 | 通路活性与药敏关系 | 该通路与响应相关 |
| 模型贡献 | 特征归因、通路移除 | 模型依赖该通路信息 |
| 稳定性 | 不同划分、种子与患者的重复性 | 解释具有一定稳健性 |
| 扰动支持 | 实测或预测处理后的通路变化 | 存在作用方向的支持 |
| 独立支持 | 未输入模型的依赖性或机制资料 | 获得额外生物学证据 |

设置保持通路大小的随机基因分组、随机通路移除和表达置换对照。注意力权重不单独作为机制证明，模型内部通路移除也不等同于真实生物学干预。

## 八、实施、验收与论文产出

### 1. 训练与工程安排

- 使用 RTX A5000 24 GB，深度模型启用混合精度；是否冻结、部分微调按阶段比较。
- 预训练特征缓存，LINCS 按批读取，不反复生成全量副本。
- 简单模型使用固定参数网格；深度模型每种架构首轮最多 12 组配置。
- 内层验证选定配置后，运行 3 个训练种子。
- 最大训练 200 轮，验证指标连续 20 轮无改进早停。
- 扰动预测使用独立验证指标，不由 PDO 测试结果选择权重。
- 统一模型接口：输入表达、药物和可选处理条件；输出响应、排序与解释结果。
- 固定数据版本、划分清单、代码版本、模型配置和逐样本预测，支持复现。

### 2. 必须通过的检查

- 患者、细胞系和药物划分无违规重叠；
- 预处理参数只来自训练数据；
- 基因顺序、药物结构和响应方向一致；
- LINCS/ChemPert 无重复记录跨集合泄漏；
- 排名指标对候选数量、缺测和并列值处理一致；
- 每次模型扩展均有删除该模块的对照。

### 3. 结果判断

- 以患者或模型为单位做 2,000 次配对重采样，报告模型增益的 95% 区间。
- 排名改善但表达置换无影响：支持总体候选排序，不足以支持个体化。
- 逐药患者差异改善但患者内排序未改善：支持敏感性分层，不宣称改善候选药物排序。
- 扰动预测改善但药敏排序未改善：支持转录预测能力，不宣称药筛收益。
- 区间较宽或跨零：报告证据不足，并结合学习曲线判断样本量限制。

### 4. 阶段交付

| 阶段 | 主要交付 |
|---|---|
| 数据阶段 | 数据合同、身份与覆盖审计、固定划分、描述性分析 |

| 联合阶段 | 两条路线消融、通路证据、最终排序及稳定性 |
