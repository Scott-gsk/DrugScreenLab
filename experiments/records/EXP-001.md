## 唯一 hypothesis

当前 DrugScreenLab 的数据资产、身份体系和预处理基础能够被整理成可审计、可复现、
无明显 identity leakage，且支持后续 `Δ978` perturbation benchmark 的 Phase-0
research data foundation。

本实验不检验模型优越性，不训练 XPert、UniPert 或 organoid 模型。

## 范围

1. 审计 repository、WSL2、`drugscreening-gpu`、CUDA/GPU、依赖、测试、磁盘、内存和实际数据路径。
2. 输出 P0 dataset readiness matrix：dataset ID、accession/version、意图角色、本地与来源可用性、校验和、metadata、许可、预处理与 blocker。
3. 扩展 registry schema，使其可表达已批准字段，但不改 raw data。
4. 建立可测试的 compound、gene、context、donor、control 和 replicate-family identity contracts。
5. 判定 `GSE92742` 的 Level-3 中按 `gene_info.pr_is_lm=1` 标记的 978 landmark
   core 是否可用，并将其与 inferred non-landmark genes 严格分开；Level-2 是可选的
   直接测量资源，不是 Level-3 landmark-core `Δ978` 的硬依赖。
6. 建立 Phase-0 最小测试与正式报告。

## 禁止事项

- 不训练完整 XPert、UniPert 或 organoid 模型。
- 不使用 `GSE117548` 进行 training/tuning。
- 不构建新的 `SMILES + Expression -> IC50` predictor。
- 不将 L1000 inferred genes 当作真实 whole-transcriptome ground truth。
- 不修改 raw data、不提交大型数据或模型 artifact、不伪造 unavailable dataset。

## 主要终点与 Go/No-Go

主要终点为 `phase_0_readiness_verdict`：`READY`、`PARTIAL` 或 `BLOCKED`。

只有在以下条件均有可核查证据时，结论才可为 `READY`：环境与测试可复现；registry
validation 通过；Level-3 landmark-core `Δ978` 前提确认；identity contracts 和 split
leakage assertions 存在；raw data 未修改；所有 blocker 已记录。否则必须选择
`PARTIAL` 或 `BLOCKED`，不得用推断表达或未确认来源填补缺口。
