## Primary Hypothesis

在冻结的 GSE92742 Level-3 exact-978 landmark space、matched vehicle、compound/context
identity 与 leakage-safe cold split contract 下，context-conditioned `Delta978` baseline
能够在 cold-drug 和 cold-context 评估中稳定优于无条件简单 baseline。

## Scope And Boundaries

- 只使用官方 GSE92742 Level-3 的 `pr_is_lm=1` exact 978-gene core。
- 同 `rna_plate + cell_id + time` vehicle matching；当前已知无有效 vehicle 的 247 个
  chemical treatment instances 必须排除。
- 不将 inferred non-landmark genes 用作 core target 或 reliable extended-gene ground truth。
- 不扩展至 UniPert、Drug--Target--Pathway、reliable gene expansion、disease reversal 或
  organoid transfer；不实现复杂 XPert architecture。
- 新的外部事实 blocker 必须完成 `PRIMARY_SOURCE_VERIFICATION`。

## Gates

- Gate A: exact-978、identity、matched-control 和 split 审计通过。
- Gate B: context-conditioned baseline 相比 global baseline 的预定义改善在多 seed 下稳定。
- Gate C: cold-drug 与 cold-context 分开报告，不能以 random/in-domain 结果替代。
- Gate D: dataset、split、config、seed、source revision 和 artifact 可定位、可重跑。

主要指标为 Pearson、Spearman、RMSE、MAE、direction accuracy；按 drug、context、gene 和
OOD stratum 分层，并报告 bootstrap CI、seed 稳定性、baseline difference 与 failure strata。
Gate B/C 失败允许形成 `VALID negative result`；不得为取得正结果改变 test set、split、
threshold 或 metric。

## Final Evidence And Outcome

- Gate A: `PASS`。`671,881` matched treatments，`247` 无 vehicle exclusions；cold-drug 与
  cold-context 的 treatment、replicate family、raw vehicle 和 cold entity cross-split count 均为 0。
- Gate B: `FAIL`。cold-drug Pearson 的 context-minus-global paired improvement 为 `+0.019961`
  （95% bootstrap CI `+0.017366` 到 `+0.022800`）；cold-context 的 `6,826/6,826` test groups
  均是未见 context，按冻结 fallback 使用 global mean，Pearson improvement 为 `0`。
- Gate C: `PASS`。两种 OOD stratum 分开报告；cold-context 的零改善没有被 cold-drug 的正改善掩盖。
- Gate D: `PASS`。独立 Reviewer 使用规定 Conda runtime 复核为 `VALID`，关键测试 `21 passed`、
  registry `PASS`；全库测试为 `40 passed`。结果 artifact `baseline_metrics.json` SHA-256 为
  `ced27699c455f8ac5fdc4d992c91c74d0e1d90213f5427259f10b341a55f646f`。

因此主 hypothesis 为 `NOT_SUPPORTED`：该 context-mean baseline 对 cold-drug 有可重复统计改善，
但不能在 cold-context 上超过 global baseline。该结论是负结果，不得表述为模型整体 OOD 成功。

## Accepted Interpretation And Method Lesson

- EXP-002 已证明 `Level-3 exact-978 -> matched vehicle -> Delta978 -> leakage-safe cold split`
  的数据与评价链路可以可靠运行。
- cold-drug 中的稳定正增益只说明该 **seen-context statistical baseline** 存在预测信号；它不证明
  任意 context-conditioned model 已获得整体 OOD 成功。
- cold-context 的 `6,826 / 6,826` group 均按预注册规则使用 `global_train_mean` fallback，候选与
  global baseline 完全相同。因此零改善是该 baseline 的能力边界，**不是** "biological context
  对 unseen-context perturbation prediction 没有价值" 的科学证据，也不否定 context-conditioned
  perturbation modelling 的可行性。
- 精确结论：当前依赖已见 context 统计量的简单 baseline 可为 cold-drug 提供一定 predictive signal，
  但自身不具备向 completely unseen context 外推的能力。
- 全量 Level-3 extraction 只应作为经 provenance 验证的数据构建步骤。其 exact-978 cache 已登记为
  可复用 processed asset；后续获批 EXP 应复用该版本。若必须重建，Research Manager 必须在实验
  记录中说明 source、contract、runner 或 cache-integrity 发生了何种变化。
