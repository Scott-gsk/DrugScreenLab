## Primary Hypothesis

在冻结的 GSE92742 exact-978 contract 上，一个只使用训练集中配对 vehicle expression 预处理得到的
低容量 context representation，与 drug/dose/time 主效应进行正则化交互后，能在预注册 cold-context
test split 的 group-level paired Pearson 上严格优于 global baseline，且不访问 held-out context 的
treatment labels 或统计量。

## Why This Is The Correct Next Experiment

它直接填补 EXP-002 的 fallback capability boundary，且只依赖已验收的 GSE92742 与 exact-978 cache。
它是 Phase 1 的最小可证伪 context encoder 检验；若不先证明这一点，直接进入 XPert、UniPert、
Drug-Target-Pathway 或 sci-Plex 会失去能力归因。总实施方案也明确要求 context pipeline 采用平台内
relative/rank/bin representation，而不把 RNA-seq 伪造为 LINCS Level-3 值。

## Required Datasets / Roles

- Dataset: `lincs_gse92742_exact978_cache_v1`，只读，连同 EXP-002 frozen split/data contract；不需
  下载、重新扫描或重构 65 GB Level-3 matrix。
- Roles after approval: Data Steward（contract/dry run）、Model Engineer（低容量模型）、Evaluation
  Analyst（paired cold-context protocol）、Independent Reviewer。Scientific Analyst 不在本最小实验的
  critical path。

## Baselines / Controls

- EXP-002 frozen global mean baseline。
- EXP-002 seen-context mean baseline，必须在 unseen context 显式报告 fallback，不能作为成功比较对象。
- Drug/dose/time-only regularized baseline，与候选使用同一 train split、同一 target、同一 optimization
  budget；候选只增加预处理 context representation。
- Negative leakage controls：held-out context label permutation、test-label isolation、vehicle/raw instance
  split exclusivity，以及全零/常量 vector 行为。

## Primary Evaluation

主终点为 cold-context held-out `(compound, context)` group 的 paired Pearson
`candidate - global`，95% paired group bootstrap CI 必须大于 0。次要指标为 Spearman、RMSE、MAE、
direction accuracy、fallback fraction 与 context OOD strata。cold-drug 仅作为诊断性报告，不能替代
cold-context 主终点；随机/in-domain 指标不构成成功证据。

## Go / No-Go

- `GO`: primary CI 下界大于 0，所有 leakage/provenance gates 通过，且候选不退化为 global/fallback。
- `NO-GO`: CI 包含 0、候选在 unseen context fallback、任何 test-label/control leakage、或 dry run
  暴露不可复现的 cache/manifest binding。NO-GO 只否定本 context representation，不否定 biological
  context 或后续机制先验的价值。

## Main Failure Modes

- Level-3 vehicle profile 不能作为真实 untreated context，或其 normalization 与 target 泄漏耦合。
- cold-context split 使候选药物主效应也无法由 train 估计，导致问题定义混淆。
- cache/contract 版本或 split manifest 不一致。
- 高容量 encoder 在少量 context 上过拟合，或由 test context aggregate 泄漏获得表面改善。

## Expected Evidence If Positive

在无泄漏的 completely unseen context 上，预处理 context representation 为条件化预测提供超越 global
mean 的信号。该结果只支持继续研究 Phase-1 context encoder，不宣称 disease/PDO、mechanism transfer
或 whole-transcriptome generalization 已成立。

## Interpretation If Negative

当前低容量、vehicle-derived representation 未能为 unseen context 提供可用外推；后续应先检查
context measurement/normalization、drug-main-effect overlap 和更有信息量的 context prior，而不是把
负结果解释为 context biology 无价值或直接堆叠更复杂模型。
