## Primary Hypothesis

在冻结的 GSE92742 exact-978 contract 上，加入 train-fitted vehicle-control proxy context
representation 的低容量模型，在相同 drug/dose/time、train split、target、优化预算和 scoring code
下，能在预注册 cold-context `primary_supported_drt` strata 的 group-level paired Pearson 上严格优于
matched drug/dose/time-only baseline，且不访问 held-out context treatment labels、test aggregate
statistics 或与 target 共享的 raw control。

## Why This Is The Correct Next Experiment

它直接填补 EXP-002 的 fallback capability boundary，且只依赖已验收的 GSE92742 与 exact-978 cache。
它是 Phase 1 的最小可证伪 context encoder 检验；若不先证明这一点，直接进入 XPert、UniPert、
Drug-Target-Pathway 或 sci-Plex 会失去能力归因。总实施方案也明确要求 context pipeline 采用平台内
relative/rank/bin representation，而不把 RNA-seq 伪造为 LINCS Level-3 值。

## Frozen Data And Shared-Control Leakage Gate

本实验中的 context 不是同一 biological sample 的纵向 pre-treatment measurement，而是
`vehicle-control proxy for pre-perturbation context`。它只在推理场景能于 treatment expression
之前取得同 context、time、plate 的独立 vehicle profile 时允许作为输入；GSE92742 证明该历史
实验中存在这种 proxy，但不证明未来 disease/PDO 场景必然可得。因此本 EXP 的任何正结果只能
支持该 **observable-proxy benchmark**，不得表述为不需额外 control 测量的泛化。

Data Steward 冻结 `EXP-003-shared-control-gate-v1`：在每个 split/matching key 内，以固定 hash
将 raw vehicles 分为非空、互斥的 `context_proxy_control_ids` 与 `delta_reference_control_ids`。
每个 target 为 `treatment - mean(delta_reference_control_ids)`；模型的 context input 仅来自前者。
proxy/reference raw `inst_id` 交集必须为 0，且候选、DRT-only、global 和所有诊断使用完全相同的
reference partition。test vehicle 可以作为该预测实例的观测输入，但不得参与任何 train/validation
统计、normalization、PCA、feature selection、bin edge、imputation、model selection 或 fallback。

所有 transformation 参数仅由 train proxy controls 拟合，validation/test 只应用固定参数。主分析
使用固定角色分割；必须进行 leave-one-control-out role sensitivity，并报告 proxy/reference Pearson
或距离分布、vehicle-count strata 和因 control 不足被排除的 cohort。`design_gate_audit.json` 已确认
7 个 test contexts、46,222 个 test treatments、130 个 test matching keys，且 `130/130` 有至少两条
vehicle；它不读取表达矩阵，也不替代执行前的 role-assignment manifest。

该 DATA GATE 当前为 `DATA_PARTIAL`：metadata 支持 raw-instance 独立分割，但真实 deployment 的
vehicle-proxy acquisition contract 尚未被证明。批准后的 execution 必须先生成小型 manifest/audit；
任一 raw-ID overlap、test vehicle 参与 train statistic、无 acquisition contract、或静默改变 cohort
均为 `FAIL`，不得训练。

## Baselines / Controls

- Matched drug/dose/time-only regularized baseline，与候选使用同一 train split、target、输出头、
  optimizer/schedule、early-stop、seed、hyperparameter budget 和 scoring code；候选只增加 context
  representation 路径，并报告参数量。
- EXP-002 frozen global mean baseline，只作为 sanity/reference，不构成 GO 依据。
- EXP-002 seen-context mean baseline，必须在 unseen context 显式报告 fallback，不能作为成功比较对象。
- Supporting diagnostics：held-out context proxy permutation、proxy/reference role swap、leave-one-control-out、
  zero/constant proxy、test-label isolation 与 feature-provenance assertions。若共享 reference 时才有
  增益，或 proxy permutation 后增益仍在，则为 shortcut `FAIL` 而非成功。

## Pre-registered Cold-context Strata

`design_gate_audit.json` 在不读 expression matrix 的前提下冻结了 test support：100% (`46,222/46,222`)
test treatments 的 drug 在 train 出现；`46,212` treatments / `13,805` DRT groups 属于
`primary_supported_drt`，另有 `10` treatments / `4` groups 属于 `seen_drug_novel_dose_time`。不存在
train-unseen drug test group。主 hypothesis **只**由 `primary_supported_drt` 检验；后者仅诊断
dose/time transfer。未来若 source/contract 变化产生 train-unseen drug groups，必须预先报告为
`unseen_drug_supported_dose_time` 或 `unseen_drug_novel_dose_time` 诊断 strata，不得混入主要结论。

## Primary Evaluation

主终点为 cold-context `primary_supported_drt` group 的 paired Pearson
`candidate - matched DRT-only`。以 held-out `context_id` 为 cluster bootstrap unit（2,000 resamples，
95% CI），每个 sampled context 保留其全部 group；不得 bootstrap genes、technical replicates 或把同一
context 下 drug 当作独立 context。预注册 seeds 为 `17, 29, 43`；每个 seed 的 paired point improvement
必须为正，seed ensemble 的 CI 下界必须大于 0。Spearman、RMSE、MAE、direction accuracy、fallback、
undefined correlation 和其他 strata 为 supporting diagnostics，不能替代 Pearson 主终点。cold-drug、
random/in-domain 均不能替代 cold-context 主检验。

## Go / No-Go

- `GO`: primary contrast 的 CI 下界大于 0、每个 seed 为正、candidate/DRT-only cohort 完全一致，
  shared-control/null/permutation/provenance gates 通过，且 candidate 不退化为 DRT-only/fallback。
- `NO-GO`: primary CI 包含 0、任一 seed 非正、context fallback、candidate 优势只在共享 control 时存在、
  proxy permutation 后优势仍在、任一 test-label/control leakage，或 dry run 暴露 cache/manifest binding
  不可复现。NO-GO 只否定该 proxy representation 的增量预测证据，不否定 biological context 或后续机制
  先验的价值。

## Main Failure Modes

- vehicle proxy 不可于真实推理获取，或其 train-fit-only transformation 与 target 有 shared-control shortcut。
- DRT-only baseline 在主要 strata 外缺少训练支持，导致问题定义混淆。
- cache/contract 版本或 split manifest 不一致。
- 高容量 encoder 在少量 context 上过拟合，或由 test context aggregate 泄漏获得表面改善。
