# EXP-005 XPert Additive KPGT and UniPert Perturbagen Tokens

## Status

`FAST_RESULT_READY · NO_MATERIAL_FAST_INCREMENT`

本实验由用户在 XPert Foundation Reset 指令中明确授权自动执行；它是首个 Novel Extension，
不是 Foundation reproduction。`EXP-004` 的遗传→化学 FAST 结果保持不变，不被本实验覆盖或重解释。

## Hypothesis

在官方 XPert 的 HG + UniMol perturbagen 路径、transformer、loss 与处理流程不变的前提下，
将官方 KPGT 与冻结 UniPert chemical representation 分别投影到 XPert hidden size 并作为独立
drug tokens 追加，能够相对未修改的 XPert 在 fixed cold-cell / cold-drug 设置中提高 Delta978
预测，并在 response-blind freeze 后的 CRC Disease Reversal → Broad PRISM ranking 中显示一致增益。

## Fixed model comparison

| Model | Perturbagen sequence |
| --- | --- |
| A | 官方 XPert：HG + UniMol（不改） |
| B | A + 一个独立 KPGT token |
| C | A + 一个独立 KPGT token + 一个独立 UniPert token |

禁止：将 KPGT `2304d` 与 UniPert `256d` 在 XPert 外部直接拼接、替换 UniMol/HG、重写 XPert transformer、
使用 PRISM response 值训练、调参或选择模型。

## Data and split contract

- Official processed L1000 SDST：`data/external/xpert_source/processed_data/l1000_sdst_78453.h5ad`（local ignored；资产见 `mvp/foundation/xpert/ASSET_MANIFEST.json`）。
- Official feature assets：UniMol、HG、KPGT；UniPert global feature contract：`mvp/foundation/xpert/GLOBAL_UNIPERT_AUDIT.json`。
- Splits：`split_cold_cell_1` 与 `split_cold_drug_1`。每个 FAST partition 按官方 `sample_id` 稳定排序后取固定前缀；runner 记录 digest，并断言 cold-cell 的 train/test context 无交集、cold-drug 的 train/test drug 无交集。
- Dataset、seed、optimizer、loss weight、epoch budget、batch size 在 A/B/C 与两个 split 中完全固定；不使用 valid/test 选择 checkpoint。
- 生成的 Broad adapter 固定为 10 exact LINCS contexts × 1,836 feature-complete identity-matched perturbagens：`mvp/foundation/xpert/BROAD_GLOBAL_ADAPTER_AUDIT.json`。

## Evaluation contract

1. Held-out `Delta978`: MSE、per-row Pearson/Spearman、prediction std；不得 collapse。
2. Disease reversal: `-Spearman(CRC signed disease signature, Delta978)`，signature 为 `mvp/core_data/crc_disease_signature_exact978.tsv`。
3. Broad PRISM: frozen identity/context cohort 后才读取 response；continuous sensitivity ranking 在 `depmap_id × pert_id` 聚合后进行 exact-context join。
4. Observed LINCS Oracle: 仅在 observed treatment/control pair 存在时构建；仅作上限/coverage 参考，绝不参与拟合。

## FAST decision rule (pre-registered)

`PROMISING_FAST` 要求至少一个 additive variant 在 **cold-cell 与 cold-drug** 两个 held-out split 中都满足：

- 相对 A 的 per-row Delta978 Spearman 至少 `+0.02`；
- prediction std 有限且大于 `0.01`；
- 未使用任何 PRISM response 值做模型选择；
- Broad ranking 用作独立翻译诊断，报告 macro Spearman、NDCG@10、top-10 overlap，不作为调参依据。

若仅一侧 split 改善或未达到阈值，结论为 `NO_MATERIAL_FAST_INCREMENT`；只有达到该规则才启动更大 budget 的 MEDIUM loop。

## FAST result

六组正式运行均使用 seed `2026`、3 epochs、batch size `128`、每个 partition 固定 4,096 rows 和官方
XPert loss。冷 cell 的 train/test context overlap 为 0；冷 drug 的 train/test drug overlap 为 0；所有
预测 std 均大于 `0.01`。完整 compact result 与 contract digest 见
`mvp/foundation/xpert/EXP005_FAST_COMPARISON.json`。

| Split | Model | Held-out row Spearman | Gain over A | Prediction std | Broad PRISM macro Spearman | Broad NDCG@10 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| cold-cell | A: XPert | 0.086005 | 0 | 0.073870 | 0.013608 | 0.570892 |
| cold-cell | B: +KPGT | 0.081021 | -0.004984 | 0.133563 | 0.007641 | 0.601548 |
| cold-cell | C: +KPGT+UniPert | 0.056076 | -0.029930 | 0.144654 | -0.009184 | 0.574096 |
| cold-drug | A: XPert | 0.052936 | 0 | 0.117621 | -0.015543 | 0.508381 |
| cold-drug | B: +KPGT | 0.085001 | +0.032065 | 0.156298 | -0.023888 | 0.477089 |
| cold-drug | C: +KPGT+UniPert | 0.055838 | +0.002903 | 0.132358 | -0.030846 | 0.441979 |

判定：`NO_MATERIAL_FAST_INCREMENT`。B 只在 cold-drug 达到 `+0.02`，没有同时通过 cold-cell；C 两个
split 均未达到要求。Broad PRISM 是独立 translation diagnostic，未用于训练、调参或选模；additive
variants 也没有显示一致 downstream 增益。因此不启动预注册 MEDIUM loop，保留官方 XPert 作为当前
foundation baseline，并将 token overlay 标记为未获 FAST 支持，而不把一次 negative additive probe
解释为 KPGT 或 UniPert 的整体失败。
