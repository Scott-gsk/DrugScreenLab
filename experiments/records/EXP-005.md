## Hypothesis

在官方 XPert 的 HG + UniMol perturbagen 路径、transformer、loss 与处理流程不变的前提下，
将官方 KPGT 与冻结 UniPert chemical representation 分别投影到 XPert hidden size 并作为独立
drug tokens 追加，能够相对未修改的 XPert 在 fixed cold-cell / cold-drug 设置中提高 Delta978
预测，并在 response-blind freeze 后的 CRC Disease Reversal → Broad PRISM ranking 中显示一致增益。

## Evaluation contract

1. Held-out `Delta978`: MSE、per-row Pearson/Spearman、prediction std；不得 collapse。
2. Disease reversal: `-Spearman(CRC signed disease signature, Delta978)`，signature 为 `mvp/core_data/crc_disease_signature_exact978.tsv`。
3. Broad PRISM: frozen identity/context cohort 后才读取 response；continuous sensitivity ranking 在 `depmap_id × pert_id` 聚合后进行 exact-context join。
4. Observed LINCS Oracle: 仅在 observed treatment/control pair 存在时构建；仅作上限/coverage 参考，绝不参与拟合。

## FAST decision rule (pre-registered)

`PROMISING_FAST` 要求至少一个 additive variant 在 **cold-cell 与 cold-drug** 两个 held-out split 中都满足：

- 相对 A 的 per-row Delta978 Spearman 至少 `+0.02`；
- prediction std 有限且大于 `0.01`；
- 未使用任何 PRISM response 值做模型选择；
- Broad ranking 用作独立翻译诊断，报告 macro Spearman、NDCG@10、top-10 overlap，不作为调参依据。

若仅一侧 split 改善或未达到阈值，结论为 `NO_MATERIAL_FAST_INCREMENT`；只有达到该规则才启动更大 budget 的 MEDIUM loop。

## FAST result

### ATTEMPT-1 corrected interpretation

ATTEMPT-1 的 A/B/C 均重新随机初始化，仅使用 4,096-row、2-epoch FAST budget；A 明显低于已验证的 XPert Foundation champion。因此该运行没有检验 strong XPert 上的 additive extension，正式状态为 `INCONCLUSIVE_PROTOCOL_MISMATCH`，而不是 extension 的科学 Go/No-Go。

### ATTEMPT-2 protocol

`ATTEMPT-2_STRONG_FOUNDATION_EXTENSION` 直接加载 XPert Foundation champion。B/C 从 A 完整继承 Context Encoder、UniMol、HG、gene embedding、self-attention、cross-attention 与 prediction heads；KPGT/UniPert 仅经 projection + learnable gate 注入，gate 初始为 0。训练首阶段冻结 Foundation，只更新 projection/gate/必要 normalization，并在训练前执行 A ≈ B(gate=0) ≈ C(gate=0) baseline-equivalence test；仅在 frozen-extension 出现 signal 后 progressive unfreeze 最后 drug self-attention 与 drug→gene cross-attention block。

ATTEMPT-2 实现已改为 gated residual fusion 到既有 HG/global compound representation，保持序列长度不变。Strong checkpoint 加载 `182/182` official keys；A 不训练，B/C 仅训练新增 projection/gate。A 的 256-row cold-cell dry-run row Spearman=`0.63587`；同 checkpoint、64-row、1-epoch bounded B/C 分别为 `0.6328307/0.6328390`。这是 protocol validation，不是正式 OOD effect size；未观察到值得扩大 architecture search 的信号。按用户指令，EXP-005 chemical fusion 关闭，Chemical Backbone Champion 选为 `XPert Foundation`。

ATTEMPT-1 的 compact 记录显示固定 seed `2026`、batch size `128`、每个 partition 固定 4,096 rows；用户复核指出实际运行仅 2 epochs。该 budget 与 foundation champion 不兼容，故不用于 extension 结论。冷 cell 的 train/test context overlap 为 0；冷 drug 的 train/test drug overlap 为 0；所有预测 std 均大于 `0.01`。完整 compact result 与 contract digest 见
`mvp/foundation/xpert/EXP005_FAST_COMPARISON.json`。
