# EXP-009 — BindingDB 结构驱动软靶点—通路表示

## 已批准实验问题

**唯一问题：** BindingDB 结构驱动软靶点—通路表示是否能提高冻结 XPert 在完整 SDST cold-drug `Delta978` 的预测？

本记录仅冻结 EXP-009 的最小数据合同；不记录或使用 SDST response、任何药效、疾病签名或外部验证标签。

## 正式训练预算（用户确认，v2）

- 训练臂：`A`（冻结 XPert forward-only）、`B`（冻结 XPert + structure-only residual）与 `C`（冻结 XPert + BindingDB Morgan soft-target residual）。
- 数据与终点：官方 `l1000_sdst_78453` 的 `split_cold_drug_1`；完整 train `62,624` 行与完整 test `15,829` 行；主终点为 Delta978 test row-macro Spearman。
- 固定训练预算：三臂统一记为 `30 epochs`、`seed=2026`、`batch_size=128`、`lr=1e-3`、`hidden_dim=256`；禁止 validation/test early stopping 或按 test 结果选 epoch。
- 公平性：B/C 均从同一只读官方 XPert checkpoint 起始，仅训练 residual；A 不含可训练参数，但以同一数据、终点、seed 与结果协议产生基线预测。
- 交付约束：每个臂必须写入 `manifest.json`、`metrics.json` 与 `prediction_digest.npz`；三臂均完成前不解释 `B-A`、`C-A` 或 `C-B`。

## DATA CONTRACT（v1，最小）

| 字段 | 冻结定义 |
|---|---|
| experiment_id | `EXP-009` |
| training chain | `XPert_SDST_Delta978_only` |
| BindingDB source identity | 运行时必须提供本地 JSON，含非空 `release_id`、官方 `https://bindingdb.org/...` `source_url`、64 字符十六进制 `source_sha256`；构建器还记录所用本地 TSV 的 SHA-256。不得下载或使用未冻结的滚动版本。 |
| permitted BindingDB rows | 必须同时具有非空 InChIKey 与 canonical SMILES；`organism == Homo sapiens`；非空、可解析的 UniProt accession 字段；测定类型仅为 `Ki`、`Kd`、`IC50` 或 `EC50`；数值必须有限且严格大于零，单位限 `M/mM/uM/nM/pM`。 |
| BindingDB teacher table | `bindingdb_teacher.tsv` 保留**所有**满足结构、物种、UniProt 和定量条件的 BindingDB 记录，不要求属于 XPert/SDST 药物宇宙；它是外部大规模药靶知识的教师数据，包含 `bindingdb_id,inchi_key,canonical_smiles,uniprot_id,organism,measurement_type,value,unit,paffinity`。 |
| SDST identity bridge | `xpert_bridge.tsv` 仅对 teacher 表中 InChIKey 与冻结 `mvp/foundation/xpert/DRUG_REGISTRY.json`（`xpert_drug_registry_v1`）的 `global_inference_eligible == true` 药物作精确 join，字段为 `bindingdb_id,inchi_key,xpert_pert_id`。不重叠的 teacher 行不拒绝、不进入 bridge；重复或歧义 XPert InChIKey 立即失败。禁止名称/alias 模糊匹配。 |
| affinity target | `pAffinity = -log10(value_in_molar)`；保留原始 measurement type、value 与 unit。`Ki/Kd/IC50/EC50` 不等同，类型字段必须保留，禁止在合同阶段把它们解释为同一种机制量。 |
| output | `bindingdb_teacher.tsv` 与 `xpert_bridge.tsv`；`audit.json` 分别冻结 teacher 与 bridge 的行数、唯一身份数、XPert 覆盖、输入和输出 checksum、纳排规则及禁用输入。 |
| structure-only coverage | 覆盖分母是冻结 XPert `global_inference_eligible` 的**唯一、非歧义 InChIKey**身份；分子仅凭 SMILES、但无 InChIKey 时不计入可联接分母。最终 BindingDB 覆盖必须由冻结 archive 的实际 join 产出。 |
| gene universe | BindingDB 靶点宇宙是接受记录的 UniProt accessions。任何 UniProt→gene/pathway 映射必须是后续独立、版本固定的正式链步骤；本合同不伪造、推断或混入 `Delta978` 的 978 基因宇宙。XPert 输出空间保持上游冻结 exact `Delta978`。 |
| response / efficacy leakage | 构建器不得读取 SDST expression/response、任何药效值、疾病签名或外部验证标签；审计中固定 `response_values_read=false`、`efficacy_values_read=false`。 |

## 本地身份与结构资产审计（response-blind）

来源为冻结 `mvp/foundation/xpert/DRUG_REGISTRY.json`（`xpert_drug_registry_v1`；registry 内登记 SHA-256 `CA0765ACDE47ED790A399FC988380EE98B6C5BC050D6DF7DD6E3686552C1EF74`）。只读取结构身份字段和 eligibility 字段：

- `official_pert_ids`: 8,418
- `global_inference_eligible`: 8,418
- 有 canonical SMILES: 8,418
- 有 InChIKey 且有 canonical SMILES: 8,301
- 非空唯一 InChIKey: 8,265

因此，**XPert bridge 以 InChIKey 作严格对接的最大可审计分母为 8,265**；另有 117 个 XPert 药物缺少 InChIKey，不能在不降低身份标准的前提下保证 BindingDB→XPert bridge。BindingDB teacher 表不受该分母限制，保留全部合格的外部结构—靶点记录。尚无本地 BindingDB TSV 或 release metadata，故不能报告 archive 实际 teacher 规模或 bridge 覆盖数，也不能构成完整数据就绪。

## 构建器与执行

构建器：`scripts/data/build_exp009_bindingdb_contract.py`。

该脚本只接受本地 TSV，不下载大文件。调用示例（所有路径替换为已冻结资产）：

```bash
/home/dell/miniconda3/bin/conda run --no-capture-output -n drugscreening-gpu \
  python scripts/data/build_exp009_bindingdb_contract.py \
  --bindingdb-tsv /absolute/path/BindingDB_frozen.tsv \
  --release-metadata /absolute/path/bindingdb_release.json \
  --xpert-drug-registry mvp/foundation/xpert/DRUG_REGISTRY.json \
  --output-dir artifacts/experiments/EXP-009/bindingdb_contract
```

`bindingdb_release.json` 至少为：

```json
{
  "release_id": "BindingDB_YYYYMM",
  "source_url": "https://bindingdb.org/rwd/bind/chemsearch/marvin/<official-date-stamped-archive>",
  "source_sha256": "<archive-sha256>"
}
```
