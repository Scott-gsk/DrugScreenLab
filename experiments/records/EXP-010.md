# EXP-010：PharmaFormer → mCRC PDO → 乳腺癌 PDO 一日验证

- approved_on: 2026-08-23
- approval: 用户明确要求下载完整重要数据和 PharmaFormer 开源代码，并“实施此计划”
- seed: 20260823
- primary_endpoint: 患者等权的 PDO 内跨药 Spearman，M3 − M2

## 科学问题

GDSC2/CMP 预训练的 PharmaFormer（M2）经泄漏安全的 mCRC PDO 短程微调（M3）后，
能否改善同一批未见患者的单药 DSS 排序，并在公开乳腺癌 PDO 数据中获得方向一致的
外部支持？一天内目标是形成可汇报的定量结果或清晰的阻断证据，不把准备工作写成结果。

## 冻结数据合同

- PharmaFormer：官方仓库 commit `f526ddda4091151f082b38367571a94823314aba`，仅作外部薄适配。
- 预训练输入：GDSC2 release 8.5 的 fitted/raw response、compound 和 cell-line metadata，
  加 CMP `rnaseq_all_20220624.zip` TPM。若重建交集不等于论文的 87,596 对，明确报告实际值。
- mCRC：`data/raw/mcrc_pdo_2026/v3` S1–S5；仅单药 DSS，高值表示更敏感；技术重复 QC 后取中位数；
  counts 转 `log2(CPM+1)`，禁止标成 TPM。
- 乳腺外部输入：GSE303509 processed RSEM；GSE287429 normalized counts；GSE276609 processed
  packages；多区域乳腺 PDO 主文和全部六个补充文件；Reactome 官方 GMT。
- 药物结构：按 GDSC 主名称/同义词查询 PubChem，冻结 canonical SMILES、CID、InChIKey；排除组合。
- 原始输入只读；URL、版本、许可、bytes 与 SHA256 登记到数据注册表。

硬门槛：mCRC 药物结构映射率至少 90%；CMP/mCRC/GSE303509 有序共同基因至少 15,000；
mCRC 至少 40 位患者且每个主 PDO 至少 5 个可映射单药；患者/区域/PDO 不得跨折。

## 模型与划分

固定五个患者外折。测试折为 `k`，验证折为 `(k+1) mod 5`，其余三折训练；每位患者恰好
测试一次，其所有区域、PDO 和运行记录同折。全部 scaler、HVG、BPE、校准器只拟合训练折。

- M0：训练患者药物中位数。
- M1：训练折 top-512 HVG + drug ID 的 Ridge 与 Random Forest。
- M2：PharmaFormer，GDSC-only checkpoint，不看 mCRC 标签。
- M3：同一 checkpoint 在 mCRC 训练折短程微调（主干预）。
- M4：随机初始化、仅 mCRC 训练。

PharmaFormer 适配目标：gene 8192→8192、drug 256、hidden 128、3 层 Transformer、8 heads、
FFN 2048、Adam 1e-5。先做计时探针，再冻结 3–10 个 source epoch；target dropout 0.3、batch 4、
最多 30 epoch、validation patience 5。正式评测前不得读取测试标签选择 epoch、特征或阈值。

## 终点、统计与停止规则

主要指标为每 PDO 内跨药 Spearman，再按患者等权宏平均；次要指标 NDCG@5 和原始 DSS MAE。
M3−M2 用 2,000 次患者 cluster bootstrap。

`PROMISING_FAST` 要求 Spearman 增益 ≥0.05、95% CI 下界 >0、NDCG@5 不下降、MAE 恶化 ≤5%；
否则依证据标为 `NO_GO`、`BROKEN` 或 `INCONCLUSIVE`，不得更换终点救结果。

乳腺癌只作预先限定的外部分析：GSE303509 检验含顺铂组合的方向排序；GSE287429 做
DOX/BTZ × 23/47h 的四个差异表达与 Reactome 分析；GSE276609 只量化域偏移；多区域 PDO
仅在公开文件同时提供患者/PDO/IC50 和足够表达特征时做四药 patient-LOPO，否则正式记
`NOT_EVALUABLE_PUBLIC_MATRIX`。

## 正式结果（2026-08-23）

共同测试支持集为 52 位患者、29 种 GDSC 支持药物、1,989 条响应；每个 PDO 有
14–22 种可比药。来源 M2 在 GDSC2 release 8.5/CMP 上训练 3 轮，最佳 epoch 2，
source validation MSE 0.008359。全部来源标签使用 `1-AUC`，与 mCRC DSS 一致为高值敏感。

| 模型 | 患者宏 Spearman | NDCG@5 | DSS MAE |
| --- | ---: | ---: | ---: |
| M0 drug median | 0.7505 | 0.8539 | 4.4961 |
| M1 Ridge | 0.7494 | 0.8593 | 4.7085 |
| M1 RF | 0.7491 | 0.8590 | 4.7339 |
| M2 GDSC-only | 0.4790 | 0.7995 | 11.9446 |
| M3 GDSC→mCRC | 0.7277 | 0.8505 | 4.8614 |
| M4 mCRC-only | 0.7188 | 0.8256 | 5.0481 |

M3−M2 Spearman 为 +0.2486，2,000 次患者 cluster bootstrap 95% CI 为
[0.2190, 0.2769]；NDCG@5 +0.0510，MAE 改善 59.3%。按冻结规则判定
`PROMISING_FAST`。但 M3 没有超过 M0/M1，故只支持“目标域微调显著修复 source-only
域偏移”，不支持总体最优或临床可用声明。

GSE303509 顺铂结构、BPE 和 8,192 基因门槛通过。标签盲推理中，M2 为 rho −0.1071、
9/21（`DOES_NOT_SUPPORT`）；预声明五折 M3 等权 ensemble 为 rho 0.4286、14/21
（`SUPPORTS`）。该结论仅限含顺铂组合的方向一致性，不是顺铂单药或临床疗效验证。

GSE287429 四个时间匹配分析只支持描述性通路响应；GSE276609 得到 22 个恶性细胞
pseudobulk，但因缺少可信 domain 标签而阻断域偏移量化，且官方 MDA468 嵌套包源端截断；
多区域乳腺 PDO 六附件受发布平台访问阻断，正式为 `NOT_EVALUABLE_PUBLIC_MATRIX`。

正式大产物位于本地忽略目录 `data/artifacts/EXP-010/`，紧凑汇报为
`data/artifacts/EXP-010/report/EXP-010_compact_report.{json,md}`。首次 M2 因 AUC 方向错误
在无 checkpoint 时中止，审计保留；正式结果来自修正为 `1-AUC` 后的完整重跑。
