## 假设（先于实验登记）

仅以内层交叉验证留出预测训练的低容量联合模型（直接药敏预测 + 扰动通路特征
+ 逆转分数 + 可靠性）在患者内排序上不劣于直接药敏模型，且至少一个指标存在
可检验增益；否则联合阶段暂不扩展为共享通路多任务网络。

## 设计要点

1. **第二层输入**全部来自内层 CV 留出预测（直接药敏模型 EXP-024 多种子的
   内层留出预测；扰动通路特征 / 逆转分数来自 EXP-023 扰动预测产物；
   预测可靠性项），外层 test 与选模流程零接触——禁止用训练样本过拟合分数。
2. **低容量联合模型**（回归/排序），不做共享通路多任务网络（该扩展以本切片
   结果为闸门）。
3. **三方比较**：直接药敏模型 / 扰动排序 / 简单联合。
4. 指标：患者宏平均 NDCG@5（主）、患者内跨药 Spearman 与 NDCG@5（次），
   沿用阶段 1 患者等权与折等权宏平均口径。

## 结果（2026-09-19 完成）

**判定：DO_NOT_EXPAND——联合阶段暂不扩展为共享通路多任务网络（预登记失败条件触发）。**

主终点：ΔNDCG@5（联合 − pathway_pca_reg）= **−0.0056 [−0.0136, +0.0021]**
（患者级 2000 次配对 bootstrap 95% CI，51 患者，seed=20260918），联合劣于
直接最强臂且 CI 跨零。

三方比较（Task-B 患者宏平均，51 患者）：

| 臂 | NDCG@5 | Spearman |
|---|---|---|
| B0（官方 carve-fit） | 0.9087 | 0.8076 |
| pathway_pca_reg（3 种子） | 0.9147 | 0.8192 |
| 扰动排序（reversal_score） | 0.4224 | 0.0195 |
| 简单联合（第二层 Ridge） | 0.9091 | 0.7987 |

要点：
1. 零样本扰动排序基本无信号（NDCG@5 0.4224、Spearman≈0.02）。
2. 简单联合损害直接信号（−0.0056，CI 跨零）；Spearman 甚至低于 B0。
3. 上游原因：LINCS 留出 ctrl_only（cosine 0.6721）> ctrl+Morgan（0.6392），
   Morgan 单独仅 0.0171——线性设置下药物条件信息无正边际贡献，与 EXP-023
   消融一致。

验证通过：landmark 基因序锚定 vs route2 冻结 ckpt（<1e-3）；B0 官方复算
5 折与冻结 CSV 一致（<1e-8，折宏 0.9089=官方）；直接臂 ppr−B0 患者级
+0.0060 与 EXP-024 一致。

训练前钉死（无基于结果的调整）：LINCS pair-random 80/20 seed=20260918；
两层 Ridge α=1.0 不搜索；Morgan radius=2/nBits=1024（38/38 对 xpert 验证）；
top-8 通路按 y-free 覆盖规则；reversal=样本差异特征（全 92 样本均值，
landmark z 空间，非疾病逆转）；联合层仅内层 val OOF 训练，外层 test
零接触。LINCS 覆盖 0/48（覆盖标志零方差，如实保留报告）。
