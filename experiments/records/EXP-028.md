## 假设（先于执行登记）

1. **融合增量假设**：路线 B 的预测扰动特征（Hallmark 通路变化 + 逆转分数 +
   种子方差）能为路线 A 最优单模型（M1_source_scaled）提供均值基线之外的
   增量，且该增量需非线性交互才能表达（EXP-025 线性联合 Ridge 已否定，
   本实验改用非线性第二层）。
2. EXP-027 依据：路线 B 绝对排序低于 B0（无药物主效应校准）但逐药跨患者
   Spearman 个性化信号 +0.115 与监督路线 A 同量级——假设该个性化成分可被
   第二层以交互形式利用。

## 协议（预登记，训练前钉死）

**数据与划分**：kryeziu_mcrc_v3 合同数据；冻结 5 折患者隔离 split
（`kryzeiu_patient_outer5fold_FROZEN.json`，51 患者；每折 train 40-41 含
val 8-9 / test 10-11）。第二层与路线 A 重训全部在此 split 上进行（官方 run 的
种子相关折分配与冻结 split 不一致，13/51 折重合，不能直接复用——需重训，
见下）。

**路线 A 重训（EXP-021 M1_source_scaled 精确复刻，官方训练代码
`src/drug_screen/transfer/transfer_experiment.py` 同流程）**：

- 架构/超参：DualEncoderPairModel，hidden_dim=32, epochs=50, lr=1e-3,
  ranking_weight=0.2, max_rank_pairs=128, batch_groups=8；特征 =
  EXP-015 源预处理器（512 维）变换后的表达 + Morgan 2048 位指纹
  （radius=2）；随机初始化（M1_source_scaled 定义：源尺度预处理 +
  目标标签训练，无源权重）。
- 种子：20260912 / 20260913 / 20260919（官方三 run 同种子）。
- 外层模型：每折在全部 train 患者（40-41）上训练 → 预测 test 患者
  （10-11）→ A2_frozen 基线 OOF 预测（15 次训练）。
- 内层模型：每折在 inner-train 患者（train − val = 32）上训练 → 预测
  val 患者（8-9）→ 第二层训练行的路线 A 特征（15 次训练）。
- 官方单次完整 run（5 折 × 4 模型）实测 98 秒（GPU），重训总成本约
  30 次训练 × 数秒，可忽略。

**路线 B 上游重训（EXP-027 合同精确复刻 + 扩展输出）**：

- ChemPert v2 ctrl_morgan（FeatCond 795+1024→512→795），非零签名行中
  SMILES 可编码子集（约 66,173 行）训练，种子 23/24/25，超参与
  EXP-023/027 一致（epochs=40/batch=512/lr=1e-3/wd=1e-4）。
- Kryzei 零样本应用同 EXP-027（785/795 基因投影、10 缺失 z=0、48/48
  指纹、92 样本队列均值差异签名、逆转分数限 795∩Kryzei 子空间）。
- **新增输出**（EXP-027 parquet 未含，故需重训）：预测扰动 delta 聚合到
  全部 50 个 Hallmark 通路（每通路 = 通路基因 ∩ 795 预测维度均值，
  纯上游输出不裁剪 Kryzei 基因；通路覆盖数登记）。
- 注：GPU 非确定性使本次特征相对 EXP-027 为独立抽样，合同一致、数值
  不逐位相同，属预登记设计。

**第二层（融合 v1，EXP-025 内层留出机制）**：

- 每折：在 val 患者（8-9）行上训练（全部 48 药的观测行，约 490 行/折），
  预测 test 患者行；训练行路线 A 特征 = 内层模型预测（无泄漏），测试行
  路线 A 特征 = 外层模型预测；路线 B 特征零样本（不接触 Kryzei 标签）。
- 特征向量（预登记，共 2,103 维）：
  1. 路线 A OOF 预测（3 种子均值，1 维）；
  2. 路线 B 通路 delta（Hallmark 50 维，3 种子均值）；
  3. 逆转分数均值/方差 + 扰动幅度均值/方差（4 维）；
  4. Morgan 2048 位指纹（仅作交互项，radius=2）。
- 臂（预登记）：
  - F0_GBM_predonly：GBM 仅路线 A 预测（机制对照：第二层本身无害）；
  - F1_GBM_full：GBM 全特征；
  - F0_MLP_predonly / F2_MLP_full：同上，MLP h32。
  - 灵敏度臂 F1_GBM_full_xfit：第二层训练行改用 train 患者（40-41）5 折
    cross-fit 内层预测（assign_patient_folds seed=20260919；75 次内层
    训练），训练行约 2,400 行/折——预登记为次级灵敏度分析，回答
    「val 留出机制是否功率不足」。
- GBM 超参（钉死）：HistGradientBoostingRegressor，lr=0.05，max_iter=200，
  max_depth=3，min_samples_leaf=20，l2=1.0，early_stopping=False，
  random_state=20260918。
- MLP 超参（钉死）：2103→32 ReLU→1；Adam lr=1e-3，wd=1e-2，epochs=100，
  batch=128；StandardScaler（训练行拟合）；种子 31/32/33。
- 参照臂：B0_frozen（每折 train 患者药物均值 → test 预测，官方 B0 协议）；
  A2_frozen（路线 A 单模型重训 OOF）。

## 终点与比较（预登记）

- 三终点：非结构药子集患者宏平均 NDCG@5（主）/ 逐药跨患者 Spearman（次）/
  全面板 NDCG@5（参照）；MLP 臂多种子 mean±SD。
- 患者级 2000 次配对 bootstrap（seed=20260918，种子平均患者值，患者交集）：
  1. F1_GBM_full vs A2_frozen（主比较）
  2. F2_MLP_full vs A2_frozen
  3. F0_GBM_predonly vs A2_frozen、F0_MLP_predonly vs A2_frozen（机制对照）
  4. F1_GBM_full vs F0_GBM_predonly、F2_MLP_full vs F0_MLP_predonly
     （路线 B 特征增量，隔离第二层本身的影响）
  5. F1_GBM_full_xfit vs A2_frozen（灵敏度）
  6. A2_frozen vs B0_frozen（冻结 split 上路线 A 信号复核）
- 方向约定：不做事后翻转；按药分层附表（哪些药融合获益）。

## 失败条件（预登记，沿用方案）

- v1 主臂（F1/F2）CI 跨零且方向不一致，且灵敏度臂同样无正向信号 →
  「融合在此数据规模不可行」负结果，不再迭代 v2（防循环调参）。
- 主臂 CI 跨零但灵敏度臂 CI 不跨零为正 → 结论改为「融合信号存在但
  val 留出机制功率不足」，v2 端到端优先且第二层训练协议改 cross-fit。
- 路线 A 重训若在冻结 split 上无法复现相对 B0 的正向方向（A2_frozen vs
  B0_frozen 点估计为负）→ 融合基线失效，停止并如实报告（不调参救）。

### 判读（按预登记失败条件）

1. 失败条件第 1 档触发（且强于「CI 跨零」：主臂与灵敏度臂 CI 全负）：
   **融合 v1 负结果，v2 端到端双分支不迭代**。v1 主臂（F1/F2）均显著
   低于 A2；cross-fit 灵敏度臂（约 2,500 训练行/折）同样显著为负——
   排除「val 留出机制功率不足」的解释，失败条件第 2 档不成立。
2. 失败条件第 3 档未触发：A2_frozen vs B0_frozen +0.0235（CI 全正），
   融合基线在冻结 split 上有效，负结果可信。
3. 机制对照：F0_MLP_predonly 与 A2 无差异（第二层本身无害，近似恒等
   映射）；F0_GBM_predonly 轻度衰减（跨零）。特征增量（F1−F0_GBM、
   F2−F0_MLP）CI 全负——在约 450 行训练集上叠加 2,102 维路线 B +
   Morgan 特征引入噪声拟合。
4. 与 EXP-025（线性联合无增量）、EXP-027（路线 B 绝对排序低于 B0）一致：
   三种机制均不支持融合提升。主线维持路线 A 直接药敏建模；路线 B
   特征保留为解释模块与 EXP-029 素材。
5. 按药分层（14 已知药逐药 Spearman 差值 8 正 6 负）呈向零回归形态，
   无稳定获益药物子集。
6. 实现注记：融合脚本 role_frame 初版未按折过滤导致 xfit 行跨折重复，
   修复后重跑；bootstrap 患者交集改为排序遍历（消除 PYTHONHASHSEED
   引起的 CI 第 4 位小数漂移）；按药分层表修正为已知药子集（14 药，
   与 EXP-027 口径一致）。点估计三次运行完全复现（GBM/MLP 均确定性）。
