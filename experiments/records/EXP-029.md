## 四项分析（预登记协议）

### T1 通路级迁移图谱

- 通路活性 = 单样本内 Hallmark 通路基因 z 分数（各域内独立 z）均值；
  50 通路全部保留（每通路 ≥29 交集基因）。
- 每域每药 Ridge（alpha=1.0，StandardScaler 标准化通路特征）：
  GDSC 963 行；Kryzei 样本级（约 91 行，主口径）/ 患者级（51 行，敏感性）。
  两域响应方向均为 higher_is_sensitive=true（GDSC 1-AUC、Kryzei DSS），
  脚本内断言，不做翻转。
- 统计量：逐通路跨 14 药的系数符号一致率（二项检验双侧 p=0.5，
  BH-FDR 0.05）；逐药 50 维系数向量余弦相似度（附表）。
- 产出：50 通路可迁移性表（一致率、p、FDR、两域平均|系数|）。

### T2 共享/私有分解（CODE-AE 式正交约束自编码器）

- 输入：三域（GDSC 963 / Kryzei ~91 / 依赖图 255）在 14,900 共享基因上，
  域内逐基因 z 分数（std<1e-8 置 1）。
- 架构（钉死）：共享编码器 14900→512→128→64；各域私有编码器
  14900→512→128→32；各域解码器 (64+32)→128→512→14900；ReLU，
  线性输出层。正交约束 = 各域 ‖Zs^T Zp‖_F / n（共享-私有互协方差）。
- 训练（钉死）：Adam lr=1e-3、wd=1e-5、batch=128（三域混批）、epochs=30、
  λ_orth=1.0、种子 41/42/43（关键指标 mean±SD）。
- 度量（描述性方差分解，非预测）：
  - R²_full：本域共享+私有重构；R²_shared：本域共享码 + 私有输入置零重构；
    R²_private：本域私有码 + 共享输入置零重构（对照）；
  - **共享捕获比例（主指标，Kryzei）= R²_shared / R²_full**；
  - 三域间无成对样本，跨域重构 R² 不可定义；替代：共享码/私有码上的
    三分类域分类器准确率（logistic，5 折交叉验证）——共享码准确率接近
    1/3 = 域不变性强；私有码应接近 1（对照有效性）。
- 样本级相关（预登记）：逐 Kryzei 样本共享捕获（1 − ‖x−重构‖²/‖x−域均值‖²）
  与该样本零样本迁移性能（已知 14 药内 Spearman）的 Spearman 相关
  （样本级 + 患者级）。

### T3 近邻诊断

- 近邻空间：同 T2 输入（14,900 基因 z 分数）；距离 = 1 − Pearson 相关。
- 源模型逐细胞系误差：source_validation_predictions.parquet（193 个
  验证细胞系，逐细胞系 Spearman（预测 vs 观测，跨其全部预测药；
  药数 ≥50 才计入））。限制：验证集参与过早停（轻度乐观），登记为局限。
- 每 Kryzei 样本与每依赖图类器官（255）：k=10 最近邻验证细胞系（误差
  池限 193 个有误差的细胞系）；统计量 = 邻居误差均值。
- 主检验：患者级（51）Spearman（PDO 零样本迁移性能，邻居误差均值），
  双侧 p<0.05 且点估计为正 → 「近邻误差显著预测 PDO 误差」。
- 次级：样本级（~91）同式；PDO 性能与邻居平均距离的相关（负向预期）。
- 无近邻标注：样本到最近 GDSC 细胞系（全部 963）距离 > GDSC 域内
  最近邻距离的 95 分位 → 标注（Kryzei 与依赖图分别计数）。

### T4 药级边界

- 逐药（14 已知）：源跨细胞系 SD（GDSC 963 行 1-AUC）；目标跨患者 SD
  （51 患者均值 DSS）；跨 14 药 Spearman（源 SD，目标 SD）。
- 可迁移药定义（预登记）：该药零样本预测的逐药跨患者 Spearman
  （患者均值，EXP-027 口径）> 0 且患者级 2000 次 bootstrap（seed=20260918）
  95% CI 不跨零。
- 结构/非结构分开计数（7+7）；主判定用非结构药数。

### 零样本源→Kryzei 推理（T3/T4 共用，纯推断无训练）

- DualEncoderPairModel.load(source_model.pt) + ExpressionPreprocessor.load
  (expression_transform.npz)；Kryzei 表达变换到 512 维源特征空间
  （缺失基因中位数填充，对齐率登记）；48 药 Morgan 2048（radius=2）；
  预测全部 table 行；评价限 14 已知药（34 未知药预测仅落盘不评价）。
- 逐样本零样本性能：已知 14 药内 Spearman；非结构子集 NDCG@5（7 药）。
- 与 EXP-028 A2_frozen outer_test 逐患者性能并列对照（解释用，不比较）。

## 预登记判定（钉死，执行后不再更改）

1. T2 Kryzei 共享捕获 >60% 且 T3 近邻误差相关显著（p<0.05 且正向）→
   迁移失败主因是标签/协议体系 → EXP-031 优先扩源域数据；
2. T2 Kryzei 共享捕获 <30% → 主因是域偏移 → EXP-031 优先域适应
   （CODE-AE 式共享表示预训练，依赖图 255 RNA-seq 作无监督语料）；
3. T4 非结构药中可迁移药 <3 个 → 如实结论「该 PDO 队列规模下迁移路线
   证据不足」；
4. 其余组合 → 中间态如实报告，EXP-031 建议按最接近的分支给出。

## 结果（2026-09-20）

**预登记判定：INTERMEDIATE_REPORT_AS_IS | INSUFFICIENT_EVIDENCE_AT_THIS_COHORT_SIZE**
（T2 Kryzei 共享捕获 0.315 处于 30%~60% 中间带偏下；T3 近邻误差相关
rho=0.010 p=0.943 不显著；T4 可迁移非结构药 0 个）。

| 诊断 | 结果 | 解读 |
|---|---|---|
| T2 Kryzei 共享捕获 | 0.315 ± 0.123（3 种子） | Kryzei 表达方差约 1/3 可被三域共享成分捕获；GDSC/biobank 共享捕获 ≈ 0（-0.07/-0.15），方差几乎全部进私有码；共享码域分类准确率 0.735（域不变性不完美） |
| T3 近邻误差相关（患者级） | rho=0.010, p=0.943 | 源模型在近邻细胞系上的误差完全不预测 PDO 零样本误差 |
| T3 无近邻比例 | Kryzei 81/91（89%）；biobank 212/255（83%） | 绝大多数 PDO/类器官在 GDSC 表达分布覆盖之外（到最近细胞系距离中位数 0.775，即相关仅 ~0.22） |
| T1 通路一致率 | 中位数 0.500（50 通路，FDR<0.05 为 0 个） | 通路→药敏系数方向整体随机；但分布有结构（见下） |
| T1 逐药系数余弦 | 最大 0.29，多数 ≈0 或负 | 50 维通路系数向量两域近正交，系数层个性化规律不迁移 |
| T4 源/目标 SD 相关 | Spearman 0.613（14 药） | 药物效应变异幅度排序跨域一致（群体级规律保守） |
| T4 可迁移药 | 非结构 0/7，结构 1/7 | 零样本逐药全部失败 |

**数据规律（本次实验的归纳性发现，供 EXP-030/031 设计消费）**：

1. **覆盖缺口是首要瓶颈**：~85-90% 目标域样本（PDO 与类器官）在源域
   表达分布的近邻范围之外。逐样本零样本迁移失败的直接原因不是模型没
   学到规律，而是输入落在训练分布之外。
2. **表示共享成分低**（Kryzei 32%、其余两域 ~0）：域偏移实质性存在，
   与覆盖缺口相互独立地限制迁移。
3. **代谢通路方向一致、增殖/免疫通路方向不一致**：一致率最高的通路
   为炎症反应/过氧化物酶体/氧化磷酸化/异生物质代谢（0.71-0.79），
   最低为雌激素反应早期/凋亡/E2F/MYC（0.07-0.29）。提示代谢状态的
   药敏关联跨体系保守，增殖信号关联相反（未过 FDR，方向性线索）。
4. **群体级药物效应幅度排序跨域一致**（SD 相关 0.613）：哪些药在
   细胞系间变异大，在患者间也变异大。这一规律与 EXP-027「路线 B 携带
   与监督路线同量级群体信号」互洽。

**对 EXP-030/031 的设计输入（规律→决策）**：
- 零样本臂保留为下界对照（预期低：83% 类器官无近邻）；
- 域适应臂与输出校准臂为主战场（覆盖缺口 + 域偏移均指向此）；
- EXP-030 增加按「有近邻 vs 无近邻」分层的报告口径，直接检验覆盖缺口的
  可修复性；
- EXP-031 方向：域适应优先于扩源（T2 中间偏下 + T3 覆盖缺口），但以
  EXP-030 在依赖任务上的结果为最终依据。
