## 假设与问题

在公平条件（同划分、同指标、同监督条件匹配、同预算）下，直接药敏路线与扰动介导路线的能力梯度分别到哪一级？监督、预处理、预训练各自的收益是多少？

## 协议（预登记）

### D1 模型梯度（每路线基础/中等/较高各一级，首轮每级一个候选）

| 层级 | 直接药敏路线 | 扰动介导路线 |
|---|---|---|
| 基础 | ①目标训练折药均值基线；②逐药正则化线性模型；③显式药物×表达交互模型（逐药线性交互项） | ①全局扰动均值基线；②药物单独信息（药 ID 嵌入）；③基础扰动预测（线性对照+线性药条件） |
| 中等 | 调参后树模型（GBM，表达+指纹特征）；小型交互网络（双编码器/dual MLP 冻结协议） | 条件化非线性扰动模型（MLP 药条件臂，EXP-023 协议）及药敏排序部分 |
| 较高（每路线一个候选） | 药物—表达双线性交互网络（自研轻量，隐藏 128，预算受控） | **XPert 官方复现路径**（本地资产+检查点，978 基因；选择依据：可复现资产在本地、环境已验证、基因空间与 landmark 系兼容；TranSiGen 因需全新适配审计，列为备选不进入首轮） |

高能力候选选择依据（登记）：可复现资产、基因空间、监督标签、显存、预训练重叠、官方实现——**不按目标测试分数选模型**。XPert 检查点路径与适配审计在运行绑定时登记；若审计发现检查点缺失/不可运行，按失败条件上报，不临时替换为其他外部模型。

### D2 调参与资源

- 每个可调模型 ≤20 个内层候选配置；深度模型最终配置 3 个初始化种子；确定性模型不重复运行。
- 测试集不参与早停/配置选择/候选筛选；训练前登记参数量、搜索空间、最大训练步数、早停规则与总预算。
- 单 GPU RTX A5000 24GB；显存不足先记录问题（保持数学目标不变的工程修复允许；改变研究设置须修订协议）。

### D3 分离收益（少量目标标签设置，L4 同款嵌套子集）

| 条件 | 内容 |
|---|---|
| C1 从头 | 目标数据从头训练 |
| C2 源预处理+随机初始化 | 来源预处理统计+随机初始化 |
| C3 源预训练权重迁移 | 来源训练权重作初始化（源检查点不可复用时按失败条件处理） |
| C4 扰动特征+目标监督 | 扰动特征（零样本预测或实测扰动）加目标药敏监督 |

零目标标签设置下：直接与间接路线的**来源药敏监督匹配**；纯逆转评分单列为无目标标签机制基线，不与有目标监督模型的差值解释成路线优劣。

### 上游扰动任务单独评价（D3 末段要求）

- 已见/未见化合物分别报告（UNK 行分层，EXP-023 协议已有词汇表）；
- 明确 ChemPert 与 LINCS 来源重叠（GSE92742 组与 LINCS 训练化合物 100% 重合，整组隔离）；
- 稀疏上下调标签不视为完整连续变化；
- 剂量/时间未建模时注明边界；
- 覆盖率不足作为待检验解释，不作为预设主因；
- 基于全体目标样本均值的参考属特定目标访问设置，不称肿瘤—正常差异。

### 指标与统计

- 主指标与辅助指标同 EXP-032（B 包统一接口）；配对增益 vs 同监督条件均值基线；患者/细胞级 2000 次 bootstrap；Holm 主比较；固定预测重采样区间与重复训练变化分开报告。

## 判定

- 每级每路线报告绝对表现与相对其同监督条件基线的配对增益；
- 梯度内比较（基础 vs 中等 vs 较高）只在同路线、同监督条件下进行；
- 高能力诊断只在基础/中等失败后按"一次受控诊断"执行（方案 G2 例外条款）；无验证收益即停止，不追加模型/种子。

## 失败条件

- XPert 检查点不可复用或官方推理在当前环境不可运行 → 上报并记录，不更换候选；
- 显存不足且无数学目标不变的工程修复 → 停止该臂，记录；
- 任何臂训练集信息泄漏到测试（泄漏审计失败）→ 实验无效，重跑。

## 预算

- 直接路线：基础/中等沿用冻结协议成本；高能力双线性网络首轮 ≤20 内层候选 ×3 种子；
- 扰动路线：XPert 官方推理零训练成本（冻结权重）+ 下游适配 ≤20 候选；ChemPert 上游重训按 EXP-027 成本（约 200 秒 × 种子数）。
