## 研究问题和五臂

在同一 50% 目标患者药敏训练条件下，加入预测扰动信息能否增加未见 PDO 患者药物排序？首轮使用事前冻结的**参考细胞预测扰动**作为最小合格输入；如后来通过类器官表达—扰动条件尺度适配，患者条件预测可作明确独立输入扩展，不能把参考细胞特征标为个体化。

| 臂 | 输入 | 目的 |
|---|---|---|
| F-A | 给药前表达 + 药物结构 | 直接药敏单路 |
| F-B | 药物结构 + 冻结的来源细胞交叉拟合预测扰动特征；不得输入 PDO 给药前表达 | 必需的扰动单路效应 |
| F-F | 给药前 PDO 表达 + 药物结构 + 同一冻结的来源细胞交叉拟合预测扰动特征 | 融合增量 |
| F-C | 给药前表达/药物结构 + 参数量和更新机会匹配的普通直接分支，不含扰动信息 | 等容量控制 |
| F-S | 与 F-F 相同架构但在训练侧按来源细胞/扰动身份打乱扰动特征 | 正确扰动对应是否必要 |

五臂共享 EXP-036 患者五折/内三折、50% 标签档、14 药共同合同、三个种子及患者内药物排序主终点。主要比较族在启动前冻结：F-F 对 F-A、F-B、F-C、F-S；患者为配对单位，bootstrap 区间、有限修正双侧符号翻转和 Holm 校正。模型预测、训练侧交叉拟合缓存、患者预测和逐键分数均落盘。

Sol / medium 在 2026-09-23 的协议监督中指出，原 F-B 沿用 F-A 的 PDO 表达输入，不能作为扰动单路对照。自本修订起，五臂的强制输入合同是：F-A=PDO 表达+药物；F-B=药物+来源细胞 OOF 扰动特征（无 PDO 表达）；F-F=PDO 表达+药物+同一扰动特征；F-C=等容量普通直接分支；F-S=同融合架构并打乱来源生物扰动身份。患者条件扰动是单独扩展，不能替代 F-B。

## 2026-09-25 五臂融合输入决策包草案（后由本记录下一节的 Sol 裁定冻结）

以下内容是送审草案；后续 Sol / medium 裁定冻结了其中的条件级 OOF 汇聚语义，当前效力与剩余缺口以紧随其后的“条件级 OOF 向量复核与输入协议冻结”为准。草案不改变既有五臂、14 药面板、50% 标签档、患者五折/内三折、三种子或统计族；身份和向量未齐前仍不得物化或训练。

1. **代表细胞：**不按 PDO 响应选择单一参考细胞。来源端使用 EXP-037 五折中每折严格留出的 LINCS 细胞；先对同一 `pert_id × dose × time × cell_id` 的重复预测等权合并。之后建立共同来源细胞集合：仅保留对整个冻结14药面板及全部共同剂量—时间键均有有限 OOF 预测的唯一细胞；所有药物条件都用这一相同细胞集合等权汇总。来源细胞未被产生该 OOF 预测的拟合模型使用；外层患者标签不参与来源特征生成。
2. **剂量与时间：**保留原始药物条件键，剂量统一转换为摩尔浓度、时间统一为小时；不把不同剂量或时间行当生物重复。先取冻结药物面板中全部药物均有支持的精确共同 dose-time 键，再在键排序固定后对共同条件等权汇总为每药一个扰动向量。该向量是多暴露参考描述，不宣称与 PDO 药敏测定剂量/时程相匹配；不外插，不以响应标签选择条件。
3. **来源五折汇聚：**每个来源细胞只使用其所属外折模型生成的预测；只有外折0–4全部具备冻结代码/输入哈希并通过折验证后，才把唯一留出细胞预测合入来源 OOF 缓存。共同来源细胞集合从各条件完整性轴取交集，五臂共用相同集合；若交集为空，输入不合格，若覆盖较窄则先报告实际唯一细胞数和条件覆盖，再由 Sol 冻结是否可用。五折患者评估共用这份固定来源参考向量，不按患者外折或结果重挑来源折，不跨折平均同一来源细胞的训练态与留出态预测。
4. **共同药物面板与缺失：**保留预登记14药 InChIKey 面板。必须对每药唯一解析到精确 `pert_id + full-InChIKey`，并在全部必需共享 dose-time 键上有有限 OOF 特征；不使用近似别名、结构替代、零值填补或响应驱动删药。F-A/F-B/F-F/F-C/F-S 使用同一完整药物集合。任一身份或特征缺失都令当前14药 F-B/F-F 输入不合格；如需改为可唯一匹配子集，必须先由用户批准一次共同面板变更，再让五臂同范围重算。当前审计9/14唯一、1/14歧义、1/14结构记录冲突、3/14缺失，因此14药协议当前硬阻断。
