# EXP-064：20药来源域处理前状态近邻五折交叉预测

## 登记、授权与用途

- **状态**：已按用户冻结协议登记；CPU-only。先执行一个完整对象折成本闸，只有完整五折、独立读回、统计与收口含20%余量均在额度内才完成剩余四折。
- **用途 / 复用障碍 / 保留条件**：检验在固定20药来源开发域内，处理前状态能否帮助为留出TRAIN来源对象寻找同药近邻并迁移实测响应。复用EXP-062冻结的1982行条件键、角色、对象与药物完整身份、978基因轴及官方H5AD。EXP-062比较的均值/状态模型没有对象级交叉拟合近邻预测；其训练侧已见预测不满足OOF要求。新增入口与配置仅完成按对象OOF估计，不改变或覆盖EXP-062及已关闭EXP-058/061/062结果。
- **端到端负责人**：root / gpt-6-luna / xhigh；由root单写注册、记录、状态与报告，执行固定域运行、分析和独立读回。
- **授权**：用户在本线程明确授权按冻结的EXP-064端到端执行；无需逐折再请示。该授权不改变EXP-063 GPU额度决定，也不启动EXP-063。

## 科学问题与边界

主问题是：仅按冻结的处理前未处理表达状态，在同一药物下选择3个训练对象，是否比固定药物均值和数量匹配随机对象更准确地预测未参与该折拟合的TRAIN对象处理后转录响应？本实验是固定来源数据上的训练侧五折交叉拟合开发比较，不是独立外部验证、未见药物验证、真实PDO迁移或药效评价。

## 数据、身份与信息隔离

- 只使用EXP-062固定开发域中的1291条TRAIN条件、93个TRAIN对象、20个完整InChIKey和978基因；源H5AD数值只读取这些TRAIN条件的`X`与匹配`obsm['X_ctl']`。inner-dev/DEV、outer、locked、PDO、PANACEA及CDS-B数据库数值不得读取。
- 先按唯一来源对象分配五折，冻结哈希种子64064；同一对象的所有条件在同一折。每折完整条件键和对象键逐键保存，训练对象与留出对象交集须为0。
- 每折仅在其余TRAIN对象上拟合处理前状态的基因标准化与16维PCA、药物均值和响应基因方差。留出对象的处理前`X_ctl`只作输入，不参与任何处理响应特征、模型参数、邻居调参或选择规则。
- 近邻候选只来自该折训练对象，必须同一完整InChIKey且为三个不同对象；距离仅由标准化/16维PCA后的处理前状态计算。随机对照固定选择同药三个训练对象，使用预登记哈希种子。候选不足3对象时记为缺失，逐药逐折报告缺失；不填补、不换成跨药候选。

## 固定比较与评价

四臂为零变化、同药训练对象等权实测均值、处理前状态最近3个同药TRAIN对象的实测响应均值、按固定种子选择的3个同药随机TRAIN对象实测响应均值。选择距离不读取处理后响应。

主分母为四臂皆可预测的同一键化留出条件集合；若邻居或随机臂无法提供3个同药训练对象，则该条件从四臂共同分母排除，并另报零变化/同药均值在全部留出TRAIN条件上的完整分母。条件误差先按对象聚合，再对象等权；主指标为以各折训练对象响应方差标准化的对象宏NMSE。报告MAE、基因相关、方向一致率、预测/真实幅度比、逐对象与逐药绝对指标，以及最近邻相对同药均值和随机臂的配对对象bootstrap区间（20,000次、种子64065）。undefined值留空并给出有效分母。

## 资源、成本闸与停止条件

- CPU总包帽900秒、GPU=0；另受EXP-055既有累计CPU帽7200秒限制。开始时EXP-055累计CPU按EXP-062 5582.459812秒加EXP-063 392.838410秒结算，即5975.298222/7200秒；EXP-064可用余额不超过1224.701778秒。失败、入口检查、数据加载、读写、统计、root复核和收口均计入两层账。
- 第一完整对象折必须包括训练对象预处理、全部四臂预测、键化落盘与读回；按实际完整成本投影剩余四折、独立读回、统计和收口，并加20%余量。只有该总投影同时≤900秒与EXP-055剩余封套才运行其余四折。否则保留首折并明确报告未完成五折缺口，不删臂、不降对象/基因数、不扩帽。
- 所有折完成后做一次独立数值/身份读回。身份、对象隔离、轴或键不符时关闭受影响结果；非有限响应保留null及分母，不静默转零。

## 2026-10-08：五折 OOF 完成及独立复核

- **运行状态与成本门**：唯一 run `coverage20_oof_v1/fit_attempt_001` 完成五折。首折含TRAIN输入读取、预处理、四臂预测、落盘与读回耗时0.717秒；五折计划按最大对象折不均衡放大后加上独立读回、汇总、60秒前置保守扣账并加20%余量，预计430.565秒，低于EXP-064包帽900秒和启动时EXP-055继承剩余1224.702秒。runner总耗时32.098秒（进程CPU 34.544秒）。
- **固定输入与隔离**：1291条TRAIN条件、93个对象、20个完整InChIKey、978基因。哈希对象折分别为15/17/13/19/29个留出对象；总分母为1291条件/93对象，所有四臂均可预测、缺失0条件。每折训练/留出对象交集为0。仅读取冻结TRAIN行的`X`与匹配`X_ctl`并重建处理响应；处理前状态近邻只依`X_ctl`均值和折内标准化/PCA。未读inner-dev/DEV、outer、locked、PDO、PANACEA或CDS-B数值。
- **主结果（对象宏NMSE，低值较好）**：同药对象均值1.080905；处理前状态最近3同药对象1.218417；哈希随机3同药对象1.354454；零变化1.283834。最近邻比随机臂低0.136036 NMSE（相对随机误差约低10.0%），93对象配对重抽样95%区间0.099711至0.174423，82/93对象上更好；但仍比强同药均值基线高0.137512（相对均值约差12.7%），配对区间−0.163963至−0.110694，最近邻仅8/93对象NMSE更低。因此处理前近邻确实胜过数量匹配随机对象，但没有超过简单同药均值，不能称为额外预测增益。区间描述固定来源对象的配对重抽样，不代表患者/亚型总体推断。
- **辅助指标（同一1291条件/93对象）**：每药均值、最近邻、随机三臂方向一致率分别62.82%、61.63%、58.97%；MAE分别0.43909、0.47969、0.52230；幅度比分别0.49691、0.70195、0.76219。零变化NMSE为1.283834；其相关系数按预登记规则未定义（对象分母0），没有填成0。方向和幅度只作描述，不改变NMSE主结论。逐对象、逐药及逐条件预测和统计保存在权威输出。
