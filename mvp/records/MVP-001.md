## Core Question

在同一真实 CRC Tumor-vs-Normal disease signature、同一候选药物 cohort、同一 scoring protocol 下，
DrugScreenLab 能否完成：

`exact-978 foundation -> observed LINCS reversal oracle -> learned Delta978 -> predicted reversal -> PRISM`

并产生第一个可审计的端到端 feasibility signal？输出仅允许 `PROMISING`、`NO_SIGNAL`、`BROKEN`；
不得包装为正式 scientific conclusion。

## Minimal System

```text
CRC Tumor-vs-Normal signed log2FC (up/down)
  -> exact-978 disease signature
  -> observed LINCS exact-978 reversal oracle
  -> drug ranking
  -> compact PRISM benchmark

GSE92742 exact-978 cache
  -> learned drug/dose/time Delta978 predictor
  -> held-out Delta978 prediction
  -> predicted reversal ranking on the same CRC signature/candidate cohort
  -> the same compact PRISM benchmark
```

### Data And Roles

- Disease signature: a real public CRC Tumor-vs-Normal Colon contrast with signed log2FC, explicit up/down sets,

- Primary phenotype benchmark: one compact PRISM response/identity asset, with drug and cell-line identities,

## MVP Model And Fidelity

- Tiny: a fixed small slice validates cache reads, row identity, loss/metric path, zero-vector handling,
  signature/ranking serialization, PRISM schema join and restart/recovery. It is engineering-only.
- Small: one-seed, simple regularized drug/dose/time model predicts Delta978 on a deterministic bounded subset;
  report both constant and `train drug-mean Delta978` diagnostic baselines. No hyperparameter search.
- MVP Full: only after Tiny/Small have no engineering blocker, expand the same simple model just enough to cover
  the frozen candidate cohort and produce predicted reversal rankings on the same signature used by the oracle.
- If the learned model has no signal, complete the chain anyway and identify the bottleneck; at most one bounded
  rescue probe is allowed, with no architecture expansion.

The model is intentionally a learned perturbation baseline, not a claim of unseen-drug or unseen-context
generalization. Its held-out perturbation evaluation uses a predeclared bounded within-drug treatment holdout.

## Reversal And External Comparison

The primary reversal target is a real CRC Tumor-vs-Normal signed log2FC signature. Up/down direction, exact-978
gene order, candidate cohort, anti-correlation/scoring direction and PRISM join are frozen before reading PRISM
response labels. Disease signature construction must not use PRISM labels.

First compute an **observed LINCS exact-978 oracle** using measured Delta978 for the same candidate cohort. Then
compute a **predicted reversal ranking** from the learned Delta978 outputs using the identical signature and scoring.
Compare both rankings to the same compact PRISM benchmark. Report per-cell-line ranking direction, Spearman,
Top-K enrichment/Recall@K or HitRate@K, and (where defined by the frozen benchmark) AUROC/AUPRC. Do not pool
replicate samples as independent cell lines and do not select a favorable stratum after seeing results.

The old GSE117548 branch remains a separate deferred protocol. Its previously frozen external `auroc` direction
and PDO line-level aggregation are retained as metadata only; they are not used to rescue or redefine this core
MVP.

## Success Interpretation

- `PROMISING`: observed oracle forms an auditable reversal ranking, the learned chain completes on the same cohort,
  and both observed and predicted rankings show a reproducible directional signal against compact PRISM under the
  frozen metrics. This is MVP feasibility only.
- `NO_SIGNAL`: the chain completes but observed oracle has no signal, or observed has signal while learned/predicted
  ranking does not. The report must distinguish `CORE_REVERSAL_NO_SIGNAL` from a learned-prediction bottleneck.
- `BROKEN`: source identity, schema, cache/metadata, exact-978 mapping, candidate identity, PRISM join or artifact
  path fails before a valid ranking can be evaluated.

Decision cases are fixed before execution: (A) observed oracle no signal -> `CORE_REVERSAL_NO_SIGNAL`; (B) observed
signal but learned no signal -> perturbation-prediction bottleneck; (C) both signal -> `CORE_MVP_FEASIBILITY_PROMISING`.
No case authorizes automatic creation of a Formal EXP.

These outcomes are decision signals only. They are not a formal scientific conclusion, do not validate disease
reversal biology, do not establish efficacy prediction, and do not replace a later rigorous external validation.
