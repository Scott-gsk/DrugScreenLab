# MVP-001: End-to-End DrugScreenLab Feasibility

## Status

`proposed_pending_approval`。这是 MVP Integration，不是 Formal Research EXP，不占用新的 `EXP-ID`。
未实现、未训练、未运行。等待 `APPROVE MVP-001`。

## Decision Frame

- Expected Decision Value: 高。它首次检验项目主链路是否能从公开表达数据走到外部药效相关的 drug ranking。
- Expected Cost: 低到中等。复用已登记 cache、小型 public PDO expression/activity tables；不下载新数据，
  不重扫 65 GB Level-3 matrix，不使用 UniPert、XPert、mechanism network、WTS 扩展或 organoid adaptation。
- Cheapest falsification: Tiny deterministic subset 上，训练/推理/ranking 任一步无法完成，或公共 drug identity
  overlap 少于 3 个候选药物，则标记 `BROKEN` / `NO_SIGNAL`，停止扩大。

## Core Question

使用当前公开数据与最简单合理 learned model，DrugScreenLab 能否第一次端到端运行并产生相对公共
PDO drug-activity evidence 的非平凡 ranking signal？

## Minimal System

```text
GSE92742 exact-978 cache
  -> learned drug/dose/time Delta978 predictor
  -> held-out perturbation prediction
  -> predicted drug signatures
  -> CRC PDO state-deviation reversal proxy
  -> per-PDO candidate ranking
  -> GSE117548 public PDO drug-activity comparison
```

### Data And Roles

- Training: `lincs_gse92742_exact978_cache_v1` plus the frozen EXP-002 metadata/identity contract. The MVP
  uses a deterministic representative subset, not a new full raw scan.
- State input: `GSE117548` untreated colorectal cancer PDO microarray profiles (25 public samples / 16 PDO lines).
- External evidence: local compact `betge_2022/external_drug_activity.parquet` (66 PDO-drug activity rows,
  five named drugs). It remains external-only: no tuning, feature selection or threshold fitting on activity labels.
- Data Steward, Model Engineer and Evaluation Analyst may work in parallel after approval; Scientific Analyst is
  optional for identity/interpretation questions. No Reviewer during FAST/Tiny/Small; one Reviewer only after a
  completed MVP milestone selected for evidence review.

## MVP Model And Fidelity

- Tiny: a fixed small slice validates cache reads, row identity, loss decrease, held-out scoring, signature/ranking
  serialization and activity-table join. Output is `PROMISING`, `NO_SIGNAL` or `BROKEN` only.
- Small: a one-seed multi-output regularized embedding model with learned drug, dose and time embeddings predicts
  Delta978 from a deterministic representative GSE92742 subset. No new architecture, hyperparameter search or
  strict cold split.
- MVP Full: only after Tiny/Small pass, expand the same simple model to a bounded cache subset sufficient to cover
  all externally mappable candidate drugs and produce one reproducible end-to-end artifact.

The model is intentionally a learned perturbation baseline, not a claim of unseen-drug or unseen-context
generalization. Its held-out perturbation evaluation uses a predeclared within-drug treatment holdout.

## Reversal And External Comparison

For each GSE117548 PDO, construct a **PDO state-deviation proxy** relative to the other public CRC PDO profiles;
map only shared, unambiguous genes into exact-978 space and score predicted drug Delta978 by signed anti-correlation.
This is an operational MVP reversal proxy, not tumor-vs-normal disease biology and not a clinical recommendation.

Candidate drugs are retained only after a deterministic, tracked name/structure identity mapping to both LINCS and
the five GSE117548 activity drugs. The MVP ranks only retained drugs within each PDO and compares rankings to the
pre-existing external activity value (`auroc`) using per-PDO rank correlation and pooled direction agreement.
The activity labels are read only after rankings are frozen. Fewer than three unambiguous mapped candidates is a
`BROKEN` data-integration result, not an excuse to use unverified aliases or download a new benchmark.

## Success Interpretation

- `PROMISING`: Tiny/Small completes; held-out perturbation score is above the predeclared constant baseline; at
  least three candidate drugs map; rankings have positive direction agreement or rank correlation with external
  activity in the frozen eligible PDO cohort.
- `NO_SIGNAL`: the pipeline completes but either perturbation or external ranking comparison lacks directional signal.
- `BROKEN`: mapping, schema, cache/metadata, expression-to-landmark mapping, or artifact path fails.

These outcomes are decision signals only. They are not a formal scientific conclusion, do not validate disease
reversal biology, do not establish efficacy prediction, and do not replace a later rigorous external validation.

## Required Reproducibility Artifact

One compact tracked summary must record data IDs/checksums, subset selector, code/config revisions, command,
environment, held-out perturbation metric, candidate mapping table digest, per-PDO ranking digest, external join
counts and the `PROMISING` / `NO_SIGNAL` / `BROKEN` decision. Large cache, predictions and checkpoints remain local.
